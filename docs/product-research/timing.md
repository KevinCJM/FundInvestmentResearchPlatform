# ETF 产品择时研究

本页是产品择时主题入口。它研究产品级入场、退出和交易路径；引用到[投前实施](../pre-investment/implementation.md)仍是 research_only，不自动发单或变更组合。
## 数据与对象

`TimingDefinition` 保存名称、说明、有向无环步骤、入场条件端口、可选退出条件端口及执行规则。步骤为 `{id,label,op,inputs,parameters}`，连接格式 `node_id.port`，ID 唯一，禁止环、自引用、悬空连接和类型错误。数字序列与条件端口严格区分。固定规则原契约与后续训练扩展分别按服务端图预算校验；当前训练扩展预算见下节。

`TimingStudy` 锁定定义快照、产品列表、研究起止日、样本外开始日、滚动分段数和价格口径。算法参数不从测试区间自动拟合；后续调参生成新实验并明确历史样本已被查看。固定规则的时间分段检查不宣称为前瞻实盘验证。

`TimingRun` 保存定义与请求快照、输入指纹、逐日净值/持仓/信号、逐笔交易、全部/样本内/样本外/分段/年度/月度统计、节点输出、执行审计和限制。历史运行不可被新定义或新行情覆盖。对照使用同一价格与日期口径、未扣费的买入持有基准；策略双边扣费用与滑点。

`TimingRelease` 只发布研究用途，锁定 run 与定义哈希，保留适用产品和限制。投前引用保存该不可变关联，不自动调整已有组合。未证明历史 PIT 数据时不能获授正式可交易回测或实盘用途。

## 算法与颗粒度

| 类型 | 职责 | 拆分原则 |
| --- | --- | --- |
| 数据源 | 输出 ETF 某个 OHLCV 字段 | 按字段显式端口，底层共享一次读取 |
| 数学算子 | 滞后、滚动、差分、算术、平滑等 | 从指标注册表派生目录与校验，复用原 NJIT |
| 指标引用 | 锁定指标版本并转成上游输入的数值计算 | 仅安全映射的序列/滚动标量进入目录，准备错误说明原因 |
| alpha-beta | 联合递推水平、斜率、创新值 | 三个输出共享不可分离递推，作为耦合内核；外围阈值独立 |
| 比较/逻辑 | 数值转条件、AND/OR/NOT | 三值缺失语义，用户可独立替换和预览 |
| 首次/确认/冷却 | 条件转离散事件并约束重复触发 | 显式状态、预热、缺失重置与边界规则 |
| 执行模拟 | 从事件与持仓推进现金、净值和成交 | 持仓/现金是不可分离状态机，事件计算在外部 |
| 评价 | 计算运行/交易/时间分区的研究指标 | 不反向参与信号图，未来收益标签不能成为特征 |

内置模板生成真实步骤和连接，不封装完整业务黑盒：

1. 均线趋势基线：价格、均线、比较、首次确认、反向退出。
2. 低滞后修复（参考 A2552 的结构）：前期收益/回撤、首次上涨、alpha-beta 斜率/创新值、独立确认条件。固定参数模板不等于 WF 的训练选择策略，也不继承其股票绩效。
3. 长期弱势反转（参考 A160S）：均线上方比例、前期回撤、连续上涨确认。本次是简化的可编辑结构模板，未复刻原量价过滤、训练策略或股票绩效。每一计算/过滤步骤可编辑，参数修改形成新定义。

算法库同时允许从空白添加算子。表单步骤与画布/公式展示共享同一后端定义，禁止前端文本和后端执行各持一套真相。

当前端口仅开放数值序列与三值条件序列。首次/冷却输出为逐日条件脉冲，连续确认输出为持续条件，目录显式声明事件语义；它们不是区间或状态编码，不允许接入事后分类状态或区间。未知与未触发分别为 -1 和 0，图表显示未知为空。

## 日频执行口径

- 收盘后才可得的入场/退出条件，只能在下一交易日开盘执行；以完整交易日历计数，不能把下一条有效行情当下一交易日。
- 买入当天不卖出。后续交易日止盈止损均以入场实际模拟价格为基准；跳空越界按开盘价格，日内同时触及按止损优先，明确这是日线保守假设。
- 普通退出在下一开盘处理；最长持有期到达后产生下一交易日退出意图。末日剩余持仓保留盯市，不能伪造同日卖出。
- 单产品研究资金只有一个头寸，持仓期间重复候选与实际成交分别计数；费用和滑点双边计入。买入持有基准使用同一价格口径，不扣费，界面明确提示。
- 原始行情和复权行情分开保存。复权价用于研究相对收益，不能解释为实际报价和可下单股数。默认 HFQ，支持明确选择 raw/QFQ；缺因子不填 1，QFQ 锚点绑定截止日。
- 执行区间缺必要 OHLC、非法价格或缺失交易日时，不输出看似有效的完整收益。特征窗口不足可以输出未知信号，但不填补价格。
- 整个执行区间缺失或非正成交量均拒绝运行；首期不实现停牌恢复、涨跌停成交队列或交易容量。交易日历需包含开市和休市日期，完整覆盖请求区间；尾部未知不能当作节假日。
- 明确披露时间晚于因子观察日的复权因子拒绝参与历史当日计算；未提供修订历史时只允许研究用途，不因此获得 PIT 认证。

## 操作与研究结果

选择 ETF／日期 → 选择或创建模板 → 调整真实步骤 → 显式准备 → 运行研究 → 查看净值、成交、样本外、年度／月度和节点证据 → 保存研究版本。输入改变使旧结果过期，晚到响应不得覆盖新草稿；图表提供逐笔交易和可访问数据表。

成交 B/S 标记绑定真实模拟日期与价格，不能为视觉抽样删交易。无成交不造点、缺价格不补线；零交易不证明稳定有效。前端只格式化，不重算绩效。
## API 与任务边界

统一前缀 `/api/timing-research`：`GET /catalog`、`GET/POST /definitions`、`PUT /definitions/{id}`、`POST /prepare`、`POST /runs`、`GET /jobs/{id}`、`GET /runs`、`GET /runs/{id}`、分页节点/曲线/交易结果、运行比较、研究发布和投前绑定。

准备/保存阶段显式编译公式并冻结定义哈希，普通运行只调用已预热计划。运行使用有界后台任务队列，返回进度和产品级失败原因；不无限排队。每研究至多 12 个产品，每产品至多 12000 行，顺序处理产品以控制峰值内存，结果分页返回。任务和结果引用必须按后端快照校验，前端状态不构成发布权限。

具体持久化：每产品一个结果 JSON、一个固定 dtype 的 NPZ；小型 manifest 记录结果与输入校验和。JSON 最大 64 MiB、数组最大 128 MiB，读取校验 SHA256，发布和新建引用再次校验冻结输入。接口按产品加载后分页，不是磁盘流式分页；默认首个成功产品带完整明细，其余按选择加载。后台一个工作线程、最多四个在途任务；运行状态保存在进程内，重启后已完成记录仍可查看，未完成任务需重跑，已有分产品文件保留且底层提交可恢复。

比较必须使用相同产品、时间区间、样本外边界、费用、价格口径和市场输入指纹。定义哈希与输入快照分别保存，算法修改不会被误当成数据修改。

## 性能、内存与因果性

- I/O 边界将日期规范为 int64，价格/量为 float64，条件为 int64；后续计算无 Pandas、object 数组或反复转换。
- 只读取必要字段和目标产品，数组冻结只读；源节点仅引用已有数组。连续窗口传基础数组与 start/end，跨节点不复制源数据；输出与工作缓冲按需要分配。
- 数据源、条件和执行核接受只读非连续视图；通用公式的固定签名要求读取边界提供 C 连续数组，不在节点内复制以迁就签名。执行前估算工作量不超过 2 亿、工作区预算不超过 64 MiB。
- 模板与保存公式共用通用指标编译器，领域 NJIT 核心固定签名并禁用请求期新签名。启动预热和保存/显式准备承担编译；运行请求缺计划直接返回可操作错误。
- 复权、日期规范化、解码和持久化是允许的边界复制，记录其范围；不将 `asarray/copy=False` 当作零拷贝证据。
- 测试实际 `np.shares_memory`、只读输入、非连续视图、别名污染、dtype/NaN/边界、未来扰动与固定签名数量。大样本基准记录实际耗时及峰值内存。
- 前端验证固定签名执行审计。数据历史修订未保证时保留研究能力和限制，不给出正式 PIT 认证；事后状态可用于评价分组，不能接入可执行信号。

### 原始依据中的关键校正

- A2552 的 108 组为3组联动 Alpha/Beta ×3个前期收益门槛 ×3个回撤门槛 ×2种确认 ×2个收盘位置门槛。不能解释为108套独立发现器。
- A160S-106 的市场广度是横截面概念，不能用单只ETF站上均线的历史时间比例代替。其原测试期零信号回退不迁移。
- 095/096 入口 `A2536_momo_094_096_high_confidence_gate_router.py`，与摘要中其他后代特征族筛选不是同一算法。这里只迁移核实后的高置信筛选/状态准入思想。
- 原学习器中代理标签成熟度、完整15日路径统计与实际退出日不一定等价。本实现只读取已完成交易的净收益、退出原因及日期，不用未来MAE/MFE拟合。

## 数据与执行链

`目录模板 → 可编辑 Definition → 显式 prepare → 冻结候选计划 → ETF及环境篮子读取 → 因果特征/条件图 → 训练成熟交易 → 冻结动作 → 样本外信号 → 既有T+1执行 → 不可变结果与审计`。

定义增加可选 `adaptation`、`training`，既有无训练定义仍走唯一固定规则实现。新字段不重写历史快照。128个可见步骤、512个内部数学步骤；最多8种动作、108个非现金训练候选。搜索空间可联动多个参数，不能修改数据源、状态依赖或退出依赖，否则候选和部署语义不一致。

运行增加 `context_baskets.market/category`，每个实际使用的篮子必须显式指定2–12只ETF。不得从单一研究产品推导“市场宽度”。成员×时间使用固定float64矩阵；类型包含 `panel` 与 `condition_panel`，不同成员身份的矩阵不能按位置相加或比较。聚合为时间序列后可以做相对动量。

每个成员仅在任务内读取一次，篮子与研究产品锁定同一行情快照/价格口径。按目标日期对齐，成员上市前/缺行情留NaN，任何成员未知则当日广度/均值未知；不删日期、不变分母、不虚构成分股历史。结果保存成员顺序、源指纹、矩阵校验和与固定篮子偏差提示。

篮子中间步骤可逐成员预览，最终比例可直接预览。默认参数的特征图与训练后最终入场是不同输出；最终入场单独展示，选中参数列于冻结审计，不将默认值图冒称所选参数图。

## 算子颗粒度审查

| 能力 | 唯一职责/可替换中间量 | 复用与不再拆分的理由 |
| --- | --- | --- |
| 普通数学与滚动 | 数值特征 | 复用统一typed注册表和NJIT计划，没有新MFI/CMF黑盒或重复滚动代码 |
| panel_formula / panel_lag | 把同一个系列能力映射到每个成员 | 仅布局/调度适配，调用同一公式计划与同轴内核；行视图可共享 |
| panel_compare | 对成员输出三值条件 | 复用共享condition_compare；类型和阈值等号不变 |
| cross_mean / breadth | 当日固定成员归约/条件比例 | 复用共享轴均值、三值转数值；与趋势计算分开 |
| Alpha-Beta | 水平、斜率、创新的联合递推 | 复用既有耦合内核；缺失重置，一遍观察后终止；外围比较独立 |
| priority_quota | 主信号优先、月内有限补位 | 当月计数与跨月冷却共享因果状态，不能拆成事后月总数；全日期扫描终止，候选不等于成交 |
| encode_states | 显式条件组合编码 | 0/1位编码、任一未知为-1；只承载状态身份，不把数字大小当距离 |
| score_trades | 已成熟交易按状态估计保守效用 | 成熟/分组边界和Welford统计融合避免每组复制；统计结果可独立查看，与选择分开 |
| choose_actions | 有限效用中选过门槛的最高者 | 独立于特征、拟合与应用；同分按配置顺序，不足证据空仓 |
| route_actions | 冻结选择映射为当日入场 | 不训练、不读取收益；状态未知仍未知，现金为明确0 |
| simulate | 推进持仓/现金/交易状态 | 复用既有固定签名T+1内核，规则与评价均在外部 |

所有完整家族只作为组合模板，插入后是真实连接，不注册整套“Axxxx黑盒算子”。上述训练阶段分别可审计，前端低码表单持久化同一类型契约。当前未新增把训练过程序列化为通用指标公式的语言；训练是独立研究阶段，不伪装为普通因果特征。

## 冻结与因果边界

- 训练交易必须满足 `signal >= study_start`、`exit < split - embargo_bars`，且已实际平仓；未完成头寸不强制当标签。
- 冻结日为样本外首日前一个交易日收盘。可用该日信号在首个样本外开盘交易，不能用首个样本外日收益拟合。
- 目标 `mean_return - confidence * sample_std / sqrt(n) - risk_penalty * stop_rate`；交易数不足、无有限效用或未严格超过门槛时空仓。无全局强行回退、不看未来无信号回退。
- global一张表；state按至多3条三值条件编码；month/quarter按信号日期自然月/季度匹配训练历史。整个样本外冻结，不宣称滚动重训。
- 在同训练集选108候选仍有选择偏差，置信惩罚不是独立内层验证或多重检验修正；最终效果必须看预留样本外。
- 图表训练期保持现金，明确“未回填拟合收益”；不显示事后选择的训练绩效冒充已部署策略。原有年度/月度、样本外分段指标继续复用。

## 内存与性能预算

- 输入float64/int64只读，成员×时间采用C布局，每成员行为零拷贝视图；非连续共享输入由固定A布局内核接收，普通公式仍要求读取边界C布局，不在节点内复制。
- 必要复制：读取日期解码/对齐，篮子面板输出分配，三值转数值工作缓冲，信号矩阵和持久化。对齐用原研究序列内核；其只接收可写C数组时，适配复制仅在I/O边界一次发生，并复用结果。
- 最多12研究产品＋两组各12篮子成员，任务内缓存唯一产品，单工作线程、4任务槽；不跨进程序列化大矩阵。
- 图工作区64MiB，训练候选峰值含基础通道、篮子、108条信号及最大单候选工作区，上限128MiB；训练估算工作量不超过20亿，显式拒绝而不是自动缩样本。
- 参数组合的公式计划全部在显式准备/启动预热完成；生产运行禁止重新prepare/compile。每次候选完成释放中间值，只保留信号和小型评分表。
