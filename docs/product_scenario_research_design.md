# 单产品研究与情景模拟融合设计

日期：2026-09-08。范围：现有单产品研究页、产品分析 API、对应固定签名 NJIT 内核与测试。基于当前工作区源码设计，保留已有研究能力。

## 1. 当前页面与问题

已核实的主要问题：长页层级不清；情景表用全量行情而统计使用另一个窗口；模拟随任意统计参数自动运行；原情景内核跳过无效价格后可能连接缺口；原 Bootstrap 压平有限收益后可能连续抽取跨缺口或跨片段的数据。后两项会改变样本的经济含义，必须与交互改造一起修复。

## 2. 用户路径与页面结构

进入产品时直接展示走势与指标，不再在首屏放置大块研究条件。情景表现、收益统计、未来模拟共用紧凑的“分析样本区间”工具栏；“全部历史”表示当前可用历史。收益口径默认复权净值，ETF 可展开“分析设置”切换交易价格，场外基金只展示口径文字。只有存在合格发布版本时才显示情景选择器；无情景、加载及加载失败提示放在情景表现页签。选择版本后默认比较所有状态，点击状态可深入连续区间。切换视图保留上下文；带情景返回走势图时显示简短摘要与“调整情景”入口。

四个研究视图：

1. **走势与指标**：主要走势图、连续时间轴指标、自定义时序、因子证据。技术设置和定义渐进展开。
2. **情景表现**：先比较状态，再看“区间长度—区间收益”散点和连续区间明细；点击一段可定位走势。
3. **收益统计**：当前样本摘要、收益统计与分布图；不重复放情景选择器。
4. **未来模拟**：当前样本与条件假设、简洁参数、运行按钮，然后显示双模型结果和敏感性。

分析工具栏与结果之间展示简短样本摘要，例如“熊市 · 8 段 · 126 个有效日收益”。所有数量来自后端。区间数量不解释为独立事件数量。未选择具体状态时，收益统计和模拟使用完整研究窗口，情景视图仍列出各状态对照。

视觉采用低饱和背景、清楚的白色内容面板、单一强调色、稳定间距；市场状态保留发布版本颜色，文字标签同时表达状态。减少渐变、重复大标题和大面积说明。表格在窄屏内部横向滚动，页面本身不溢出。标签页支持键盘操作，图表配套可读的数值/表格。

## 3. 情景中心与消费关系

情景中心继续拥有方案、版本、冻结运行与发布。产品页只引用 `run_id + publication_id`；服务器验证不可变状态、发布用途 `product_research`、内容哈希、方案版本匹配，再解析原始状态与区间。客户端不得上传自行改写的区间代替发布结果。

连续区间 ID 由冻结运行中原始区间索引生成 `segment-{index}`，不随研究窗口变化重新编号。状态不存在、区间不存在或两者不匹配时返回 422。更换版本会清空状态、单段和旧模拟。

本功能提供历史条件研究和以该样本为基础的未来路径模拟。回顾性状态可用于描述历史；所选状态不被解释为当时可获得的交易信号，也不产生未来状态转移概率。

## 4. 样本与指标契约

### 数据与窗口

- 研究数据默认复权净值；ETF 可显式切换交易价格。每次响应标明实际口径和数据指纹。缺少指定字段不静默改用另一种数据。
- 行情技术图继续使用实际行情时间轴；计算收益统计、情景表现与模拟使用同一研究数据和 `statistics_period` 窗口。
- 研究窗口沿用已有完整窗口规则，短历史不自动冒充完整窗口；缺失值不填零、不前向填充，不跨缺口计算单期收益。
- 原始日期顺序保留。发布区间与产品数据/研究窗口相交后披露截断情况，未覆盖的完整情景不能被称为完整事件。
- 当市场交易日历可用时用于识别缺失交易观测，不以通用工作日历伪造交易日。基金数据频率与披露特征需保留。

### 收益边界与聚合

设有效净值为 \(P_t\)，普通收益 \(r_t=P_t/P_{t-1}-1\)。选择状态/区间后，仅使用两个端点都属于同一连续区间、且价格均为有限正数的相邻收益。状态切换日跨界收益不归入段内表现；这是历史区间描述口径，不是买入卖出回测。

均值、上涨日比例和收益分布按有效收益观察值汇总，权重为每个观察值等权。状态年化波动率按有效段内收益的样本标准差乘 \(\sqrt{252}\)，不足两个收益观察值返回空。偏度、峰度、箱图、QQ 沿用各自样本门槛。

每段累计收益与最大回撤按该连续段真实路径独立计算；单点无收益，路径缺失时返回不可用原因。状态层只展示合格片段收益/回撤的中位数、最差值与合格片段数，不展示拼接后的“状态最大回撤”或伪造连续净值。

短片段仍保留在明细和样本披露中，不通过前端合并改变已发布定义。完整但很短的片段允许展示实际区间收益/回撤，并用观察数提示解释边界，不输出短段年化收益或夏普率。不同长度片段的区间收益同时配合长度散点解释。

恢复时间需要沿真实后续路径追踪且处理未恢复事件，本次不将区间结束误标为恢复。自定义路径指标继续保留完整时间轴计算，结果卡明确其各自窗口。

### 条件未来模拟

- 普通分析请求 `include_simulation=false`；只有运行按钮提交 `true`。
- 至少 20 个有效收益观察值。选择单段后不足门槛应阻止模拟并解释原因，不能退回全样本。
- 选择状态时假设未来整个模拟期持续该状态；选择单段时使用该段作为历史样本。未选择状态时使用完整窗口。统一起始虚拟净值为 1。
- 参数化模型保留均值、波动、偏度、超额峰度的四矩校准，并展示匹配、近似或正态安全降级状态，不能隐瞒校准退化。
- 区块 Bootstrap 保留段内时序；遇片段结尾、缺失值或原始序列末尾必须重新随机抽块，禁止从末尾循环连接到起点或从一个片段继续走进另一个片段。名义区块长度与实际被边界截短的情况须说明。
- 边界重抽不能直接均匀选择起点，否则会过度抽取片段后部。设继续概率为 `1-q`、`q=1/L`，首次起点均匀；此后的重启起点权重为连续有效块首 `1`、其他位置 `q`，归一化后通过 CDF 二分抽样。它补足每个位置从前驱收到的概率差额，使每一期历史观察值的边际权重保持均匀。测试包含多期正负对称片段、不等长片段与缺口，不能只测试单点碎片。
- 模拟一个历史收益观察值对应未来一个交易日，是明确的日频建模约定。基金缺少产品对应日历时，不声称净值观察必然是严格日频；按净值所属日期研究也不等于按公告日期还原当时可得信息。
- 随机种子绑定产品、研究条件、参数、运行轮次；同输入同轮次可复现。
- 两模型使用相同研究样本，保留模型差异提示。模拟是给定样本与假设下的分布，不能解释为经过校准的真实未来发生概率。

## 5. 前后端接口

复用 `POST /api/instruments/products/{product_id}/analysis?kind=etf|fund`，不另建平行分析入口。


保留原统计、技术与模拟参数。移除被取代的粗粒度 `regimeStatistics`，由以下结构统一表达：

状态汇总包括观察数、收益数、片段数、片段长度中位数、合格片段数、平均日收益、年化波动、上涨日比例、片段收益中位数/最差值、片段回撤中位数/最差值。区间明细包括稳定 ID、状态、日期、观察数、有效观察数、收益数、累计收益、最大回撤、状态、原因与窗口截断标识。

情景表现的收益/波动/回撤为小数比率；原顶层日收益与 `returnStatistics` 的收益值继续使用百分数。展示层按显式类型/字段格式化，不按名称猜单位。完整发布 lineage 由原 `regimeReference` 返回。

`startDate/endDate` 表示当前选中样本的覆盖范围；`windowStartDate/windowEndDate` 表示统一研究窗口。多段样本的日期包络不代表连续持有路径。区间状态枚举为 `complete / insufficient_sample / missing_data`。切换研究窗口或收益口径时清空单段选择，避免新口径覆盖不足导致下拉选项与实际请求不一致。

## 6. 运行与前端状态管理

服务器只做验证、真实数据读取、日期和数组转换、编排及结果封装；样本掩码、片段统计、分位数、收益聚合、模拟均使用固定签名 NJIT。新增内核纳入现有启动预热与执行审计，禁止请求时新签名编译或 Python 回退。替换旧计算时更新所有实际调用和测试，不保留旧实现副本。

前端将普通分析结果与显式模拟结果分开管理。研究版本、状态、单段、周期、口径、产品及模拟参数变化时，取消在途模拟并立即清空旧结果。异步响应必须绑定发起时的上下文，晚到响应不能覆盖新选择。切换标签页不触发模拟。数据错误只影响对应工作区，基础资料和可用行情仍可查看。

1. 原产品资料、导航返回来源、自定义指标与时序、技术叠加、统计图、双模型结果保留。

5. Bootstrap 不连续跨越片段或缺口，固定输入/轮次确定，新增内核实际经过固定签名执行，审计无 fallback、无请求编译。
6. 初次进入、切换状态、改参数均不自动模拟；点击运行才请求，条件变化清除旧结果，过期请求不会复活结果。

## 8. 研究依据与范围

产品研究应解释不同市场环境下的行为，并结合回撤、风险暴露及定性信息；情景结果是研究证据的一部分。[CFA Institute，Investment Manager Selection](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/investment-manager-selection)

回撤依赖连续收益路径及其序列相关性，因此状态片段的拼接或重排会改变回撤含义。[Goldberg 与 Mahmoud，On a Convex Measure of Drawdown Risk](https://arxiv.org/pdf/1404.7493)

本次交付集中在单产品页。SAA/TAA 权重求解、自动交易、持仓重估压力测试、状态转移预测、任意自定义指标的条件化批处理不混入本次实现。发布中心已有版本治理继续复用。
