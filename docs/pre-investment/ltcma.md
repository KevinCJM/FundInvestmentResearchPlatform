# LTCMA：长期资本市场假设

本主题负责长期收益、资产风险、均值估计不确定性及版本生命周期，不决定投资授权或最终权重。业务入口见[投前研究](README.md)，组合消费见[SAA](saa.md)。

下文保留专业模型契约；方法可用范围以能力接口为准。当前原始代理读取以 CNY／SSE 日频为边界。跨币种、跨频率、不同 vintage 自动融合及原生多年状态路径未实现。
## 业务边界

`资产范围／代理 → LTCMA → 冻结 CmaVersion → Mandate + CMA → SAA`。

LTCMA 回答各大类的预期收益、实现风险及估计不确定性，不选择投资目标、不分配组合权重、不重新定义 C1–C5。创建 LTCMA 不需要 Mandate 或实施产品映射。LTCMA 只输出明确口径的年化收益与风险，不再设置预测期限；历史估计窗口仍决定实际取样。资金目标及现金流的投资期限由 Mandate 定义。

旧 CMA/API 的来源、数值和时点语义保持不变。新中心创建的版本显式标记新契约，不能把历史版本改标签后冒充新结果。产品代理变化会改变依赖该代理的 CMA；与研究代理无关的实施产品变化不应改变新 CMA。

## 前端：先列表，后研究

正式入口：`/pre-investment/ltcma`，名称“LTCMA 中心”。标题下常驻两段中英文说明：LTCMA 为长期配置提供收益、波动率和相关性的前瞻假设；历史样本未必适用于未来环境，均值方差优化可能放大参数估计误差。说明机构通常结合历史数据、当前估值与宏观判断，并关注估计不确定性，不承诺消除预测误差。仅符合条件的假设可供 SAA 使用，组合权重仍由 SAA 决定。

概念核实（2026-09-22）：CMA 是资本市场假设的统称，LTCMA 强调长期投资视角，不是某一种固定算法。[摩根资产管理方法手册](https://am.jpmorgan.com/content/dam/jpm-am-aem/global/en/insights/portfolio-insights/ltcma/noindex/ltcma-methodology-handbook.pdf)将历史作为参考，并结合估值及经济判断形成前瞻假设；[CFA 资产配置原则](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/principles-asset-allocation)明确指出均值方差优化对输入变化敏感；[BlackRock CMA 方法](https://www.blackrock.com/institutions/en-global/institutional-insights/thought-leadership/capital-market-assumptions)另外考虑预期收益估计本身的不确定性。因此，不能将 LTCMA 理解为“替代历史数据、自动解决优化误差”的工具。这里介绍的是方法逻辑，不表示本中心每种生成方法都已接入估值和宏观模型；历史统计仍是样本估计，保存为 CMA 不自动增加前瞻证据，具体资格遵循各方法契约。

每份 LTCMA 只绑定一个资产范围，范围内可包含多个大类；真实大类方案与独立战略范围二选一。

列表显示名称、生成方法、研究日、状态，不重复展示资产范围列，范围仍可在详情中核对。历史统计等有历史样本的方法只附加取样窗口，如“历史统计 · 近 2 年”；列表不展示实际取样日期、日收益样本数或指数／产品来源明细。窗口来自已保存版本，不读取最新行情、不重新计算或改写历史，完整证据仍保留在研究记录中。支持筛选、查看；操作列提供“修改”“复制为新研究”“删除”。名称在当前、仍可引用的方案之间唯一（忽略首尾空白与大小写）。修改可以沿用本方案名称；复制为新研究须使用不同名称。停止引用的方案释放其名称。已有研究不会自动采用修改后的结果。

- **修改**：带入原方案参数，重新预览并点击“保存修改”，更新原方案在列表中的条目，不增加独立方案。内部以 `study_id` 保留方案身份，用 `supersedes_cma_id/hash` 关联替换前的冻结结果；原结果及其 SAA／TAA 引用保持可读，不回写数值或自动换引用。
- **复制为新研究**：沿用输入，新建独立方案，仅记录 `copied_from_id`，不替换来源方案。
- **删除**：确认框先说明影响，复用现有退役接口及内容指纹校验。成功后从默认列表移除、停止新引用，并移除本页已选项；已有 SAA／TAA 等研究及历史记录保留，勾选“显示已停止引用的版本”仍可查看。退役行不允许重复删除或保存修改，仍可查看或复制为新研究。失败时确认框保留原因并允许重试；删除当前页最后一项时返回上一页。
- 草稿沿用原有删除能力；已确认版本不物理删除。
- **按目标与范围分组（2026-09-23）**：列表按「投资目标与约束版本 + 研究路径 + 研究范围版本」分组，组头显示目标、路径（Strategy first／Product first）与范围，名称均可点击进入查看页，并标注钉住的版本号及"已有新版本 vN"。同组版本排在一起，组按首次出现顺序、组内保持原顺序，排序在后端分页前完成。列表项的 `version`、`upstream`、`usable` 按[版本与依赖管理](versioning.md)统一派生。
- **上游删除或改版（2026-09-23）**：所用范围或其绑定目标被删除时，LTCMA 视同停止引用（`usable.status = blocked`，计算入口返回 `CMA_UPSTREAM_DELETED`），不另写退役记录。LTCMA 自身已被新版本替代，或其目标、范围已有实质新版本时为"需更新"（`stale`），可查看、修改、复制，但不能进入 SAA 或作为先验（`CMA_NOT_CURRENT`）。范围只改说明、配置指纹不变的改版视为等价，不影响可用性。

### 从中心选择 CMA 进入 SAA

中心列表为正式交接入口，沿用「研究范围 → LTCMA → SAA」顺序，不自动生成、确认或重算 CMA。

| 操作／状态 | 页面行为 |
| --- | --- |
| 尚未选择 | 底部显示「已选 0 个 CMA」及勾选提示，「下一步：战略资产配置」禁用 |
| 单选已确认版本 | 带入该版本、研究范围和范围已绑定的投资目标，进入 SAA 政策比较 |
| 多选（最多 20 个） | 保留完整版本集合，进入 SAA 先明确选择「加权融合」或「共同约束」；不自动取平均、不默认模型权重 |
| 加权融合 | 沿用现有参数平均模型；用户填写权重，或点击「确认使用等权」，合计 100% 才能继续 |
| 共同约束 | 沿用现有逐模型门禁，不填写模型权重；同一配置须在每个所选模型下通过目标与约束 |
| 筛选／翻页／无搜索结果 | 保留已选项，底部仍可逐项移除或清空；选择区重复方法及窗口，区分同名方案 |
| 不可同时选择 | 只有同一投资目标与约束、同一研究路径与范围版本的 LTCMA 才能一起选择，否则提示“只能一起选择同一投资目标与约束、同一研究路径与范围下的 LTCMA”；同组内仍按研究日、币种、收益口径或有序资产逐项说明原因；旧版本只可单独使用，多选需复制确认 |
| 退役／未来版本／PIT 未加载 | 显示原因并禁止新选择；点击下一步重新核对退役状态与内容，失败保留选择并允许重试 |
| 未绑定投资目标的旧范围 | 保留 CMA 和范围，只提示在 SAA 补选目标；不从浏览器上次研究推断绑定关系 |

交接仅做只读核验：读取冻结版本和目录；战略路径采用范围的持久化目标绑定，产品路径读取范围快照的绑定。范围编辑后，当前目录只列新版；已确认 CMA 仍使用原范围 ID，交接及 SAA 刷新时按该 ID 补读原版，并在交接时核对 CMA 冻结的范围指纹。不能将“不在当前目录”判为不可用，也不能按同名自动改用新版。自 2026-09-23 起，多选要求目标、路径与范围记录 ID 均相同，且每份均为可用（`ready`）；配置事实相同但范围记录 ID 不同（例如范围只改说明前后的两个版本）的 CMA 分属两组，不能同时选择，但各自仍可单独使用。交接仍逐份读取原范围并核对各自记录 hash。原版读取失败时保留选择并允许重试；绑定目标失效仍须处理。新 CMA 不自动选择实施产品映射；原冻结版本已有的映射身份可原样带入。

URL 用重复的 `cma` 参数传完整版本集合。SAA 草稿按明确的范围、目标、映射和 CMA 集合隔离，刷新可恢复已明确选择的使用方式和权重；流程书签保留完整集合，换范围或目标时清除旧引用。请求使用取消信号与代次保护；移除、清空或切换 PIT 后，旧响应不能触发跳转。未选择多 CMA 使用方式时禁止进入政策比较。

入口校验用于即时反馈；深层冻结来源、代理一致性、数值资格及计算预算仍由现有 SAA 后端在比较时核验。本次交接不改变参数平均、共同约束或单 CMA 的算法和发布契约。

编辑页两个步骤：

1. **研究输入**：主区先展示名称，然后是资产范围、生成方法与研究日，再按方法展示所需数值。名称由研究员自定义，留空时按范围、方法和研究日自动生成；与其他当前且仍可引用的 LTCMA 重名时，输入步骤就地报错并禁用“计算预览”，保存时后端再次强制唯一（`CMA_NAME_CONFLICT`）。通用备注及每类依据仍在选填折叠区。币种及战略资产分类沿用已保存范围；产品路径的币种例外与未确定分类仍可明确设置。历史窗口决定统计样本长度。
2. **结果与确认**：资产收益／波动表、相关矩阵、数据覆盖与限制；高级详情包含原始参数、模型血缘、均值协方差和执行信息。先预览，确认限制后发布，发布成功提供“用于 SAA”。

生成方法选择区下方仅用一段话概括当前方法的必要操作、计算目的与关键限制，切换后即时更新；尚未选择资产范围时也可阅读。全部八种方法的下拉选项旁均有问号，展开面向量化研究者的通俗说明，集中展示必要输入、计算逻辑、数值例子与结果口径。浮窗最大宽度 56rem，窄屏限制在视口内；支持悬停、键盘和触控阅读，同一时刻只打开一份说明，查看不选择方法、不触发计算。摘要与详细说明采用中英文词条，摘要与选择控件建立无障碍关联。“历史情景”（`historical_regime_occupancy`，原界面名“历史状态”）、自动长期情景及条件情景分别说明，明确均值估计误差与资产风险的区别，以及条件情景暂不能用于 SAA 的限制。方法更名只影响显示，计算及已保存版本保持不变。

“历史情景”的详细浮窗说明通用步骤：按情景划分历史日期 → 在共同日期统计各类资产的收益、波动与相互关系 → 按情景占比合成并年化。说明默认占比来自有效样本的时间比例，总风险包含情景内波动和情景间收益差异；无需实时识别、不预测情景发生时间，沿用历史占比时可能接近同样本的普通历史统计。下方摘要只保留选择与合成逻辑；浮窗不绑定某个指数或某种情景名称。

第 02 步战略范围可预先配置研究代理与现金收益。该步不再手填配置用途和变现能力；现金分类由资产类型生成并随范围冻结，LTCMA 承接后仍校验与冻结分类一致。选择该范围后，新 LTCMA 草稿承接代理、权重、再平衡和现金输入；人工模式预填纯现金收益、零波动与零协方差，统计模式沿用共享参考资产计算链。用户可在 LTCMA 调整研究输入，原范围不回写；旧范围未配置代理时仍由本页补充。保存范围不证明数据可用或 PIT 合格，也不产生实际投资产品映射。

主要交互：
- Manual 填收益、波动和相关性；产品路径可明确读取历史风险，人工覆盖后解除旧来源认证。通用依据与各资产说明均为选填，不伪造来源文字来通过校验。
- Historical 选择 1/2/3/5/10 年、共同起点或自定义窗口；收缩参数放高级设置。
- BL 复用现有绝对／相对观点编辑器，不重写其数值算法；风险、基准与无风险收益须有明确来源，缺失不猜值。
- Bayesian 选择先验版本、证据窗口及等效样本强度；不隐藏先验强度常数，不把“强”解释为置信概率。
- Scenario 保留人工情景，增加历史状态来源；原占用率和应用概率分开，修改需说明理由。

字段处理原则：
- PIT 开启时研究日自动跟随当前平台研究日并锁定；仅明确关闭 PIT 时可以手填，PIT 未加载或读取失败时阻止计算和草稿保存。打开旧草稿或复制历史版本会将新研究对齐当前 PIT，不修改原版本；日期变化同步模型及代理日期，清除风险参考认证、口径确认和旧预览。
- 名称、通用研究说明及资产分类说明不参与收益矩计算。LTCMA 2.0 的通用说明允许空字符串；1.0 仍要求原来源和分类说明。模型公共说明可为空，但 BL 基准来源、具体观点来源及其观察／可得日期、情景依据和概率覆盖理由保留原校验。
- 战略范围中的资产名称用于显示，内部资产轴保持不变；已冻结的角色及流动性继续传入并校验，不重复要求用户选择。产品路径缺失分类时仍须填写，因为下游现金资格依赖这些字段。
- 不参与计算的预测期限标签已取消：新请求、草稿、列表及结果摘要不保存或显示旧 `horizon_years` 字段。NIW 先验、单／多 CMA 的 SAA 消费不再按旧期限标签拦截，仍校验资产定义、研究日、币种及收益／风险等实际口径。旧请求中的 `horizon_years` 在输入边界丢弃；已冻结版本及其 hash 原样读取，不批量改写。条件情景的 `horizon_days` 是例外：它实际进入转移与复利递推，不能取消或与旧标签混用。样本诊断保留观察年数和短窗口提示，旧诊断只读兼容。
- 完整研究代理默认收起，可展开检查和修改；缺失代理或权重不完整时自动展开。展开后与 02、08 共用 `risk-scales/CategoryEditor`：一行一个大类，代理成分与权重收在该行的展开区，行内显示状态徽章与代理摘要；大类本身由战略范围冻结（`fixedAssets`），名称只读、不能增删，只有流动性大类可切成现金（`cashEligibleIds`），代理仍可自由增删改权重。手工风险、均值不确定性、费用和汇率口径仍可设置；空数值不自动填零，缺失原因在计算按钮附近显示。

统一使用现有 UI 原语、数值输入、设计令牌与中英文词条。字段有可见标签；负数、空值和未完成输入不自动变零。加载、空态、错误、禁用及过期状态完整。窄屏按区域排版，宽矩阵仅在自身区域横向滚动，不缩小字号。数据和风险提示旁不放吉祥物；例外有两处：提交计算时的整块等待区——只在输入步骤（屏幕上只有表单控件、尚无预览结果）居中出现行走姿势加一行说明，切到结果步骤后等待提示只保留纯文字；以及整块读取失败态——目录或版本没读出来、屏幕上没有业务数值时，用共用的 `ErrorPanel` 居中给出带问号的形象、失败原因和重试，保存、停用这类操作失败仍只用纯文字。

切换资产、日期、模型、输入或知识截止日均使未确认预览失效；用 AbortController 与请求代次忽略旧响应。冻结历史版本可读取，不因打开页面重新取市场数据／训练模型。

## 数据和五类模型

### 共同证据

优先复用产品大类读取器与 `ReferenceSources`。指数／产品用真实类型，不伪装 ETF。用有来源的代理绑定对齐战略资产轴；不能凭同名大类匹配。

日频统计按各来源共同可得、且对每条来源都相邻的单日收益计算：来源交易日历不同（如境外指数与 A 股指数）时只在共同交易日对齐，跨过缺口的那一段整段排除，不生成跨日的“单日收益”。共同样本可能短于所选窗口，实际区间与被排除的收益期数随样本一并返回；窗口本身不自动改写。所有来源都没有数据的 SSE 开放日属于缺数据而不是日历差异，仍然阻断。不填零、不按剩余成分重新归一化。数据可得时点必须不晚于研究日。默认共同样本；共享缓存限本请求，底层输入只读。

当前原始代理读取能力以 CNY/SSE 日频为边界；未实现的币种转换、完整跨市场日历及频率切换明确拒绝，不静默换算法。纯人工同币种前瞻输入沿用旧合法路径。

### Historical

共享样本均值与 `ddof=1` 协方差；可选显式对角收缩。独立增量近似下年化均值／资产协方差乘 a；均值标准误乘 a。原风险参考的固定收缩不改名为 Ledoit–Wolf。输出历史统计基线及样本不足／周期不足提示。

### Manual、BL 和人工 Scenario

沿用已有计算真相，不重新实现 BL 更新或情景混合。Manual 风险读取属于显式来源操作，自动值与人工覆盖分别留痕。BL 的后验均值协方差不作为资产风险；基准权重不是实施产品权重；无观点恢复 rf+先验溢价。

人工 Scenario 的同期间混合包含 within 与 between 项；没有明确概率则不混合。其单期矩不自动生成多年状态切换或尾部预测。

### Bayesian NIW

先验选择按资产配置事实匹配，不以战略范围记录 ID 不同直接排除。相同的有序资产、币种、经济角色、流动性和研究代理可以跨保存记录复用；名称、备注、创建时间不影响兼容性。实际统计代理另按来源／字段、权重、再平衡及现金收益核对。收益矩、费用与汇率口径、先验日期、退役和模型用途仍独立检查。未明确一致的旧人工费用／汇率口径不能自动解释为当前统计口径。

选择器显示方法和窗口以区分同名研究；不适用项保留禁用状态，并可展开查看具体差异。研究选项目录返回全部当前先验候选（含退役项的禁用状态），并补回草稿中明确绑定的历史先验，不以列表分页上限静默截断。只有从未存在已确认研究时才提示先创建；已有但不匹配时提示实际原因。修改当前代理后所选先验失效，计算按钮即时阻断；服务端计算与发布仍重新核验。配置事实指纹由后端规范化业务字段生成，与整份记录的完整性 hash 分开；旧记录读取时派生，不迁移或重写历史。详细字段与验收见[配置事实设计](../research/cma-model-decisions.md#按配置事实复用-ltcma2026-09-22)。

使用同频先验和同频样本的解析后验；保存 kappa、nu、Psi 和样本截止。资产协方差乘 a，均值后验协方差乘 a²。先验来源、等效样本强度和数据重叠明确核验。先验续更仅用新增证据；跨频率不沿用旧信息量。现有 NIW 核要求先验协方差正定；含零波动固定现金的奇异矩阵仍不能直接作为该模型的完整先验，配置匹配成功不消除此数值限制，系统不自动添加扰动。可信半宽用 t 尺度及相应自由度，不把 t 的尺度当协方差，不统一用 1.96 代替。

### Historical Regime

读取冻结 run，不重新执行识别。用同一状态轴切分所有资产的合法收益，记录收益归属规则、未知状态与样本覆盖。默认共同样本时间占用率；基础期条件矩先混合再年化。原样 ML 混合应还原全样本 ML 矩；不把分组重构冒充新增预测。无样本的正概率状态、未来信息或非法状态阻止发布。

## SAA 衔接

SAA 保留政策比较和采纳流程，仅把“编辑长期假设”替换成“选择已确认 LTCMA”。选择器按资产配置事实、币种、研究日和退役状态解释兼容性；缺失版本保持不可用，不自动换成最新版。

新建／复制 LTCMA 从 SAA 跳转时只携带可验证引用；返回时加载精确 ID。Mandate 不反向决定模型参数。SAA 继续执行实际目标、现金及风险校验。多 CMA 的组合消费由 SAA 负责，见其独立契约。

## 共同数理口径

下列收益、时间轴、年化和风险语义是各模型共同遵守的约束；增加新字段不能通过重标历史 artifact 伪造新口径。
## 资产轴与维度

用 N 表示大类数量，T 表示观测数，M 表示 CMA 模型数，S 表示情景数，a 表示每年观测期数。

\[
R\in\mathbb R^{T\times N},\quad \mu\in\mathbb R^N,\quad \Sigma\in\mathbb R^{N\times N}.
\]

M 套 CMA 在内部可暂存为 `means[M,N]`、`covariances[M,N,N]`；传统单模型优化器仍接受一个向量与一个二维矩阵。三维数组只是多模型批量容器，不是额外的一阶／二阶统计量。

均值是一阶矩；方差和协方差都是二阶中心矩；偏度涉及三阶矩。不能把协方差称为三阶矩。

资产 ID、经济定义和 Proxy 版本共同确定暴露含义。同名但不同大类定义不得自动对齐。顺序变化应显式排列并记录，缺资产不能补零。

## 四种收益概念不得混用

| 名称 | 定义／用途 |
|---|---|
| 单观测期简单收益 | `r_t = NAV_t / NAV_(t-1) - 1`，历史统计的原始单位 |
| 年化算术参数 | `mu_a = a * mean(r_t)`，`Sigma_a = a * Cov(r_t)`；协方差换算依赖独立增量近似 |
| 一年复合后的简单收益随机变量 | `R_1Y = product(1+r_t)-1`；其期望和方差不一般等于上一行 |
| 资金所需年有效收益／CAGR | 常数复利增长率，满足现金流与期末目标；不是市场预期均值 |

保留当前 `return_basis = annual_arithmetic_total_return` 的历史字段。新版本同时增加：

```text
observation_frequency
periods_per_year
moment_period
moment_semantics: annualized_periodic_arithmetic | one_year_simple
annualization_method
fee_basis
currency
fx_hedging_basis
covariance_role: asset_return | predictive
included_uncertainty_components: [] | [mean_estimation] | [model_state_variation] | [...]
```

五类方法在新建研究中默认采用明确的年化算术参数出口；若输入是实际一年简单收益矩，则标识为 `one_year_simple`。跨语义融合必须先通过明确、已验证的适配，不能只因都有“年化”二字而直接相加。

历史 artifact 的既有口径保持原状；无法确定其细分语义时允许只读，新的跨方法融合须重新确认来源／创建新版本，不回写旧记录。

## 协方差与年化

若基础期收益在时间上独立且使用加法累计近似：

\[
\mu_a=a\mu_p,\qquad \Sigma_a=a\Sigma_p.
\tag{U1}
\]

若存在自相关，加法收益的 a 期协方差为：

\[
\operatorname{Cov}\!\left(\sum_{t=1}^{a}r_t\right)
=a\Gamma_0+\sum_{h=1}^{a-1}(a-h)(\Gamma_h+\Gamma_h^\top).
\tag{U2}
\]

因此“日频风险乘 252”是有假设的近似，不是对所有市场状态或产品都成立的恒等式。基础版保留简单年化，但必须记录局限；长期情景路径另由分布适配器处理。

样本协方差默认统一 `ddof=1`；状态经验分布重构允许 `ddof=0`，须显式记录。收缩矩阵不是原始样本无偏协方差。

## 数据时间与 PIT

分别保存：观测日期、源数据可得时间、模型训练截止、状态确认所需信息截止、研究 as_of、实际计算时间、发布时间。

正式历史时点研究要求其信息集合不超过 as_of。今天重算一个历史 as_of 的研究可以，但必须证明数据、模型选择与状态划分都只用当时信息；不能仅截去曲线后半段。

历史数据缺少可靠 availability 时可做 `retrospective_research`，明确“历史可得性未验证”；不能自动获得正式 PIT 资格。没有时点证据不是零延迟证据。

严格共同收益轴应先从合法相邻 NAV 构造收益，再按共同日期取样；不能删掉中间日期后，把跨数日收益当作一天收益。月／周聚合必须记录端点、有效间隔与日历。

## 统一风险函数与测量边界

对于第 m 套 CMA：

\[
\mu_m(w)=w^\top\mu_m,\qquad
\sigma_m(w)=\sqrt{w^\top\Sigma_mw}.
\tag{U3}
\]

相对基准 b 的主动风险：

\[
TE_m(w,b)=\sqrt{(w-b)^\top\Sigma_m(w-b)}.
\tag{U4}
\]

投资授权基准的 TE 与 TAA 相对 SAA 的 TE 是两个约束，不能共用名称而覆盖彼此。

同一数值波动上限跨模型比较，须满足币种、收益单位和风险时间尺度一致；结果仍是“在该模型下的估计风险”。风险标尺不是所有模型天然等价的证明。

## 产品代理与指数代理

两种模式均输出 AssetClassVersion、ProxyBindingVersion 和收益面板。

| 项目 | 产品代理 | 指数代理 |
|---|---|---|
| 来源范围 | 已冻结、可追溯的产品池 | 有明确数据权限和口径的指数库 |
| 代理成分 | 单产品或多个 ETF／基金 | 单指数或复合指数 |
| 构建操作 | 手动或自动分类、类内权重 | 手动组合或对指数集合自动分组 |

产品池中的产品数量不决定战略预算。分类是分类，不用 SAA 的最优权重反过来改写类别定义。

## 手动与自动分类的边界

保留当前 rule、hierarchical、k-medoids、k-means、spectral、GMM，以及 correlation、去噪相关、metrics、PCA、blend 等能力。统计相似性用于辅助分组；合同分类／经济暴露约束作为独立、可选择且可见的规则。

指数模式复用同一特征和分类框架，但需要独立的指数类型、成分范围、总收益口径适配，不通过把指数代码伪装成 ETF 进入现有产品接口。

自动分组结果须明确成分归属、代表代理、类内权重、未分配项目及原因；与上游固定产品池／指数集合版本绑定。分类规则、权重算法改变须新建版本。

## 代理收益与权重时点

统一公式：

\[
r_{class,t}=\sum_i h_{i,t-1}r_{i,t},\qquad
NAV_{class,t}=NAV_{class,t-1}(1+r_{class,t}).
\tag{P1}
\]

若每期使用固定目标权重，这是“每个观测期再平衡的合成代理”，不是买入后不动的组合。若是买入持有：

\[
h_{i,t}=\frac{h_{i,t-1}(1+r_{i,t})}{1+r_{class,t}}.
\tag{P2}
\]

月度／季度再平衡则在指定时点重设目标，其余时间漂移。绑定中必须保存 rebalancing rule、权重可得日、费用、初始净值和日历；不能把今天挑出的优秀产品回填到历史，宣称当时已知道。

现有 `fit.py` 使用固定类内权重形成加权收益；其容错路径可能略过未映射成分并归一化。新正式 Proxy 发布须对所有请求成分覆盖做独立门禁，不能把既有函数存在当作“无缺失、无隐式范围变化”的证明。原历史调用行为不能在本次文档任务中直接修改。

## 收益、币种、费用与缺失

优先使用可验证总收益／复权净值。价格指数、全收益指数、基金净值不互相冒充。外币未对冲转换满足：

\[
1+r^{base}_t=(1+r^{local}_t)(1+r^{FX}_t),
\tag{P3}
\]

FX 报价方向、时点、对冲规则必须冻结；无 FX 数据则不能声称自动完成同币种转换。

产品 NAV 已扣管理费时，不在代理和资金模型中重复扣相同费用；实施交易成本、顾问费等另行明确。异常跳点默认阻断或展示，不默认 winsorize 掩盖真实损失；高级清洗须保留原值与规则。

“共同成立以来”指共同可用收益起点，不是让每个资产用不同样本长度后直接拼矩阵。产品缺失不能用其他产品静默替换，复合指数也不得对剩余成分自动再归一化。

## 窗口解析

提供 `1Y / 2Y / 3Y / 5Y / 10Y / common_since_inception / custom`。

相对窗口以研究 as_of 为锚，结束于该时点实际可得的最后完整观测；显示请求区间和实际区间。近一年是日历回溯，不自动等于“最近 252 条”；高级观察数窗口与日历窗口是两种不同参数。

不得静默缩短用户指定的区间。无法覆盖时提供：调整窗口、修改代理、明确接受缩短并形成新请求。月频最后一个不完整月份不进入完整月度统计。

代理取交集前，逐一核对来源的首末观测是否覆盖请求窗口的边界（已知 SSE 休市按现有日历处理）；头尾数据不足返回 `LTCMA_PROXY_WINDOW_COVERAGE`，列出来源及可读区间，不以交集内仍有足够样本为由自动截短。跨市场区间内仍按共同相邻收益期计算。未接入来源自身的完整交易日历时，不能把边界缺失猜成海外休市；可明确调整窗口后重试。`common_since_inception` 仍以各来源共同可用起点开始，结束日不自动提前。

NIW 先验菜单同步检查服务端 `usable`：`stale` 解释需更新的先验／上游，`blocked` 解释停止引用，均不可选择；恢复的旧选择保留名称与原因，不能继续计算。后端继续独立复核。

同一 CMA 的均值和协方差默认取同一共同有效样本。不同模型可以采用不同历史窗口，这正是模型比较的一部分，但模型内部不得无提示地混用样本。

## 内置估计器

\[
\bar r=\frac1T\sum_{t=1}^T r_t,\qquad
S=\frac1{T-1}\sum_{t=1}^T(r_t-\bar r)(r_t-\bar r)^\top.
\tag{H1}
\]

可选择原始样本协方差或对角目标收缩：

\[
S_\lambda=(1-\lambda)S+\lambda\operatorname{diag}(S),\quad0\le\lambda\le1.
\tag{H2}
\]

再按 U1 转到年化算术参数。当前实现的 lambda 是固定配置值，不是自动估计的 Ledoit–Wolf 系数。未来加入自动收缩时必须独立注册目标矩阵、强度估计公式与测试，不能改名字就声称已实现。[R1]

数学最低要求 T>1；生产样本门槛由版本化数据质量策略给出。当前风险参考最低 20 条仅是技术门槛，不等于长期估计可靠。T 不大于 N 时原始样本矩阵可能秩不足；PSD 允许秩不足不代表估计稳定，需显式选择收缩／先验或停止要求正定的模型。

## 误差与异常提示

在独立同分布假设下，基础期均值标准误约为 `sqrt(S_ii/T)`；其年化值乘 a，而不是乘 sqrt(a)。存在自相关时该公式仅作 iid 参考，应使用有明确口径的 HAC／区块重采样扩展，或标记未校准。

样本均值与协方差来自同一历史数据不意味着估计难度一样，也不意味着样本均值天然“有偏”。应区分抽样误差、非平稳与结构性偏差，不能用笼统的“不准”禁止历史方法。[R1]

1Y／2Y 可以使用，但显示周期覆盖不足、均值不稳定与最近状态敏感提示；不自动把短期样本称为 LTCMA 的最佳长期中枢。

输出 `forecast_semantics=historical_sample_baseline`。只有用户明确选择本方法时，历史均值才成为该 CMA 的有效预期输入；其他方法不被后台默认替换成它。

## Manual CMA：手动收益，默认自动风险

用户选择资产版本、日期、币种后，系统加载 Proxy 风险参考：

\[
\Sigma=D\,Corr\,D,\qquad D=\operatorname{diag}(\sigma_1,\ldots,\sigma_N).
\tag{M1}
\]

默认只填写各大类年化算术预期收益、判断依据与必要治理字段；不要求用户手工维护 N×N 矩阵。提供查看风险矩阵与高级覆盖入口。

风险来源优先顺序是用户已选且可用的冻结风险版本、当前明确请求的历史估计、显式导入。不是系统静默选择一个“最好看”的窗口。

没有 Proxy 历史数据时，允许显式外部／人工风险输入并清楚标记；不能用单位矩阵或零相关冒充自动估计。当前指数来源历史风险受现有 CmaRequest 约束限制，自动风险接入需要真实接口改造，不只是前端回填。

保留高级波动率、相关性或完整协方差覆盖；覆盖后重新验证 PSD 与来源。手动收益不需要伪装成统计显著性，缺少可估计不确定性时明示。

## 模型与使用条件

这里是一般贝叶斯参数估计，不是朴素贝叶斯分类。基础模型使用同频率多元正态似然和 Normal–Inverse-Wishart 共轭先验；可解析更新，不需要默认 MCMC。[R4]

在基础观测频率中：

\[
r_t\mid\mu_p,\Sigma_p\sim N(\mu_p,\Sigma_p),\quad
\Sigma_p\sim IW(\Psi_0,\nu_0),\quad
\mu_p\mid\Sigma_p\sim N(\mu_0,\Sigma_p/\kappa_0).
\tag{B1}
\]

要求 `kappa0>0`、`nu0>N+1`、Psi0 正定，才能按本文输出有限协方差期望。似然样本在该假设下条件独立；不把波动聚集自动当成已建模。

## 先验参数来源

| 参数 | 来源规则 |
|---|---|
| mu0 | 上一版已确认 CMA、显式人工长期锚、BL 先验或未来基本面／外部模型 |
| Sigma0 | 已确认风险矩、上一版 CMA 或不同证据窗口的历史风险 |
| kappa0 | 已版本化的均值先验信息量，不是 0–100% 置信概率 |
| nu0 | 风险先验信息量，使用 `nu0=N+1+n0_cov` 表达 |
| Psi0 | `n0_cov * Sigma0`，保证先验风险期望为 Sigma0 |

当前界面提供先验版本、证据窗口、先验使用方式，以及显式填写的两个 **日频等效观察数** `kappa0 / n0_cov`，没有弱／中／强模板或自动校准默认值。若后续引入模板，必须说明证据依据并显示对应信息量。

填写强度前可点击“查看样本参考”。`POST /api/strategic-allocation/cma/sample` 只需要产品大类或战略范围（两者选一），以及 `StatisticalCmaContext` 的资产轴、研究日、历史窗口和研究代理；不需要先验版本、强度或已完成的 CMA。它复用正式预览的 `CmaEvidence.build_sample` 读取和校验数据，不估计模型、不保存研究版本。返回实际共同日收益观察数 T、请求和实际日期区间、日频/252 口径及源数据和收益面板哈希；共同净值日中相邻的一对产生 1 个日收益观察，跨过缺口的收益期不计入 T；返回值给出被排除的收益期数 `excluded_return_periods`；共同净值日数按 `T + excluded_return_periods + 1` 还原，不能在删去跨日收益后仍按 `T + 1` 显示。可得时点、全部来源都缺的交易日或窗口不足仍按原证据规则报错，不使用“年数 × 252”估算。

界面将均值强度与 T 比较，并显示旧均值权重 `kappa0 / (kappa0 + T)`；以 T/4、T、4T 对照 20%、50%、80%，仅帮助理解分量，不自动回填或推荐参数。风险强度只显示 `n0_cov / T` 倍数，不能当成波动率混合权重。范围、研究日、窗口或代理改变后清除旧参考并取消旧请求；修改强度无需重读。查询失败可以重试，计算预览仍重新验证当前数据、先验资格及重叠限制，样本查询成功不代表 NIW 可用。前端允许范围直接由后端 Pydantic 契约生成，非法上限值会提示并阻止计算预览。

三个参数旁直接说明用途，均值算例按需展开，中英文文案统一维护在 `locales/system.json`：

| 界面参数 | 当前计算含义与选择用途 |
| --- | --- |
| 先验使用方式 | “以冻结参数建立新先验”借用所选版本的收益和风险中心，由用户重新设定两种信息量；“续更已有 NIW 后验”继承同日频 NIW 的均值、Psi、kappa 和 nu，只接受原样本截止日后的数据，不再填写强度。 |
| 均值先验等效日观察数 | `kappa0` 决定旧收益判断在均值更新中的分量。相对本次 T 个日收益观察越大，更新后的均值越靠近先验；例如 kappa0=100、T=100 时，两者各占一半。 |
| 风险先验等效日观察数 | `n0_cov` 决定旧协方差中心的信息量，通过 `Psi0=n0_cov*Sigma0`、`nu0=N+1+n0_cov` 构造先验。它覆盖波动和资产联动；数值大不代表风险大，风险更新还包含新旧均值差异项，不能直接平均波动率。 |

两个强度均须大于 0、不超过 100000，可以不同；它们不是要读取的历史天数或正确率。证据窗口决定使用哪些数据，强度决定旧判断的权重。所选版本只有收益、风险中心时，无法据此唯一还原研究者对它们有多大把握，所以必须明确填写；续更则沿用已保存的信息量。没有通用最优值，应依据先验证据设定，并检查不同取值下结论是否稳定，不把示例值当成推荐参数。

界面算例：旧年化算术收益 6%，本次 100 个日观察的样本均值按同一 252 期口径年化为 10%；均值强度 100 时更新为 8%，300 时为 7%。这只是公式 B3 的算术例子，不是投资预测。风险参数不会直接进入 B3，但均值强度会通过 B4 的差异项影响风险，两者并非完全独立。界面同时提醒数据复用限制：重新建先验时若有重叠须确认，续更时勾选确认也不能放行重叠样本。方法依据为 [Murphy 的 NIW 解析更新，第 9 节](https://www.cs.ubc.ca/~murphyk/Papers/bayesGauss.pdf)；项目映射已按 `recenter_niw_prior`、`niw_update` 和 `statistical_result` 核对。

“24 个等效月”不是 24 条日观察；更不能仅把 kappa0 乘一个交易日数，就声称 NIW 先验在不同频率下完全等价。第一版采用 **先验拟合频率与似然频率一致** 的门禁。已有 NIW 后验续更锁定原频率；需要切换日／月频时，从已确认的长期中心参数按新频率重新建立先验版本，并显式选择该频率的强度模板。只转换收益矩的单位，不自动恢复原先验的信息量或分布。

若使用上一版 NIW 后验续更，新似然默认只包含上次样本截止后的新增证据。若需要衰减，使用明确 d∈(0,1]：

\[
\kappa_0=d\kappa_{old},\quad
n_{0,cov}=d(\nu_{old}-N-1),\quad
\Psi_0=n_{0,cov}E[\Sigma\mid D_{old}].
\tag{B2}
\]

这保留先验均值和风险中心，降低强度。d 的选择是版本化适应性策略，不是新事实。其他 CMA 没有 NIW 强度时必须提供先验构造模板，不能仅凭一个协方差还原不存在的后验分布。

先验和似然复用同一数据属于经验贝叶斯／数据复用，须标记并限制置信度解释；不宣称两份独立证据。若未来自动校准强度，用时间序列训练／验证划分优化预测得分，不使用最终测试集，也不在此运行成千上万次 SAA。

## 解析后验

令样本均值为 r_bar，离差和矩阵为 `A = sum((r-r_bar)(r-r_bar)')`，注意 A **不是除过 T−1 的样本协方差**。

\[
\kappa_T=\kappa_0+T,\quad \nu_T=\nu_0+T,
\quad\mu_T=\frac{\kappa_0\mu_0+T\bar r}{\kappa_T}.
\tag{B3}
\]

\[
\Psi_T=\Psi_0+A+\frac{\kappa_0T}{\kappa_T}(\bar r-\mu_0)(\bar r-\mu_0)^\top.
\tag{B4}
\]

\[
C_p=E[\Sigma_p\mid D]=\frac{\Psi_T}{\nu_T-N-1},\qquad
U_p=\operatorname{Var}(\mu_p\mid D)=\frac{C_p}{\kappa_T}.
\tag{B5}
\]

基础期后验预测协方差为 `C_p + U_p`。均值边际分布是自由度 `d_f=nu_T-N+1` 的 t 分布，尺度矩阵：

\[
T_\mu=\frac{\Psi_T}{\kappa_Td_f}.
\tag{B6}
\]

t 的尺度矩阵不等于协方差；`Cov(mu)=d_f/(d_f-2)*T_mu`。各资产边际可信半宽为 `t_quantile * sqrt(T_mu[ii])`；边际 95% 不是整个 N 维向量同时 95%。

## 年化输出与避免重复计量

采用年化算术参数时：

\[
\mu_a=a\mu_T,\quad \Sigma_a=aC_p,\quad U_a=a^2U_p.
\tag{B7}
\]

模型输出默认：`effective_returns=mu_a`、`effective_covariance=Sigma_a`、`posterior_mean_covariance=U_a`。

若未来 a 期中共享同一个未知均值，在条件独立、加法累计近似下，预测协方差是：

\[
\Sigma_{pred,a}=aC_p+a^2U_p,
\tag{B8}
\]

不是简单把单期预测协方差乘 a。复合收益预测还需[资金模型](funding.md)中的多期分布适配，不能由 B8 自动得到。

Bayesian 生成器计算一次解析后验，SAA 消费一套参数。后验抽样如用于分布检验，也不是每个 draw 都必须做优化。

## 第一版实现与失败条件

2026-09-18 第一版已实现 `bayesian_niw` 契约、固定签名 NIW 内核、数值 t 分位数及先验选择器，并核对了 SciPy 参考值。当前支持同日频下重新构造先验与后验续更；基础强度由用户明确输入，不伪造弱／中／强模板；尚未实现上述全部衰减策略或跨频率适配。

t 分位数属于数值实现要求：可在受控预计算表／已验证固定签名函数中求取，并记录误差与支持范围；不能默默用 1.96 代替所有自由度。

## 基础数学及先验含义

经典 BL 使用均衡收益作为中性起点，再结合观点；它属于贝叶斯方法家族，但不等于一般 NIW。[R5]

\[
\Pi=\delta\Sigma w_{ref},\qquad
\mu_{prior}=r_f\mathbf1+\Pi.
\tag{L1}
\]

这是风险资产超额收益均值方差反向优化的构造。若使用任意机构基准、含现金代理或其他实施约束，称为 `benchmark/reference-implied prior`；不声称由真实全球市场唯一识别。

存在满仓约束及活跃上下界时，反向最优条件还包含约束乘子。给定一个参考权重并不能唯一证明 L1 是市场真实预期收益；本项目将 L1 作为明确的先验构造规则，而不是因果预测。

## 参数自动来源表

| 参数 | 自动准备规则 | 不能做的事 |
|---|---|---|
| Sigma | 同资产轴 Proxy 风险估计或明确风险版本 | 让用户默认手填；无数据时伪造相关性 |
| w_ref | 已发布中性基准；或通过完整规模门禁后按市值生成 | 用指数内部权重、ETF AUM、复合指数内部权重冒充跨资产市场组合 |
| delta | `RP_ref / (w_ref' Sigma w_ref)`；RP_ref 来源必须明确 | 把本次 Mandate 的个人／机构效用偏好冒充市场风险价格 |
| r_f | 同币种、同收益口径的现金／利率假设版本 | 今天隔夜利率自动代表未来十年现金收益 |
| tau | 版本化先验不确定性设置，保留当前 0.05 作为可选兼容起点 | 宣称它是唯一正确常数 |
| P、Q | 从绝对／相对观点自动构建 | 让一般用户手写矩阵 |
| Omega | 当前明确正 `view_std²` 的对角矩阵 | 把“80% 自信”直接当方差 0.8 |

无风险利率、参考权重及溢价来源不可得时，显示缺失并允许显式研究输入；“偏自动”不等于自动猜值。

若历史参考组合溢价用于估 delta，使用明确再平衡规则的组合历史超额收益与同口径方差。负／零估计溢价不满足当前 delta>0 契约时，应提示改用有依据的长期溢价或另建研究，不取绝对值修补。

严谨市值构造要求同资产范围、同币种、可比较市场价值口径、无底层重叠、可得时点与更新日期可追溯。

- `index_weights_df.parquet`／Tushare `index_weight` 表示指数内部成分权重，不是股票、债券、黄金之间的权重。[R12]
- `index_daily_basic_df.parquet` 的指数市值可能覆盖重叠股票，不能直接相加。
- ETF 的 AUM 是包装产品规模，不是全体底层资产市值；可以作为 `aum_reference`，但必须明确不是 CAPM 市场组合。
- 股票基础目录不能自动提供所有股票研究日市值；债券与海外资产还需要各自规模、币种和日期口径。

这些是数据准备要求。本轮未重新盘点正式活跃数据快照；实现时须重新核对 `data/tushare_active.json`、实际 Parquet schema 与数据可得性。不能把文档中出现文件名当作当前数据已完整的证据。

## 观点与后验

将总收益绝对观点或相对收益差转换为超额观点：

\[
Q^e=Q-r_fP\mathbf1.
\tag{L2}
\]

例如三资产轴股票、债券、黄金：黄金总收益 5% 对应 P=[0,0,1]；股票比债券高 3 个百分点对应 P=[1,−1,0]。相对观点的 P1=0，所以无风险利率抵消。

令 `V=tau*Sigma`、`S_v=P V P' + Omega`，通过线性方程求 K，而非显式求逆：

\[
K=VP^\top S_v^{-1},\quad
\mu^e_{BL}=\Pi+K(Q^e-P\Pi),\quad
\mu_{BL}=\mu^e_{BL}+r_f\mathbf1.
\tag{L3}
\]

后验均值协方差使用 Joseph 形式：

\[
U_{BL}=(I-KP)V(I-KP)^\top+K\Omega K^\top.
\tag{L4}
\]

当前实现默认保留资产风险 Sigma 不变，U_BL 单独保存。无观点时总收益为 `r_f + Pi`，**不是仅 Pi**。

其他实现可以使用 Sigma+U_BL 表示后验预测风险；本项目不默认这样做，以避免风险语义变化及与均值惩罚重复。若未来开放，需明确 `covariance_role` 与下游去重规则。[R6]

当前 view_std 独立于 tau，所以不能直接引用“tau 会抵消”的某些特殊 Omega 构造结论。0–100% confidence 转 Omega 需明确转换算法；第一版继续以观点标准差为执行契约，不伪装已经接入 Idzorek 校准。

## 现金与奇异矩阵

当前模型要求各资产正方差。确定性无风险现金不应通过人为加一个极小方差绕过门禁。第一版可使用有实际波动的现金代理；若需要数学上确定性现金，应在新模型中显式分离风险资产块与现金，并验证完整资产轴回填，不回写旧模型。

S_v 在正观点噪声下可求解不意味着所有旧协方差门禁都支持奇异资产；具体支持范围以契约与测试为准。

## 责任边界与现有缺口

情景算法中心负责保存“哪些日期属于哪些状态”的不可变研究结果；CMA 中的桥接层负责用这些日期，对**本次所有大类的共同收益轴**估计状态参数。

“已保存的事后状态研究”下拉框始终提供“打开情景算法中心配置事后情景”，无可用结果时也可进入。选择后直接打开情景算法中心的“定义历史参考”（事后情景识别）步骤，落在该步骤的已保存清单上，可继续已有研究或新建；该入口只负责跳转，不会替换当前研究引用或概率设置。

当前 `conditional_stats` 主要针对单个评价目标，且带 `forward_1_period_from_signal` 语义，不能直接充当多资产状态协方差。

当前 LTCMA 的 `cma_evidence.py` 已提供证据桥接；历史中心与 CMA 保持单向引用：

```text
HistoricalRegimeRun + ReturnPanelVersion
→ RegimeEvidenceBuilder
→ 带基础频率的状态条件矩与占用率
→ 单一共享混合内核 + 明确期限适配
→ CmaVersion
```

原 `historical_regime_occupancy` 仍只从事后运行导入。新增两种自动模式通过下述独立证据适配接入情景中心；实时识别证据本身仍不构成未来预测证明，更不以“今天熊市”覆盖未来十年。

### 自动长期情景与条件情景

展开生成方法下拉菜单，可通过“长期情景”选项旁的问号查看计算逻辑与数值算例，无须先选择该方法：按时间分三轮检验，自动选择各情景参考整体历史的比例，再合成收益风险并评估均值误差。支持悬停、点击与键盘阅读；示例数值不属于当前研究，帮助操作不修改或计算研究数据。

界面方案及模块职责见[前后端设计](../research/cma-model-decisions.md#情景中心与-ltcma-的前后端设计2026-09-22)。两种新方法共享收益证据、状态统计和频率无关的混合矩，不删除或改写原六种方法及冻结版本。

| 方法 | 必要输入 | 自动输出 | 下游用途 |
| --- | --- | --- | --- |
| `long_term_scenario` | 范围、历史情景区间；其余继承上下文 | 历史占用率、自动收缩后的联合资产矩、时间块重采样均值误差 | 确认后可用于现有 SAA；统计参考不代表未来预测已验证 |
| `conditional_scenario` | 相同历史参考、精确匹配的已校准实时运行、`horizon_days` | 当前／期末／平均占比、逐期状态推演、累计收益矩与模拟尾部 | 可保存比较研究；当前没有已验证的 SAA 期限适配，不能作为单／多 CMA 或 NIW 先验 |

`GET /cma/study-options?as_of=YYYY-MM-DD` 返回情景中心候选及每项 `available/reasons`，区分尚未创建和已存在但因数据时点、校准或版本不适用；历史情景不按识别频率筛除，实时概率仍要求匹配日频预测口径。历史参考由用户主动下拉选择，即使只有一个合格候选也不默认采用；已保存的绑定在编辑或恢复时回显。下拉框始终提供“打开情景算法中心配置事后情景”，直达事后情景识别，导航动作不改写研究引用；不按名字或“最新”猜配。PIT 变化重新读取并阻断旧选项计算。

引用由 `run_ref` 的 ID/hash 与可选 `historical_reference` 的 run/publication/hash 冻结。同一运行的多个发布版本分别可选，用发布次序与日期区分；不能只保留第一条，否则实时研究绑定后续发布时无法配对。发布时间和保存时间只用于追溯，不作为研究资格的截止时间；今天可以重新计算截至过去 PIT 的研究。已发布历史运行仍必须绑定精确 publication，不能省略历史参考的发布身份；原未发布保存运行仍可用于长期研究。条件模式必须绑定精确的历史发布参考；当前实时运行只需保存不可变版本，不要求发布为 TAA 或正式回测。LTCMA 独立检查快照完整性、PIT、日频、因果且不重绘，以及既有概率校准资格，并匹配同一历史参考、状态轴及收益面板末日。所有正概率状态须有校准资格，置信度不是概率。旧 `reliability.cma_evidence` 禁用入口继续禁用，新增桥接不赋予其预测权威。

历史情景与长期情景共用宽松的引用规则：接受任意识别频率生成的历史区间，但冻结运行的 `as_of`、观察数据及标签识别所依赖的信息均须不晚于本次研究日。不能把使用了未来数据的完整情景截短后当作 PIT 研究，必须重新计算并保存对应截止日的版本。历史情景列表也返回 `available/reasons`；前端不再自行隐藏月频或未来版本，鼠标悬停、键盘聚焦或点击不可用项显示具体原因，不能因此选中该项。

条件情景的历史参考适用相同规则；当前状态／概率维持严格规则：因果识别、无未来信息、精确参考绑定、日频与收益末日一致、校准资格与有效期，以及所有正概率状态通过验证。发布归档日期不作为额外门槛，既有校准可得日和验证时点门槛仍由可靠性模块执行。LTCMA 直接读取已核验的冻结运行并复用概率校准，不调用 TAA 发布资格解析器；未校准项返回具体的概率校准原因，不提示先发布到 TAA。TAA 仍独立要求正式发布资格，情景计算接口和既有冻结结果不变。

长期采用同一有效共同样本的时间占比。状态经验分布与总体经验分布按自动选定的 λ 混合：`F_s*=(1-λ_s)F_s+λ_sF_0`；均值与协方差和抽样来自同一分布，协方差保留两分布均值差项。λ 使用固定模型政策下按时间划分的 energy score 选择，训练原子和验证样本有明确计算上限；不足时回到总体分布并披露。未出现状态不能获得伪造的零矩或正概率预测。现金沿用范围给定固定收益，精确保持零协方差。

长期均值误差使用 256 次联合时间块重采样，固定情景定义与已选正则化参数。自动块长是依赖性启发式，非已证明最优块长；区间不覆盖标签模型选择及修订风险。保存 `mean_estimation_covariance` 与边际半宽，资产风险不加这份估计误差。默认区间稳健模式可消费半宽，联合椭球半径尚未校准，明确拒绝椭球选择。

长期重采样也消费同一 `period_contiguous`。滞后一期依赖只使用连续且两端状态已知的收益对。无缺口时保持循环块取样及原数值结果；有缺口时按目标块长把每段连续收益切成不重叠块，保留短尾块和孤立观测，逐次有放回抽取相同数量的块，再按本次抽中的已知状态观测总数归一化。变长块不做等权块均值，不丢弃短段，也不跨缺口或段尾循环。抽中次数相同的块在共同资产轴上使用同一倍数，保留联合收益关系；不同抽样块之间不声称历史连续。全为孤立观测时明确记录 `fallback=independent_observations`，这只能估计独立观测条件下的均值误差，不能识别缺口内的时间依赖。部分缺口情况下也不推断缺口内的相关性；分块边界与自动块长仍是研究启发式，不代表覆盖率保证。

`bootstrap` 记录目标块长 `target_block_length`、实际最长抽样块 `block_length`、每次块数、缺口数、取样方式及降级方式；`mean_uncertainty_method` 区分循环块与连续分段块。完整情景片段须在同一连续收益段内，且两端均观察到已知的异状态转换；缺口、未知状态与样本首尾是截断边界，不计完整片段。

区间划分是独立的索引算子；重采样内核保留对同一次块抽样的联合资产累加，未新增模型或界面参数。只读收益和标记直接传入固定签名内核，不物化块内收益副本。区间表最多 `2N` 个 int64，块计数最多 `N` 个 int64；用抽中次数累加，每次最多扫描一次收益面板，避免变长块重抽导致无界重复工作。连续、部分缺口与全孤立分支均在启动时预热。

条件模式自动选择转移正则化强度，未知状态打断相邻转移；当前概率按 `q_t P^h` 演化。期末概率与期间平均占比是两个量，均不等于至少发生一次的概率。联合经验收益按同一情景路径抽样，避免独立抽取资产破坏相关性；累计简单收益按乘积复利。累计一二阶矩由 Markov 奖励递推计算，尾部分位数与损失概率由固定种子模拟估计。年化摘要仍是未来窗口随机一期的周期算术矩，不能当作期限累计风险或 CAGR。

转移估计另须满足收益区间连续：前一收益期的结束日等于后一收益期的开始日才可计一次转换。产品和战略代理两条取数路径都在删日时保留 `period_contiguous`（int64 的 0/1 标记，首行 0）；正常周末／休市前后若共享价格端点，仍属于连续区间。历史状态转移诊断、条件模型的训练计数与正则化验证共用此规则，缺口两端标签仍保留，不把缺口编成中性状态或零收益。留出比较的完整预测区间若跨过缺口则跳过，不能把 H 个保留样本行当作 H 个连续日频步。

新发布 LTCMA 保存 `evidence_period_contiguous` 数组及其内容指纹，审计报告记录排除的缺口数；原始收益样本及其均值／协方差统计不因此删去更多记录。连续性在数据边界一次生成并只读传递；转移内核只复制一条状态向量，在缺口处插入未知分隔符后复用既有转移计数器，不复制收益面板。向量最多 `2N-1` 个 int64 元素；留出分段复用连续性数组的切片视图。固定签名预热覆盖只读非连续视图和缺口分支，版本分别为 `ltcma-statistics/1.3.1`、`scenario-cma/1.0.2`。旧研究快照保持原样，不重新拟合。

状态未来比较采用按时间训练与不重叠期限终点，分别对比 Markov、历史占比和状态持续基准；事后已知状态的诊断与标签成熟时点检查分开。缺少历史实时概率流和当时拟合版本时，明确标为诊断，不能声称整条预测链已通过样本外验证。条件路径尚未建模状态内残差相关及参数不确定性，合成测试不能补足真实市场资格。

数值执行统一走固定签名 NJIT、启动预热和只读收益面板；概率矩、路径及 Bootstrap 工作区按预算分配。种子绑定数值输入与证据，不绑定名称或备注。数值精度检查仅按其真实覆盖范围标记，不能用均值模拟标准误宣称尾部或模型已验证。结果及用途随不可变版本保存，旧记录不重新拟合。

条件期限支持 1–2520 个交易日。解析递推按 `期限×状态数²×资产数²` 设 5,000 万工作量上限；模拟最多 8192 条最终路径，包含自适应重复计算的总资产日抽样预算为 2,000 万。预算不能满足目标时如实记录，不能把预算耗尽标成精度达标。均值 Monte Carlo 标准误目标为 0.001；亏损概率标准误、分位数的近似次序统计区间另行保存，均不覆盖模型估计误差。

## 状态轴、收益归属与有效样本

使用同一个市场状态定义切分全部资产。例如用权益市场牛／熊／震荡作为条件，研究债券、黄金在**权益牛市期间**的收益；不能分别筛每个资产自身牛市后拼成一行多资产样本。

先计算每个真实相邻观测的收益 r_t，再依据冻结规则把 r_t 分配给状态。第一版默认 `return_end_state`：区间 `(t−1,t]` 的收益归属于 t 对应的事后状态；跨状态边界的收益只计一次，并在诊断中披露。

历史标签按已观察的闭区间投影到日收益末日：原观察日保留原标签；两相邻观察日状态相同且非未知时，区间内日期归属该状态，可得时间取两个端点的较晚值。两端状态不同、未知空段以及首尾范围外均不猜测或外推。该规则复用情景中心连续同状态分段的起止含义，不改变原观察点的标签。月频识别产生的区间可以用于日收益分组，不把月收益按日年化，也不补造未识别的切换边界。投影由启动预热的固定签名 NJIT 内核执行，保留来源频率、未知观察数和可得日期用于诊断。

不把分散在多年中的“熊市价格点”拼在一起重新求收益，不忽略中间状态形成跨期跳跃。若采用“必须两端同状态”的严格口径，会改变样本与占用率，须作为独立选项，并不再声称重构原全样本矩。

Unknown、缺失 Proxy、无效间隔从同一个多资产共同面板中排除，保留排除原因和覆盖率；不归入震荡、不填零。合法样本不足按质量策略阻断正式生成。

## 默认概率与用户覆盖

本节的人工概率覆盖属于原 `historical_regime_occupancy` 契约。新增自动长期／条件情景不要求或接收人工概率、转移矩阵及分情景资产参数，相关估计由模型完成。

在当前有效共同面板上：

\[
p_s^{detected}=n_s/T,\qquad T=\sum_s n_s.
\tag{G1}
\]

这是时间占用率，不是状态段数量占比、HMM 某日置信度或转移概率。保存原运行全样本占用率与当前共同样本占用率的差异，避免用户误以为发生了参数错误。

显示“历史识别占用率／本次应用权重”两列；默认相同。修改后保留 detected、applied、原因并支持恢复。应用权重须非负且合计 1，禁止静默归一化。

零概率状态保留用于审计，但区分“合法、尚无样本”和“数据／状态本身非法”。桥接结果保存完整 `declared_states` 与 `unestimated_states`；数值混合只传入具有完整、合法参数的状态，并保存该执行子集与全状态轴的映射。

没有历史样本且应用权重为 0 的状态可以仅保留为 `unestimated`，不能伪造零均值／零协方差。其应用权重一旦改为正数，必须有显式先验或人工条件参数；否则阻断。已发生样本异常、状态编码非法或缺失覆盖，不能通过把概率设为 0 免除质量门禁。用户新增历史没有出现的情景时，也必须给出独立参数来源。

## 基础频率条件矩

对状态 s：

\[
m_s=\frac1{n_s}\sum_{t:z_t=s}r_t,\quad
C_s^{ML}=\frac1{n_s}\sum_{t:z_t=s}(r_t-m_s)(r_t-m_s)^\top.
\tag{G2}
\]

默认使用状态专属风险，而非所有状态共用同一个风险矩。小样本状态可明确选择对角收缩、NIW 条件估计或共享风险；共享风险并不能补出不存在的状态均值。

所有均值和协方差在**同一观测频率**统计。段数、完整段数、首尾截断段、持续时间、覆盖率和状态样本量一并输出。

## 历史占用模式：先混合，再年化

基础频率混合：

\[
m=\sum_s p_s m_s,
\quad C=\sum_s p_s C_s+\sum_s p_s(m_s-m)(m_s-m)^\top.
\tag{G3}
\]

采用独立增量近似时：

\[
\mu_a=a m,\qquad\Sigma_a=a C.
\tag{G4}
\]

**不能**先令 `mu_s=a*m_s`、`Sigma_s=a*C_s`，再套年度混合式。那会把状态间协方差放大为 a² 倍，而正确基础期混合再年化是 a 倍。

历史状态有持续性，严格多期风险还包含 U2 的跨期项。第一版应标为 `historical_occupancy_iid_annualization`，不是已校准的多年状态转移预测。需要保留原时序的 Bootstrap／Markov 路径时，必须另有转移、持续期、再平衡与期限模型，不能只换一个名称。

## 年度替代情景模式：现有混合公式继续适用

当每个情景描述的是**同一年度收益随机变量在不同世界下的条件分布**，且输入已经是可比的一年简单收益矩：

\[
\mu=\sum_s p_s\mu_s,\quad
\Sigma=\sum_s p_s\Sigma_s+\sum_s p_s(\mu_s-\mu)(\mu_s-\mu)^\top.
\tag{G5}
\]

这是现有 Scenario Mixture 的数学语义。年度世界概率与历史日／月占用概率不能默认视为同一件事。

建议 source kind 明确为：

```text
manual_same_period_scenarios
historical_regime_occupancy
```

当前已提取唯一频率无关的 `mixture_moments_kernel`，返回均值、总协方差、状态内协方差和状态间分歧。`scenario_mixture_kernel` 保留人工情景的输入验证；历史状态经 `cma_statistical_models.py` 在基础频率直接复用共享内核，再年化。两种包装不能交换概率及时间尺度语义。

## 一个必要的恒等式检查

若 p=n_s/T，使用 ML 条件协方差，未做收缩、覆盖或预测调整，G3 应恢复同一全样本的 ML 均值与协方差。

因此“先切牛熊震荡，再按原历史占用率原样混回去”可能与普通 Historical CMA 完全一样。此时价值是解释状态贡献，不是凭分组自动增加预测信息。

使用 `ddof=1` 时，重构全样本协方差须用：

\[
S_{all}=\frac{\sum_s(n_s-1)S_s+\sum_s n_s(m_s-m)(m_s-m)^\top}{T-1}.
\tag{G6}
\]

未来真正改变结果的来源包括：显式修改概率、状态条件均值／风险收缩、不同长期先验、经验证的状态转移路径等。必须标注改变发生在哪里，不能把机械重构包装为新预测。

## 发布、Horizon 与跨期信息

建议新增 `cma_reference` 引用用途，保存 run ID、定义 revision、状态映射、run hash、数据知识截止、共同样本、概率覆盖和统计参数哈希。

事后识别可以在当前研究日使用截至当前的信息作历史解释；如果按 2020 年 as_of 研究，不能裁剪一个看过 2026 年行情的识别结果冒充 2020 年知识。

状态中位持续几十天并不自动证明可作十年长期状态生成器。基础模式可作为历史对照并展示周期覆盖；结构性 LTCMA／多年路径资格需要独立 Horizon 证据，不因取消无数值作用的预测期限标签而获得。

## 最新决策及未实现项

历史均值的年化估计协方差为 `a² S_period/T = a Sigma_annual/T`，不能漏乘一个年化因子。状态 ML 使用 ddof=0，历史样本协方差使用 ddof=1，二者不能无条件统一。

BL 支持绝对、相对及篮子观点，均进入同一更新内核。单 CMA 可使用冻结均值协方差的椭球不确定集；模型专属覆盖半径、收缩风险方向、NIW t 尺度及状态持续解释见[CMA 决策](../research/cma-model-decisions.md)。该纪要中的最终勘误优先于早期评审建议。

状态转移和持续期诊断不等于已实现多年 Markov 资金模型。人工年度情景不得通过每月重抽伪装成同一分布。Building-block、跨币种／频率适配及多 CMA 联合均值误差仍是后续能力。

数值计算复用固定签名 NJIT，发布冻结来源与数组；只读历史不重新训练。技术证据见[配置验收纪要](../verification/allocation.md)。
