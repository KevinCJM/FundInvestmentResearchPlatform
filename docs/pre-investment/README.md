## 如何完成一次研究

1. 在设置中发布风险标尺，在投资目标中确认资金事实、成功标准及风险授权。
2. 选择研究路径与范围：先浏览范围库或选择研究路径；新建时在范围配置内必选已发布的投资目标与约束。可从产品池构建大类，也可先用指数／参考产品构建战略大类。研究代理与最后实际投资的产品分别管理。
3. 在 LTCMA 中心研究并确认长期收益与风险假设；在 SAA 中选择精确版本，比较候选并保存政策。新增[长期情景与条件情景](ltcma.md#自动长期情景与条件情景)连接情景研究中心：长期情景沿用年化口径；条件情景研究指定期间的变化，当前可保存比较，暂不能交给 SAA。
4. 按需做 TAA，保存相对该 SAA 的战术决策；纯 SAA 研究无需伪造 TAA。
5. 进入产品与资金，确定实施映射、产品权重、费用、持仓与现金，计算实际产品风险和剩余资金。
6. 汇总为同一研究包，锁定候选后验证，满足对应条件后具名研究定稿。修改输入必须重新验证。

## 投前总览与操作路径

投前入口 `/pre-investment` 将九个模块放进连续的三段流程。每步显示名称与“做什么”，不重复列出产出；段末说明如何交给下一段；点击步骤名称进入对应模块。顶部“从投资目标开始”进入目标列表，“查看已保存 SAA”进入方案列表，已有研究仍从各模块列表打开。详细布局、调研来源和验收见[前端设计](../frontend/README.md#投前总览分段流程与交接)。

| 阶段 | 操作路径 | 交接条件与结果 |
| --- | --- | --- |
| 确定研究基础 | 01 投资目标与约束 → 02 研究路径与范围 → 03 LTCMA | 绑定目标、确定资产与代理，确认长期收益与风险假设，再进入 SAA |
| 形成配置方案 | 04 SAA → 05 TAA（按需）→ 06 产品配置与择时 | 保存长期配置；需要战术调整时再做 TAA。产品配置承接 SAA 或 TAA，保存同一候选后进入验证 |
| 验证并定稿 | 07 研究包与风险汇总 → 08 研究验证 → 09 研究定稿 | 汇总同一候选的证据，核对验证报告后定稿；发现问题返回修改并重新验证 |

两种研究路径的区别放在第一段的展开说明中：先定大类时配置指数／产品研究代理，现金填写预期收益，实际产品可随后匹配；先选产品池时从已保存池版本构建大类及代理。两条路径都在 LTCMA 汇合，不提供跳过 LTCMA 的 SAA 计算捷径。表中的箭头表达业务依赖，页面导航仍可自由打开各模块列表，不会因此判定已满足准入；第 07 步汇总视图不是产品候选保存后进入验证的额外强制页面。

## 主题与交接

01、02、05 入口和 04 配置工作台的标题下提供两段说明：先解释用途，再说明用户的操作与下游承接。04 的目录入口先展示已保存的 SAA 方案及目标、范围和 LTCMA 关联，并提供新建按钮，见[SAA 方案列表](saa.md#方案列表入口)。01 对应 IPS 中的目标与限制，先选风险等级配置，再设定收益／资金目标、最高风险等级和现金安排；02 确定一致的研究对象，并区分研究代理与实际产品；04 依据目标、约束和 LTCMA 确定长期资产比例；05 在 SAA 基础上评估有边界的临时调整，比较扣费结果并明确复核条件。参考诊断和模型结果不构成收益承诺，保持 SAA 也是有效选择。

说明依据 [CFA 投资规划与组合构建](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/basics-of-portfolio-planning-and-construction)的 IPS 逻辑、[资产配置总览](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/overview-asset-allocation)的资产定义与实施区分，以及[现实约束下的资产配置](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/asset-allocation-with-real-world-constraints)的战术偏离、成本与政策基准比较。[Vanguard 的动态配置研究（2024）](https://corporate.vanguard.com/content/dam/corp/research/pdf/time_varying_asset_allocation_vanguards_approach_to_dynamic_portfolios.pdf)补充了长期战略、短期战术与中期动态配置的区别；页面不将这些方法混为一谈。资料核对日期为 2026-09-22。

## 当前能力与限制

风险标尺、精简目标流程、两类 LTCMA 上游、当前已登记 CMA 方法、三种 SAA 模式，以及产品与资金／证据汇总／锁定验证／研究定稿已有基础实现。旧总设计中把产品实施、统一验证整体列为下一阶段的叙述已失效。

仍需区分以下边界：

- 历史有效前沿用于历史配置实验；不能替代前瞻 CMA。研究可复现不证明历史 PIT 合格。
- 战略范围的 TAA 使用冻结研究代理，可在未完成产品映射时研究和保存；完整映射与可投资域检查保留在产品应用边界。无代理定义的旧产品基线沿用原数据读取契约。
- 单 CMA 椭球、模式 A 的 E2 参数平均、模式 B 的共同约束有各自能力门禁；E3 原生混合路径、多 CMA 椭球、模式 B 产品联合 QCQP 不作为已完成能力。
- 产品实施基础版支持声明条件下的 ETF／现金研究；全期实际交收、成交容量、基金未来费率、认证独立审批仍未验证。
- 研究定稿不自动成为交易指令、实盘组合或投资效果证明。账户与组合核算仍见独立目标设计。

## 跨页面一致性

投前总览是分段流程导览，不代表已选择某份研究。总览不展示上次研究的方案名称、完成进度或续接提示；从流程进入模块时不附加上次研究身份。已保存书签与草稿保留，进入具体研究后再展示对应上下文。

持久化对象按精确版本及内容 hash 承接，不自动采用最新版本。上游改版或删除后下游的可用性按[版本与依赖管理](versioning.md)统一判断。资产范围、产品池、研究日、PIT、模型、费用或资金状态改变时，废弃依赖它们的未确认预览；晚到响应不能恢复旧候选。草稿恢复必须说明缺失／失效依赖。第 02 步只有真实存在于已发布目录的投资目标与约束才能解锁锁定快照与后续入口；所选目标研究日与当前页面 PIT 日期不一致时给出非阻断提醒，不自动改口径、不重写选择，也不因日期差异阻断保存。

历史结果只读；当前退休、准入与有效性另行核验。底层数据更新不回写已冻结研究。保存、验证、定稿均由后端校验，不以按钮禁用或前端通过数量替代。

## 第 02 步：研究范围库与简化录入（设计）

本节记录第 02 步「选择研究路径与范围」的界面设计与契约调整；实施状态见节末。

### 范围库（两条路径共用节奏）

复制产品范围时同时继承产品池版本、研究日及 `excluded_product_keys`；排除项属于范围配置，不因复制为新研究而清空。

列表页（`ProductPoolSelection`，`/pre-investment/product-pool`）与编辑页（`ProductPoolWorkspacePage`，`/pre-investment/product-pool/new`）拆成两个独立路由，对齐 01 投资目标与约束的 `objectives` / `objectives/new` 结构：列表页只负责浏览范围与选择研究路径；新建、编辑、复制、查看/继续研究一律先跳到编辑页，不在列表页原地展开。两页各自独立读取战略目录与产品范围库（编辑页为同名预检自己再读一次，不与列表页共享 state）。

- 顶部只保留研究路径分段链接与说明，说明使用卡片完整可用宽度、窄屏自动换行；不在列表页要求选择投资目标。「投资目标与约束」下拉移至编辑页的「配置大类资产与研究代理」内部，产品路径放在「选择产品池版本」内，均为必选；未选定有效目标不能保存。目标加载、读取失败重试、缺少已发布目标及 PIT 提示就近显示。
- 路径说明下常驻「已保存研究范围」库：搜索框 + 新建主命令 + 可搜索表格；行包含名称、关联的「投资目标与约束」名称、研究日、类型/路径、产品数或战略资产数、当前选中标记。目标名称可点击，进入「01 投资目标与约束」中保存时绑定的只读详情（`objectives/new?view=<mandate_id>`）；未关联、读取中或读取失败时保留文字提示，不显示可点击名称。目标按各范围自己的 `mandate_id` 解析；活动目录缺失时按精确 ID 读取历史版本，保留原目标名称，不取当前 URL 或浏览器书签中的其他目标。无关联显示「未关联目标」，读取失败显示「目标名称暂不可用」并提供重试，不能将失败当成未关联。研究日与当前页面 PIT 日期不一致（PIT 已确认开启时）在日期旁加 `PitBadge` 同款红色感叹号图标，悬停显示不一致说明（浮窗用 `createPortal` 挂到 `document.body`，避免被表格的横向滚动容器裁切）；冻结日期本身不因此改写。
- 操作固定为「继续研究」「编辑」「复制新建」「删除」；除「删除」（留在列表页原地做具名确认）外都是跳到编辑页 `/pre-investment/product-pool/new` 的 `<Link>`，携带精确身份参数（产品 `universe`、战略 `scope=strategic&strategic_universe`，「编辑」再加 `edit`、「复制新建」再加 `copy`）与范围绑定的投资目标 `mandate`；仅新建可携带 URL 中的明确目标作为预选；未绑定旧范围的列表链接不借用当前目标，须在配置内明确选择或通过显式目标深链接补记。产品路径数据来自 `GET /api/investable-universe-snapshots` 的不可变摘要（newest-first）；战略路径来自战略目录中的已保存范围。
- 「新建研究范围」同样是跳到编辑页的 `<Link>`，携带 `mandate`（如已选）、`scope=strategic`（战略路径）与一个每次点击都重新生成的 `new=<timestamp>`——不能写死成常量，否则连续两次点「新建」会撞上同一个草稿 key，第二次悄悄捞回第一次未保存的草稿。点击时清空旅程里残留的 `universeId`/`strategicUniverseId`/`implementationMappingId`，编辑页据此渲染全新草稿，不套用上一次遗留的选择。
- 编辑页 URL 标识这次编辑的范围；已保存范围从服务端恢复绑定的目标版本，并补齐 URL 的 `mandate`，无需重新选择，错误的目标参数不能换绑。保存成功（新建/复制/编辑）立即把新 ID 写入编辑页自己的 URL（产品 `universe`、战略 `strategic_universe`）并清掉 copy/edit/new/version 及过期映射参数，同时保留当前投资目标；编辑页顶部的「← 返回研究范围库」带回 `mandate`/`scope`，回到列表页后保持模式，目标参数只用于后续新建预选，不改变列表中各范围的绑定。
- 编辑页按 URL 参数在三种状态间切换：查看已保存范围（只读摘要 + 「编辑此范围」「复制此范围新建」）、编辑（`edit=<id>`，主按钮「保存修改」+「取消编辑」回到只读、不写入）、全新草稿（`new=<timestamp>` 或裸进入）。同名校验（去除首尾空白并忽略大小写，跨产品/战略两条路径）前后端都做，冲突时在名称字段给出「研究范围名称已存在，请修改名称。」并阻止保存；改名后即可保存，不会自动加后缀。保存实际修改后，新不可变版本替代当前列表项，旧版本与其 hash 仍可按 ID 只读读取。独立战略范围的完整定义和目标绑定未改变时，保存直接返回原记录，不制造重复版本；名称备注的修改仍保留，但不阻断相同配置事实的 LTCMA 复用。
- 「删除」需具名确认（「从列表移除「名称」？已引用的历史研究保留。」），取消不发请求；成功后仅从活动列表移除并清掉当前旅程引用，冻结快照与下游历史引用保持只读；重复删除幂等，服务端失败时保留列表并显示错误。删除等待期间切换选择不会清掉新选择。
- 没有有效投资目标与约束时，不提供跳过目标直达 SAA 的链接。

本地验收（2026-09-23，范围目标选择与说明布局）：相关三个测试文件共 82 项通过；隔离浏览器在 320／768／1440px 下共 15 项通过，覆盖全宽说明、按方案展示目标名称、配置内必选、刷新恢复、历史绑定锁定和目录失败重试，并检查正常页面文字对比度与无横向溢出。构建、语言、设计、文档及本任务路由覆盖检查通过。未修改后端接口和数值算法，也未向真实业务服务保存测试记录。全项目前端单测本轮为 1739 通过／30 失败，失败集中在并行调整中的 SAA 候选及其交接页面；全项目类型检查也受该区域影响，不能据此宣称全项目通过。

### 产品范围（产品池版本）

- 已发布版本改为可搜索表格：每个产品池一个当前版本，已选版本不因搜索隐藏；保留生效期、评价数据截至、晚于研究日提示与「按研究日回放」。
- 分别读取全部已发布版本与当日生效版本：两者皆空说明「尚未发布」；有发布但当日无生效时说明原因，并把非生效版本作为只读信息展示，不能借此绕过生效日门禁。
- 恢复已保存快照时，即使当前版本筛选隐藏其来源版本，也保留其 `version_ids`。研究名称默认生成、可编辑，收在「研究名称（默认已生成，可修改）」补充区；研究日保持可见；已保存快照摘要与产品明细保留。
- 选中的已保存快照默认只读：展示冻结摘要、继续入口、「编辑此范围」与「复制此范围新建」；编辑与复制都发生在独立草稿上，已保存版本与其 hash 不被就地改写。

### 战略范围

- 配置页在「返回研究范围库」与资产编辑区之间显示当前投资目标与约束，新建可在配置内选择目标，或按 URL 中显式指定的目标预选；查看和编辑从范围中恢复固定关联，产品范围同样展示。保存时持久化 `mandate_id` 与 `mandate_hash`，编辑版本继承关联，复制新研究可在配置内显式采用其他目标；已保存范围的目标选择器锁定并说明更换需复制新建，编辑不改写原绑定。无关联的旧范围仅可按明确指定的目标一次性补记，不能从全局书签或名称推断归属；补记单独存放，不改冻结范围及其 hash。默认展示目标名称、期限、币种、收益/资金目标、风险上限和现金下限；展开可查看研究与复核日期、流动性限制、资金安排、再平衡与备注，并进入完整目标。摘要只读取已保存值，区分填写值与已解析的有效下限，不在展示层重新计算；目标读取失败时显示重试；已绑定但停用／被替代的目标仍按原版本展示历史约束，并说明继续新研究需复制范围并选择可用目标。
- 已保存战略范围在编辑区以只读摘要（名称、研究日、本位币、资产数）与只读资产表呈现，底部配「下一步」「返回编辑」，不再以整组禁用输入框代替摘要；新建直接点击「保存战略范围」，编辑点击「保存修改」，可「取消编辑」回到只读 URL。前端在一次保存中自动完成后台校验与写入，不再要求手动预览。保存处直接显示未满足的条件或服务端错误，失败保留输入并可重试；校验错误使用大类名称、界面字段和当前语言的修正建议，不直接展示字段路径或框架原始错误。服务拒绝新增配置时合并为一条页面/服务版本不匹配提示，不要求用户删除研究代理或丢弃字段重试；保存中防止重复点击，修改输入、目标、PIT 或切换视图会取消在途操作，迟到校验不得继续写入。
- 只读资产表使用共享 `DataTable`，展示代理名称/权重或现金收益，不展示内部 ID；已保存范围的实施映射折叠在「匹配真实代理产品（可稍后完成）」内，已有映射引用时自动展开；父级范围库已取代底部的历史范围下拉框。
- 已保存战略范围底部仅保留「下一步」「返回编辑」，位于历史映射和真实产品匹配折叠区之后；两者采用共享按钮外观，等宽等高，下一步为主色、返回编辑为描边。窄屏满宽纵向排列，宽屏并排；复制新建仍从范围库操作。下一步只进入 LTCMA 新建假设，确认后再由 LTCMA 进入 SAA；本页不提供绕过 LTCMA 直达 SAA 的入口。
- 新定义使用共享的 `risk-scales/CategoryEditor`：一行一个大类（大类名称 / 资产类型 / 再平衡或现金预期年化收益率 / 研究代理与状态 / 操作），代理成分、权重与「备注（选填）」收进该行的展开区，默认收起、新增的大类自动展开；宽屏由一行表头承载列名，窄屏在每个控件上方显示字段名，控件本身始终带可访问名。每行右侧给出状态徽章（已配代理 / 待选代理 / 待填收益率 / 权重合计 xx%），标题行给出「共 N 个大类 · M 个可用 · K 个待完成」，口径说明在清单上方只出现一次，不再逐个大类重复。保存操作条在卡片底部常驻（`sticky bottom-0`），长清单下不必滚到底。非现金类直接批量选择指数、ETF 或公募基金，填写成分权重和再平衡规则；现金类只填预期年化收益率（默认 0%），不显示代理与再平衡。所有大类仅保留「备注（选填）」折叠区，不再展示配置用途与变现能力。资产类型是本页现金识别的唯一用户输入：新请求在后端按现金/非现金类型生成现有下游计算分类，现金自动采用现金储备且可流动，非现金不能沿用现金角色；新非现金默认可流动，编辑已有非现金时保留原有变现限制。未声明类型的旧请求仍执行原显式分类契约，已保存历史不回写。08 风险等级配置中心的「参考资产与代理」与 LTCMA 统计模型的「研究代理」是同一个组件的另外两处调用：08 与 02 完全一致；LTCMA 传 `fixedAssets`，大类跟随战略范围冻结，只读名称、不能增删，且只有流动性大类可切成现金（`cashEligibleIds`）。调用方不传 `renderAssetDetails` 时，展开区兜底给出「经济定义与依据（可选）」输入框（08 与 LTCMA 走这条），02 则用它放「备注、参考资料」。
- 清单上方是「常用大类」快速添加区：候选来自本账号已保存的其他战略范围（取各名称最近一次出现的代理配置，跳过未配置代理的条目），每个候选是一枚可点的标签，点一下即在清单末尾追加该大类并一并带入代理与来源名称，随后仍可自由改名或改代理，不限制为固定分类；已在本次清单中的名称、以及范围内已有现金大类时的现金候选，标签置灰并说明原因。标签右侧的「不再推荐」只把该名称移出建议列表，不影响已配置的大类；隐藏后标题行出现「恢复已隐藏的 N 个」可整组恢复。该隐藏名单只存于本机浏览器（`localStorage`），不是新增的后端字段，因此不同浏览器或设备之间不同步。候选超过 8 个时其余收进「展开其余 N 个常用大类」。
- 稳定 ID 自动生成，编辑器和摘要均不展示；改名/改币种不改身份，复制保留原 ID。可选理由与来源改为「备注、参考资料」，默认折叠。范围补充说明属于顶部基本信息，分隔线位于其下方。
- `StrategicAsset.research_proxy` 保存研究输入默认值（现金/市场类型、现金收益、代理成分、再平衡及名称）。未选代理的市场大类仍可保存；填写的权重须非负且合计 100%，产品必须采用复权数据，纯现金最多一类。实际配置代理仅支持 CNY。后台校验 hash 包含这些输入，每次保存都重新校验当前草稿并使用本次 hash 确认；旧范围没有代理时保留原定义/hash 格式。
- `StrategicAsset.weight_limits` 是范围层大类权重边界（下限 / 上限，0–100%，下限不高于上限，下限合计不超过 100%）；未设置时不写入，保留旧定义与 hash。SAA（单 CMA、多模型、前沿诊断）从 CMA 冻结的范围快照读取，02 历史初筛读取当前草稿，均在 `_constraints` 中与投资目标授权取更严者：范围只能收紧，不能放宽目标。SAA 页面预填约束按同一口径合并。
- 投资目标生效现金下限大于 0 时，02 编辑区每个编辑身份补一次现金大类（已有现金但未设边界时只补下限），下限预填为目标值；之后用户调低或删除只提醒不改回。现金下限低于目标或缺少现金大类时，编辑行、只读资产表与范围库名称旁用共享 `WarningMark` 红色「!」提示（与研究日 PIT 不一致提示同一组件），保存条同时显示文字，均不阻断保存；SAA 仍由 `policy-cash-reserve` 按目标下限执行。未显式设边界的旧范围视为沿用目标，不提示。
- 保存后可直接进入 LTCMA，新研究草稿承接代理、权重、再平衡及现金收益；人工模式预填纯现金收益与零波动/零协方差。数据可用性、历史窗口与 PIT 仍由 LTCMA 重新核验。研究代理不生成实际投资产品映射、不改变实施状态；确认 SAA 后可供 TAA 大类研究，计算仍须通过数据与时点检查。
- 战略本位币唯一且显式可编辑，资产行币种继承并随本位币同步；历史不可变版本不改写。研究日继续遵守 PIT 规则。
- 说明性来源与理由在前后端均改为可选（有界字符串，默认空），保留已填写内容及其冻结 hash；ID、角色、流动性、币种、日期等量化校验与门禁不变，不为了通过校验而编造证据。

### 代理来源批量选择（SourcePicker → CategoryEditor → 研究范围 / LTCMA / 风险标尺）

- 选择器改为内联批量：类型切换 + 代码/名称搜索 + 表格（名称与代码、覆盖与口径、可用性与原因、复选框），已选托盘跨搜索、类型与分页保留，只保留「确认选择」与「取消」两个命令。
- 结果表限高 `24rem`（`DataTable` 的 `maxHeight`），一页 20 条在表内纵向滚动、表头吸顶，不把选择器下方的其他大类顶出屏幕；再往后的结果仍走「下一步」翻页。02、08 与 LTCMA 共用同一个选择器，三处一致；06 手动构建「从可投资域添加产品」的检索表同样限高 `24rem`。
- 确认由调用方（`CategoryEditor`，02、08 与 LTCMA 共用）一次性原子追加全部已选项（同一 kind + series + field 去重，禁用来源不可选），已有权重不重算、不静默归一化；取消不产生任何修改。移动端托盘换行堆叠，不产生横向溢出。

### 第 02 步：历史前沿与目标初筛

选择研究范围并关联投资目标后，编辑页自动调用 `POST /api/strategic-allocation/scope-feasibility`，不必先保存范围或生成 LTCMA。战略路径使用当前大类、指数／产品代理、权重、再平衡和现金收益；产品路径使用所选已发布产品池版本及排除项，复用锁定快照的产品合并和准入规则，但不写快照。已保存范围沿用其绑定目标与研究日。

- 默认回看 5 年，可显式选择 1／2／3／5／10 年或全部共同历史。复用 LTCMA 历史证据链，要求 CNY 与足够的共同日频样本。代理交易日历不同（如境外指数与 A 股指数）时按共同交易日对齐，跨日收益期整段排除并在界面报告数量；窗口本身不自动改写，所有代理都没有数据的交易日仍然阻断。使用历史日收益算术均值、未收缩的样本协方差，按 252 日年化；现金沿用输入收益、零波动与零协方差。
- 图横轴是年化波动，纵轴是历史年化收益；绘制当前范围在权重、现金与流动性边界下的有效前沿。年化算术收益目标画收益下限横线、波动上限竖线及交点，阴影表示收益线上方、风险线左侧。累计／复利要求与算术要求同时存在时，改画随波动变化的同口径收益要求曲线，不画固定目标交点或矩形达标区。目标交点是两条边界的交点，并非必须精确命中的投资组合。前沿不因目标过高而被隐藏；求解失败点保持断开，数值可在表格中读取。
- 同图叠加目标绑定的风险标尺原始前沿（灰色虚线），以及目标确认时保存的约束后参考前沿（棕色点线）；蓝色实线仍为当前范围。`reference_comparison` 只读取原目标精确引用的不可变标尺清单并验证指纹，约束后曲线取该目标同一标尺引用下的冻结诊断，不读取当前默认标尺、不重新计算或校验市场数组。三条线共用坐标轴、提示和数值表格，未解点保留断开。展示参考名称、研究日、币种和原样本区间；改变历史窗口仅重新估计当前范围，参考资产和样本可能不同，不能把曲线位置当作同样本优劣证明。
- 未绑定标尺、来源不可读／指纹不符、币种／算术年化口径／研究日不兼容分别提示；不可用参考不影响当前范围判断，不回退到最新默认标尺。旧目标没有约束后参考曲线时只展示原始标尺。当前范围无可用前沿时，原始曲线仍可作参考，但明确不能据此确认当前范围可达。可达性求解和保存／继续流程不消费这些显示用曲线。
- 可达性复用 SAA 的连续约束求解器，寻找风险上限内的最大历史收益，并检查原始约束残差。存在经验证达标的权重才显示“历史测算可达”；连续求解的收益上界低于目标，或有约束不可行证书时显示“历史测算不可达”。不能用 41 个绘图点都未达标证明无解。
- 数据不足、未选代理、矩阵无效、求解未完成、目标或风险参考过期等显示“暂无法判断”及具体原因。资产／组授权严格匹配所属范围；产品权重上限和排除项必须生效。产品池没有明确现金或流动性分类时，不把可交易 ETF／基金直接认定为已满足现金或变现约束；可保留范围前沿，但标明未应用完整目标约束。
- 01 已通过统一 `funding_inputs` 计算资金计划所需的固定年复利收益；02 复用同一计算，在 `mandate.funding_requirement` 回显数值、求根状态及扣费前口径。资金目标显示“资金计划所需年化收益率”，不再只显示“按目标条件单独验证”；超出搜索范围、下界已满足与精确求解分别说明，不能以边界值冒充解。只有复利要求、没有额外算术收益要求的资金目标图通过 `funding_comparison` 将三条原前沿的每个点统一投影为模型年化复利收益（中位数），再画所需收益横线、风险竖线、交点和比较区域；不把复利率直接画到算术收益轴上，不改写原 `target_return`、原始前沿或保存数据。复用既有日频矩适配器（252 日、独立对数正态增量），费用已计入所需门槛，曲线保持扣除计划费用前口径；此图并非重新求解的复利最优前沿、历史实际 CAGR 或未来预测。
- 前沿生成、历史约束初筛、资金路径成功率是三层证据。资金图只在当前范围约束已完整应用、连续风险检查通过、且当前范围候选／有效绘图点达到复利门槛并满足风险上限时，显示“收益门槛与风险约束初筛通过”；参考曲线不参与判断。有基准约束时只接受已检验基准的连续候选。未找到点时显示“尚未找到达到收益门槛的组合”，不能证明全域无解；缺精确求根或完整约束时保持未完成状态。后续资金成功概率以步骤说明表达，不再用黄色“资金路径成功率待验证”徽章混淆本步结果；产品流动性未知仍明确警示。完整可达性 `status`、`target_check` 与资金概率门禁保持原契约，新增投影状态只代表收益门槛初筛。资金所需收益率已计算不等于实际组合按时支付并达到期末金额的成功概率已通过；后者继续由 LTCMA／SAA 及后续研究验证。相对目标在当前模型内使用“冻结基准预期收益＋要求的超额收益”形成绝对算术收益要求，同时保留跟踪误差约束；只有与当前范围同轴且来源合格的冻结基准才参与，否则保留前沿并说明未完成判断。01、02、SAA 与 TAA 共用带口径的收益要求契约，详见[投资目标与约束](mandate.md)。
- 选择、代理、目标、日期、PIT 或窗口变化立即隐藏旧结论，500ms 后重新计算；取消在途请求并丢弃迟到响应。加载保留图表占位，失败可重试。不可达时建议先修改范围、代理或目标，但不改变原有保存／继续流程，也不自动降低目标或放宽约束。

### 字段与状态约定

| 信息 | 新建时 | 已保存时 |
| --- | --- | --- |
| 投资目标与约束 | 必填；PIT 不一致仅提醒 | 自动展示范围绑定的目标版本；编辑、刷新不需重新选择 |
| 研究名称 | 默认生成、可修改，收在补充区 | 显示冻结名称 |
| 研究日 | 沿用各路径 PIT/生效日规则 | 显示冻结日期，不自动对齐当前 PIT |
| 大类名称、类型、研究代理/现金收益 | 主操作区；用途与变现能力由系统处理，不再手填 | 展示代理名称/权重或现金收益 |
| 战略资产 ID | 系统维护，不展示；改名不改身份 | 后台保留精确身份，复制保留 |
| 战略本位币 | 范围级设置一次，资产继承 | 显示冻结口径 |
| 来源与定义/匹配理由 | 默认折叠的补充说明（非必填），空值不编造解释 | 已有内容原样可查 |
| 映射产品域、代理、复核日 | 真实引用与有效性要求不变；缺产品可先做战略研究 | 保留缺口与原始引用 |

| 状态或动作 | 行为 |
| --- | --- |
| 读取范围库 | 保留标题与工具栏；失败时表格整块换成 `ErrorPanel`（居中形象 + 失败原因 + 「重试读取范围库」），不退回「还没有已保存范围」那类空态文案 |
| 从未保存范围 | 说明暂无记录并提供新建入口 |
| 搜索无结果 | 保留搜索框，允许清空；不把全部数据当成空库 |
| 查看已有范围 | 按精确 ID 只读摘要；旧请求与迟到保存不能覆盖后选身份 |
| 复制新建 | 独立草稿，不回写原快照或沿用旧结果 |
| 未选择有效目标 | 允许查看，保存与继续保持禁用并给出原因 |
| 当日没有有效产品池 | 区分尚未发布与该日无生效；非生效版本只读 |
| 切换搜索、类型、页码 | 待选清单保持；已有代理与不可用来源不能重复加入 |
| 确认/取消批量选择 | 一次原子加入；取消丢弃待选，已有权重不变 |
