# 配置研究上游流程优化

日期：2026-09-11。依据 `taa-human-journey-audit-2026-09-11.md` 的 J01–J08、J10–J13。仅记录本次产品池、手动大类及共享导航范围；SAA、TAA、后端质量由同批其他实现记录覆盖。

## 页面与联动

- 顶栏显示真实研究名称与范围研究日，删除虚构研究编号。常驻五步：产品范围 → 大类 → SAA → TAA → 产品配置；没有产品范围时不把孤立下游引用显示为已完成。
- 返回 SAA 携带大类配置名称和产品范围。产品配置尚未交接时引导回 TAA 保存页，已有交接草稿时恢复对应版本，避免绕过交接门禁。
- 已有产品池先显示可用数量、待复核项及“使用已发布版本开展配置研究”。复核在前，池定义、评价来源与人工例外折叠。编辑修订号只留在详情，避免与发布版本号混淆。
- 选池从发布入口预选目标版本；默认显示各池最新有效发布版本，历史按需展开；同一个池只能选择一个版本。继承平台研究日期并解释其与版本生效日期的区别；无有效版本提供创建/发布入口。
- 手机产品池使用具名、可展开的复核卡片，主结论与产品信息先显示；批量设置默认折叠。桌面保留局部滚动表格，父容器与输入增加宽度边界。
- 手动大类支持一次选择多只产品，显示已归属大类并禁用重复加入；导入的重复产品也在保存、拟合前拦截。首次加入单产品的自定义类内权重为 100%；多产品可一次等权。显示“类内权重”，提示大类之间的预算在 SAA 设置。
- 拟合失败保留在页面。开始日晚于平台知识截止时就地说明问题，保留输入。底部固定“检查大类数据 / 保存”动作，保存后可继续 SAA，保存窗口也支持直接继续；组合指标研究列为次要用途。
- 移除重复的原值累计收益行；滚动相关性默认折叠，按需研究。

## 草稿与失效边界

`frontend/src/app/allocationJourney.ts` 提供统一引用、路径及草稿 API。只保留用户输入与保存对象引用，不把计算结果或浏览器状态当作 PIT 证据。

- 手动大类按 `universeId` 隔离草稿；选池按明确发布版本隔离；产品池表单与复核按池及编辑修订隔离。返回页面、刷新及 PIT 重载可恢复输入。
- 改产品范围清理下游配置、基准、TAA 引用；改配置清理基准及 TAA；改基准清理旧 TAA。旧范围草稿仍可按原范围恢复。
- 修改类成员、权重、开始日或知识截止，会清理当前拟合/相关性结果。修改成员或权重后重新保存，才显示继续 SAA 的新配置入口。
- 口径切换保留定义，运行结果须重算。复核草稿跨服务器修订不自动套用，以免覆盖新复核状态。
- 当前研究按标签页保存在 sessionStorage：首次继承最近研究，之后只响应本页更新；另一个标签页的 storage 事件不会改本页导航。输入草稿仍按身份在 localStorage 持久化。
- 换产品范围同时清除旧名称、研究日和产品池版本；真实快照加载后补回。产品范围返回链接携带明确 universe，并按它隔离恢复草稿；元数据未知时直接显示“名称待确认”。
- 拒绝损坏 JSON、错误顶层草稿结构及研究引用的错误类型；存储不可用时编辑仍能运行，但不能保证刷新恢复。浏览器草稿不是服务器正式保存、发布或团队共享。

## 浏览器复查后的指标布局收敛

主任务实操发现大类检查和 SAA 回测一次铺开约 60 行年度指标。在现有横向指标组件上增加显式 `AllocationMetricsReview`，仅用于这两个调用点：

- 默认显示累计收益、年化收益、波动率、夏普、VaR、ES、最大回撤、卡玛 8 项核心指标。年度明细按需展开。
- 收益风险象限及大类同类一致性合并到“详细研究”；象限坐标只选核心 8 项，图表在展开后挂载，避免隐藏容器初始化尺寸错误。相关矩阵、净值图和主动作继续可见。
- 其他横向指标表保留原有全表默认行为。仅分组呈现原有数据，没有修改指标数值或 SAA 计算、日期、校验/PID/PIT 逻辑。

新增行为测试验证默认全表不变、精简显示 8 项、年度明细数值保留，以及展开后象限只有 8 项选择和同类一致性证据。三文件定向测试 19 项通过。后续另加活动标签页隔离与范围恢复测试，最终八文件回归共 50 项通过。SAA 交接另移除用局部方案日期覆盖范围研究日的导航元数据写入：基线 as_of 保持方案日期，范围研究日保持原值，最终加强断言定向 11 项通过。详见 `journey-routing-validation-2026-09-11.md`。
