# 情景中心页面对齐补充设计与验收

日期：2026-09-07。补充 [时序情景设计](regime-series-studio-design-2026-09-07.md)。

## 问题与本次范围

此前主入口仍展示模板目录，构建工作台在另一页；只调整工作台内部组件，用户看不到与指标中心一致的配置流程。本次直接修改 `/settings/scenario-algorithms` 的历史情景入口，参考当前指标中心的实际页面布局和操作顺序。本次不修改指标中心及共用计算组件，不改后端计算协议。

## 页面和操作

| 用户意图 | 本次行为 |
| --- | --- |
| 查找或新建算法 | 左侧算法库支持搜索、来源与实时/事后筛选，右侧原位打开；顶部提供新建、保存和另存 |
| 设置名称与输出 | 右侧基本信息和输出字段；主结果固定为枚举时序，状态名称与颜色可配置，支持数值辅助输出 |
| 自由搭建计算 | 同一公式卡片内切换画布、构建向导、高级公式，持续编辑同一份定义 |
| 使用构建向导 | 围绕当前输出展示其依赖步骤和计算摘要；选择步骤后打开参数编辑，资源入口添加变量、常量、算子、指标 |
| 编写公式 | 浅色源码编辑区，显式应用或还原；未应用的公式阻止保存、运行和模式切换 |
| 检查算法结果 | 独立“校验与预览”页签设置实时/事后、截至日与数据，展示状态区间、诊断及冻结结果 |
| 查看历史版本 | 库底部保留历史版本与旧版迁移目录；原版本、发布和实验能力继续可用 |
| 使用窄屏或大画布 | 手机切换算法库、定义、预览；桌面可收起算法库或全屏画布，Escape 退出全屏 |

输出配置和构建步骤保持指标中心的使用方式，枚举状态及情景结果仍使用情景领域展示。高级公式继续使用情景后端支持的受限图表达式，不宣称其语法与指标中心的所有公式语法相同。

## 编辑保护与兼容

- 切换历史识别和情景模拟时保留各自页面状态，情景模拟按需首次加载。
- 切换模板或已保存算法时保护已修改草稿；异步加载返回后再次检查请求身份和草稿签名，禁止覆盖较新的选择或编辑。
- 保留原来的公式应用、节点身份、撤销重做、冻结结果、运行取消和过期结果提示。
- 实时模式继续禁用事后节点，后端仍是时点限制的最终校验方；页面重排不改变计算结果。
- 新增 `RegimeDefinitionLibrary.tsx` 和 `RegimeGuidedFormulaPanel.tsx` 承担库与输出摘要展示；参数编辑复用既有情景编辑器，避免复制计算规则。

## 数学公式展示修复

后续反馈指出页面仍只有步骤和源码，没有正式数学排版。新增独立数学展示层：作者接口从当前图生成各输出的 LaTeX 和依赖步骤，三种构建模式均通过 KaTeX 展示。数值表达式复用指标中心的数学符号生成器；区间收益展示分式，区间阈值展示牛、熊、震荡及未识别的分段公式，使用实际连接的上下界。其他领域节点用具名算子表达，附带语义说明和标量参数，不伪造闭式展开。该展示层不执行时序计算，也不改写定义。

公式编辑后隐藏旧排版，应用成功后更新；切换输出只展示该输出及其依赖，异步旧响应不能覆盖新配置。LaTeX 文本经过转义，KaTeX 禁止可信 HTML，窄屏在公式内部横向滚动。

本次验收：后端 52 项通过；前端相关 64 项通过；8 套模板的 63 条公式全部通过实际 KaTeX 渲染。全仓前端 584 项通过，仍有 1 项既有资产配置发布引用测试失败。页面端到端 4 项通过、2 项按配置跳过；生产构建通过。全仓类型检查仍有已有错误，本次修改文件无报告。真实前后端验证峰谷公式、分步分式、四窗口、阈值从 3% 改为 12%、未应用草稿隐藏、模式往返和手机布局；后端重启预热完成，健康接口正常。指标中心代码未修改。
