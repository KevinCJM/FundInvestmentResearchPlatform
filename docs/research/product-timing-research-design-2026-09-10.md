# 产品择时研究：详细设计与验收

## 目标与范围

面向研究员和组合责任人，使用可编辑的计算步骤、条件和事件规则，完成日频 ETF 择时算法的构建、解释、样本外检验、比较和研究版本复用。首阶段规则型闭环的历史验收如下；后续已增加14个ETF改编模板、篮子与冻结训练研究，当前扩展契约见 [ETF算法改编设计](etf-algorithm-adaptations-2026-09-10.md)。场外基金申赎、股票母池原版复现和实盘执行仍不在范围内。

三处入口共用定义、服务与工作台：设置中的择时算法中心管理共享算法；产品研究中的产品择时研究绑定产品并验证；投前产品配置与择时引用冻结的研究结果。单产品退出到现金的独立研究可以进行，但下游改变大类总预算必须经 TAA 约束，研究信号不直接形成实际订单。

## 当前代码与复用决策

- `App.tsx` / `processRegistry.ts`：替换现有产品信号回测与产品择时原型入口，新增设置入口，旧链接保留重定向。
- `cal_indicators.typed_dsl`、`typed_numba_plan.compile_numba_series_plan`：唯一通用数学编译/执行实现；公式只允许已有因果数值序列算子，同一指标的多个输出共享一次 DAG 计算。
- 指标中心原有 `lag/difference` 缩短日期轴，不改变其既有数学契约。择时将它们作为独立同轴步骤，复用 `historical_regimes.v2_numba.unary_transform_kernel`，前缀保留 NaN；数值公式不能嵌入缩轴滞后。
- `historical_regimes.condition_numba`：共享数值比较和三值条件逻辑；条件为 -1 未知、0 不满足、1 满足，未知不静默变成零。
- `research_series` 的复权 NJIT 内核及活跃快照定位：保留既有数据含义。择时数据适配按产品一次投影读取多列，避免逐指标重复扫描。
- `custom_indicators.repository.AtomicJsonStore`：复用文件锁与原子持久化能力。算法定义、运行、发布使用择时自己的领域对象。
- 现有组合研究不能承担完整含成本产品择时执行；新增唯一择时执行内核，未来统一回测中心通过该服务消费，不在页面复制执行逻辑。

## 数据与对象

`TimingDefinition` 保存名称、说明、有向无环步骤、入场条件端口、可选退出条件端口及执行规则。步骤为 `{id,label,op,inputs,parameters}`，连接格式 `node_id.port`，ID 唯一，禁止环、自引用、悬空连接和类型错误。数字序列与条件端口严格区分。单定义至多 64 节点、每公式至多 128 内部节点、4 个输入。

`TimingStudy` 锁定定义快照、产品列表、研究起止日、样本外开始日、滚动分段数和价格口径。算法参数不从测试区间自动拟合；后续调参生成新实验并明确历史样本已被查看。固定规则的时间分段检查不宣称为前瞻实盘验证。

`TimingRun` 保存定义与请求快照、输入指纹、逐日净值/持仓/信号、逐笔交易、全部/样本内/样本外/分段/年度/月度统计、节点输出、执行审计和限制。历史运行不可被新定义或新行情覆盖。对照使用同一价格与日期口径、未扣费的买入持有基准；策略双边扣费用与滑点。

`TimingRelease` 只发布研究用途，锁定 run 与定义哈希，保留适用产品和限制。投前引用保存该不可变关联，不自动调整已有组合。未证明历史 PIT 数据时不能获授正式可交易回测或实盘用途。

## 算法与颗粒度

| 类型 | 职责 | 拆分原则 |
| --- | --- | --- |
| 数据源 | 输出 ETF 某个 OHLCV 字段 | 按字段显式端口，底层共享一次读取 |
| 数学算子 | 滞后、滚动、差分、算术、平滑等 | 从指标注册表派生目录与校验，复用原 NJIT |
| 指标引用 | 锁定指标版本并转成上游输入的数值计算 | 仅安全映射的序列/滚动标量进入目录，准备错误说明原因 |
| alpha-beta | 联合递推水平、斜率、创新值 | 三个输出共享不可分离递推，作为耦合内核；外围阈值独立 |
| 比较/逻辑 | 数值转条件、AND/OR/NOT | 三值缺失语义，用户可独立替换和预览 |
| 首次/确认/冷却 | 条件转离散事件并约束重复触发 | 显式状态、预热、缺失重置与边界规则 |
| 执行模拟 | 从事件与持仓推进现金、净值和成交 | 持仓/现金是不可分离状态机，事件计算在外部 |
| 评价 | 计算运行/交易/时间分区的研究指标 | 不反向参与信号图，未来收益标签不能成为特征 |

内置模板生成真实步骤和连接，不封装完整业务黑盒：

1. 均线趋势基线：价格、均线、比较、首次确认、反向退出。
2. 低滞后修复（参考 A2552 的结构）：前期收益/回撤、首次上涨、alpha-beta 斜率/创新值、独立确认条件。固定参数模板不等于 WF 的训练选择策略，也不继承其股票绩效。
3. 长期弱势反转（参考 A160S）：均线上方比例、前期回撤、连续上涨确认。本次是简化的可编辑结构模板，未复刻原量价过滤、训练策略或股票绩效。每一计算/过滤步骤可编辑，参数修改形成新定义。

算法库同时允许从空白添加算子。表单步骤与画布/公式展示共享同一后端定义，禁止前端文本和后端执行各持一套真相。

当前端口仅开放数值序列与三值条件序列。首次/冷却输出为逐日条件脉冲，连续确认输出为持续条件，目录显式声明事件语义；它们不是区间或状态编码，不允许接入事后分类状态或区间。未知与未触发分别为 -1 和 0，图表显示未知为空。

## 日频执行口径

- 收盘后才可得的入场/退出条件，只能在下一交易日开盘执行；以完整交易日历计数，不能把下一条有效行情当下一交易日。
- 买入当天不卖出。后续交易日止盈止损均以入场实际模拟价格为基准；跳空越界按开盘价格，日内同时触及按止损优先，明确这是日线保守假设。
- 普通退出在下一开盘处理；最长持有期到达后产生下一交易日退出意图。末日剩余持仓保留盯市，不能伪造同日卖出。
- 单产品研究资金只有一个头寸，持仓期间重复候选与实际成交分别计数；费用和滑点双边计入。买入持有基准使用同一价格口径，不扣费，界面明确提示。
- 原始行情和复权行情分开保存。复权价用于研究相对收益，不能解释为实际报价和可下单股数。默认 HFQ，支持明确选择 raw/QFQ；缺因子不填 1，QFQ 锚点绑定截止日。
- 执行区间缺必要 OHLC、非法价格或缺失交易日时，不输出看似有效的完整收益。特征窗口不足可以输出未知信号，但不填补价格。
- 整个执行区间缺失或非正成交量均拒绝运行；首期不实现停牌恢复、涨跌停成交队列或交易容量。交易日历需包含开市和休市日期，完整覆盖请求区间；尾部未知不能当作节假日。
- 明确披露时间晚于因子观察日的复权因子拒绝参与历史当日计算；未提供修订历史时只允许研究用途，不因此获得 PIT 认证。

## API 与任务边界

统一前缀 `/api/timing-research`：`GET /catalog`、`GET/POST /definitions`、`PUT /definitions/{id}`、`POST /prepare`、`POST /runs`、`GET /jobs/{id}`、`GET /runs`、`GET /runs/{id}`、分页节点/曲线/交易结果、运行比较、研究发布和投前绑定。

准备/保存阶段显式编译公式并冻结定义哈希，普通运行只调用已预热计划。运行使用有界后台任务队列，返回进度和产品级失败原因；不无限排队。每研究至多 12 个产品，每产品至多 12000 行，顺序处理产品以控制峰值内存，结果分页返回。任务和结果引用必须按后端快照校验，前端状态不构成发布权限。

具体持久化：每产品一个结果 JSON、一个固定 dtype 的 NPZ；小型 manifest 记录结果与输入校验和。JSON 最大 64 MiB、数组最大 128 MiB，读取校验 SHA256，发布和新建引用再次校验冻结输入。接口按产品加载后分页，不是磁盘流式分页；默认首个成功产品带完整明细，其余按选择加载。后台一个工作线程、最多四个在途任务；运行状态保存在进程内，重启后已完成记录仍可查看，未完成任务需重跑，已有分产品文件保留且底层提交可恢复。

比较必须使用相同产品、时间区间、样本外边界、费用、价格口径和市场输入指纹。定义哈希与输入快照分别保存，算法修改不会被误当成数据修改。

## 性能、内存与因果性

- I/O 边界将日期规范为 int64，价格/量为 float64，条件为 int64；后续计算无 Pandas、object 数组或反复转换。
- 只读取必要字段和目标产品，数组冻结只读；源节点仅引用已有数组。连续窗口传基础数组与 start/end，跨节点不复制源数据；输出与工作缓冲按需要分配。
- 数据源、条件和执行核接受只读非连续视图；通用公式的固定签名要求读取边界提供 C 连续数组，不在节点内复制以迁就签名。执行前估算工作量不超过 2 亿、工作区预算不超过 64 MiB。
- 模板与保存公式共用通用指标编译器，领域 NJIT 核心固定签名并禁用请求期新签名。启动预热和保存/显式准备承担编译；运行请求缺计划直接返回可操作错误。
- 复权、日期规范化、解码和持久化是允许的边界复制，记录其范围；不将 `asarray/copy=False` 当作零拷贝证据。
- 测试实际 `np.shares_memory`、只读输入、非连续视图、别名污染、dtype/NaN/边界、未来扰动与固定签名数量。大样本基准记录实际耗时及峰值内存。
- 前端验证固定签名执行审计。数据历史修订未保证时保留研究能力和限制，不给出正式 PIT 认证；事后状态可用于评价分组，不能接入可执行信号。
