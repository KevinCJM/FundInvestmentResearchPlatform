# 配置研究：决策与验收纪要

本页保存投前、SAA/TAA、风险标尺和实施研究的历史证据。当前业务入口见 [投前研究](../pre-investment/README.md)，模型勘误见 [CMA 模型决策](../research/cma-model-decisions.md)。下列日期与测试数字属于当时版本；本次文档整理没有重跑这些业务验收，不把专项、重叠用例或历史结果累计为当前全仓通过。

## 已确认的关键决策

| 主题 | 保留的决定与原因 |
| --- | --- |
| 两条研究路径 | Product-first 从产品池构建大类；Strategic-first 允许无产品的战略研究，进入实施时才要求显式产品映射。研究诊断不等于采纳或交易授权。 |
| 有效前沿 | 恢复目标收益网格逐点求解、风险分桶代表性和权重步长契约。目标数 2–200 与单点预算 1–1000 独立；不能以三个代表点的迭代次数替代整条前沿。 |
| 精炼 | 比较使用原候选统一目标，合并后重建共同 Pareto 集合和特殊代表点；失败保留原因，不插值制造成功点。非二次风险的 BFGS-SQP 不称为 SLSQP 或全局最优。 |
| 目标诊断 | 资金建议必须回代同一模拟、约束与冻结种子；Wilson 下界不表示现实收益保证。改变研究截止日使未保存候选失效，历史快照仍按原时钟解释。 |
| TAA | 费用口径、信号可得日、独立分量有效期与实际持仓共同约束；未来待生效信号不能提前延长已应用目标期限。两条消费者共享资格和应用校验。 |
| 风险等级 | C1–C5 使用版本化参考标尺；不因每个客户临时资产池重新定义等级，不把参考组合诊断自动变成正式 SAA。 |
| LTCMA | 发布时再检查先验生命周期；最终 UTF-8 制品大小在写入和索引变更前校验，读写共用 8,000,000 字节上限。预览有效不意味着发布必然仍有效。 |
| Multi-CMA | A 融合参数，B 保留各模型独立风险约束。外逼近中的切面、残差、目标界和数值停止全部在预热 NJIT 内核；Python 只编排和检查墙钟时间。 |
| 研究包 | 验证绑定候选 hash/版本，定稿追加不可变记录；失败尝试可审计，不把旧报告套到新候选。费用、实施风险和余款资金续算使用同一冻结候选。 |

## 可复核的数值与资源证据

- 产品实施风险保留残差协方差 Q，不能只聚合 Beta：两产品 Beta=1.2、资产波动 10%、残差波动 5% 且完全相关时，产品组合波动为 13%。
- 自融资费用：100,000 资金从 50/50 调至 60/40，买卖各 5bps 的受控例成本为 9.9990001；不是先忽略费用定目标再扣现金。
- 资金续算覆盖 1/3/13/37 月、零本金未来投入、零剩余期限、部分已缴、漏缴及旧整数年 ABI；13 月由真实 SAA 链端到端验证。旧 ABI 与新月份契约分开。
- 实施基准：37 月 × 2000 路径 × 3 产品，63.05/64.13/63.67ms；只读步长视图复用 1,776,000 字节底层内存，无请求新签名或 Python fallback。仅该样本和执行进程有效。
- PR43 同种子最大轴：外逼近旧 0.02646/0.02479/0.02590 秒，新 0.02856/0.02782/0.02758 秒；目标界差 5.480574327698662e-12，均 39 次 master；traced 峰值 675,564→677,804 bytes。此证据说明语义保持，不证明提速，也不含启动、锚点、资金和 I/O。

## 未确认关闭：奇异协方差前沿

2026-09-13 在 `2329845b345665a9bacc95e36b814868a8e288ea` 的独立复现：A 年收益 3%、波动 10%，B 年收益 9%、波动 20%，两者不相关，C 的收益序列逐项等于 A；只有资金守恒和各资产 [0,1] 约束。最低风险解析解为 `wA+wC=0.8, wB=0.2`，收益 4.2%、波动 8.94427191%；三资产前沿应等同两资产。

当时两资产在 20/200 个目标、单点预算 1000 下全部成功；三资产两个请求都在最低风险端点耗尽预算，目标未开始，返回 `range_unresolved`。驻点残差约 2.78e-17，但平坦方向步长约 1.39e-7，超过 1e-9 步长门槛。随机种子 0–19、300/1000 两档预算共 40 次复制资产探针也失败。

后续交付记录明确保留该问题。本次没有取得当前 HEAD 下同一解析复现通过的证据，因此状态为**待当前版本复验，不能标已关闭**；不是断言当前一定仍失败。验收应覆盖半正定/近共线、重复资产独立单项和分组约束，保持风险矩阵与经济语义，不能删资产绕过。`max_iterations=1` 的诚实失败测试不能替代此复现。

同次非二次风险探针 12 组 × 20 目标：VaR 144/240、ES 110/240、下行波动 135/240、最大回撤 127/240 成功。它们是合成样本工程观察，不是市场成功率；诚实失败不等于全局最优证明。
