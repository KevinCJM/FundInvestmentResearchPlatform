# 内置时序指标迁移到通用滚动计算：架构与实施设计

## 1. 目标与代码事实

本次只迁移指标中心的5个内置时序指标：20日收盘价均线、20日布林带、10日成交量均线、KDJ（9,3,3）、5日滚动年化夏普。它们当前最新为 revision 2，DSL/算子注册表为2.4.0；定义使用 `rolling_window + 普通归约`。通用区间作用域 `rolling_apply` 已可运行完整区间标量子图，但尚未被这些内置定义使用。

本次迁移不新增业务指标、不改变默认数值参数、不覆盖已保存的历史定义，不自动改写自定义指标、运行快照或显式锁定版本的下游引用。新指标计算必须真实进入通用区间执行器；仅改显示名称不算迁移。

代码入口：`series_definitions.time_series_builtin_indicators` → `IndicatorRepository` → `series_service` → Typed DAG → `rolling_scope.compile_scope` → 已预热NJIT计划。

## 2. 版本与上线策略

保留相同 indicator_id，新增 revision 3，目录默认返回v3。已有v1/v2数据契约仍经唯一当前编译/数值实现执行，不保存备用算法源码。迁移前已计算10份历史定义的SHA-256（排除创建/更新时间）；迁移后用回归测试验证全部字段不变。

内置目录的 `list` 只返回每个ID的最新版本；`get(id, revision)`、`list_all_versions` 继续提供历史读取和启动预热。锁定v1/v2的快照与运行不跳转v3；未锁定版本的新调用使用v3。通用滚动Sharpe的来源协议改为3.0.0，其源标量指标ID、revision、定义hash继续锁定。

DSL2.4.0增加可选参数签名，不改变现有2参数/4参数表达式的规范形式与数学语义。作用域实现版本进入编译计划身份，使重启后的新实现不误用旧计划；生产请求禁止临时编译。

## 3. 五个指标的目标计算图

| 内置指标 | v3定义 | 必须保持的口径 |
|---|---|---|
| 收盘价均线 | `rolling_apply(mean(market_close),20)` | 最近20个观察位置，满20个有限值才输出 |
| 成交量均线 | `rolling_apply(mean(volume),10)` | 原日期轴不变，满10个有限值才输出 |
| 布林带 | 中轨M=`rolling_apply(mean(market_close),20)`；S=`rolling_apply(std(market_close,0),20)`；上/中/下轨为M+2S、M、M-2S | 总体标准差ddof=0，倍数2，通道ID/顺序/精度不变 |
| 滚动夏普 | `rolling_apply(完整来源Sharpe标量公式,5)` | 5个收益观察对应6个净值点；ddof=1；原无风险利率及年化频率不变 |
| KDJ | 9期高低极值分别使用通用滚动；RSV、K/D递推、J保持原计算图 | 不足9期时允许1个有限观察值；K/D初始50，平滑3；零分母50；J不裁剪 |

布林带不分别包裹3个完整通道公式，以免重复求均值和标准差。相同M/S表达式形成共享DAG节点；只有两次滚动作用域调用，外层加减不增加滚动语义。KDJ同样共享低价极值、高价极值、RSV、K、D节点。

## 4. KDJ不能直接替换的兼容缺口

原 `rolling_window(low,9,1)` 在初始不足9期或窗口含缺失值时仍可使用其余有限值求极小值。现有通用滚动默认要求完整有限窗口。直接替换成 `rolling_apply(min_value(low),9)` 会改变首8期及缺失后的K/D递推，甚至影响后续整条曲线，故禁止如此迁移。

方案：给通用作用域新增可选 `min_periods`，并用独立的有限值判断原语及现有条件归约明确表达缺失规则，不写KDJ专属滚动分支。

```text
rolling_apply(min_where(market_low, finite_mask(market_low)), 9, 1)
rolling_apply(max_where(market_high, finite_mask(market_high)), 9, 1)
```

`finite_mask` 只负责逐项判断是否为有限数：NaN、正负Inf为false，真实0为true。`min_where/max_where` 已是普通区间条件归约。这样跳过缺失是计算图的显式语义，不是滚动引擎偷偷补零或删除行。

KDJ的递归平滑不能放进作用域。它们继续在整个时间轴上继承上一次有效状态；只有区间极值每个窗口独立重算。

## 5. 通用作用域的兼容扩展

保留已有简写 `rolling_apply(calculation,window)` 和规范4参数（含系统日期、年化配置）。新增简写3参数 `(calculation,window,min_periods)`，规范为5参数 `(calculation,window,dates,annual_rate,min_periods)`，避免与既有4参数发生歧义。

默认不传min_periods时，仍为完整有限窗口，已有自定义公式结果不变。显式传入时：

1. `window/min_periods` 必须是1至5000的整数常量或作者开放的整数参数，且min_periods不大于window。
2. 右对齐窗口仍按观察位置取 `[max(0,t-W+1),t+1)`，不为凑够有效样本向前扩大窗口。
3. 只检查窗口有效观察数是否达到min_periods，不压缩时间轴，不创建筛选后的数据副本；原始视图传给区间图。
4. 部分有效输入的具体计算规则由区间图明确处理。本次KDJ通过finite_mask+条件归约跳过非有限值；普通mean不会被自动变成另一种nanmean。
5. 多输入按共同日期位置计有效观察，不分别压缩后拼接。收益窗口保留原始起点边界；局部样本数、天数按实际子区间重建。
6. 公式、画布、可变参数校验、取数lookback/预热、因果审计、Excel都按同一签名和约束处理。

这只是统一窗口调度契约的扩展，不增加rolling_kdj/min/max等专用业务算法。

## 6. 前端与人类操作

不新增页面。用户仍在指标中心选择同名内置指标，看到v3及原来的输出通道。画布展示“区间统计内容→滚动计算”，KDJ有限值筛选与递推步骤真实可展开/编辑。

普通滚动仍只需填写窗口。新增的“最少有效观察数”作为可选高级配置，不强迫所有用户填写。KDJ的说明明确“窗口9期，至少1个有限值即可计算”。窗口和最少观察数由同一参数系统识别；复制为自定义指标后，可选择开放为参数并设默认值。内置指标保持只读及原固定参数，不在迁移中擅自开放新运行时覆盖权限。

参数校验失败时应展示字段和原因，不能把min_periods静默截断为window。保存来源、预览、参数临时覆盖和恢复默认工作流不改变。

## 7. 内存、执行与性能约束

所有数值循环进入预热NJIT；数据边界统一连续float64数组，mask为uint8，日期为数值日序号。窗口使用基本切片视图，不复制原始窗口，不物化T×W矩阵；输入只读，不修改共享缓存。finite_mask只分配必要的小型布尔结果，条件归约直接扫描源视图和mask，不创建筛选后的值数组。

复用已有作用域生成器，部分窗口由编译期签名决定，正式计算不查指标名、不调用Python callback、不增加签名。保留运行前预算检查及异常路径内存释放。历史专用内核只服务仍实际被引用的历史契约。

通用算法复杂度仍是各窗口子图成本之和，不能声称自动等价于O(T)滑动增量。需比较v2/v3稳态时间，并记录通用性带来的成本；布林带/KDJ必须证明共享节点没有重复求值。结果与必要的单窗口中间量可以分配，零拷贝不代表零分配。

## 8. Excel与因果性

Excel使用相同区间和局部子图。finite_mask导出原生ISNUMBER判断（输入非有限值导出为空）；KDJ的条件MIN/MAX保留部分窗口规则。默认完整窗口继续COUNT=窗口长度；部分窗口使用共同有效计数≥min_periods，不引用窗口外数据。过大工作簿按预算明确拒绝，不输出伪造公式。

因果审计继续审查完整滚动作用域，不能把作用域内归约误当全样本提前计算。新增有限值原语审查时点一致性；KDJ递推因果性和预热状态不因迁移被重置。未来扰动不能改变过去结果。

## 9. 修改范围与架构四问

- 定义层：series_definitions新增当前v3目录数据，保留真实使用的历史数据契约。
- 通用引擎：rolling_scope、Typed DSL/注册表、参数及历史推断，仅扩展统一min_periods；普通finite_mask作为独立数值原语。
- 展示/导出：复用现有元数据、画布、参数UI及原生Excel编译；只补新输入说明。
- 测试：新增迁移专项、历史hash、逐点等价、缺失/短窗口、共享DAG、实际NJIT、参数/Excel/浏览器。

滚动作用域只解决窗口遍历和区间上下文绑定；finite_mask只解决有效值判断；条件极值、递推均独立可替换。把它们合成KDJ黑盒会丧失组合性；把递推也按窗口重置会改变状态语义。现有普通算子可组合完成业务公式，因此本次不新增业务黑盒或另一套滚动数值实现。

## 10. 验收门槛

- 最新目录恰为5个时序指标、均为v3，每个通道可达路径包含rolling_apply且不含rolling_window/历史rolling包装。
- 历史v1/v2定义10份hash保持不变，历史版本可读取/计算/预热；显式版本引用不改写。
- 完整数据逐点比较v2/v3并独立参考均值/总体标准差/Sharpe/KDJ；缺失位置相同。浮点归约顺序允许明确小容差，不接受数学口径改变。
- KDJ首1至8期、NaN/Inf、连续缺失、零波幅、零价格有效输入、K/D状态延续及J越界均验证。
- 布林带恰两次scope调用；KDJ极值各一次、递推各一次；无不必要全历史子图执行。
- 参数默认/覆盖、非法min_periods、计划复用、只读视图、异常分配均验证。
- Excel与画布往返、前端构建/专项测试、桌面与窄屏真实后端浏览器验证。
- 最终记录测试命令、通过数量、性能差异、已知全仓阻塞；未验证项不宣称完成。
