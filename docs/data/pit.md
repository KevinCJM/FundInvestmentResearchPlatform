# PIT：数据可得时点与决策时钟

本页是全项目时点语义的主要入口。价格／复权见[复权契约](adjusted-price.md)，研究依赖见[投前研究](../pre-investment/README.md)。代码事实与历史缺口必须分开；本轮整理不构成全链路 PIT 认证。

## 四条时间轴

| 时间 | 含义 |
|---|---|
| event time | 净值、交易或经济事件属于哪一天 |
| available time | 信息最早何时可被观察者取得 |
| version time | 使用的是哪次发布／采集的修订 |
| decision time | 本次选产品、拟合、生成信号或调仓站在哪一天 |

研究日截断必须依据可得时间；今天用全样本训练后截短输出不能还原历史决策。回测每个调仓日重新约束可见输入，不只在整次运行开始截断一次。

## 用户口径与优先级

一个 PIT 版本包含 as_of、run_mode 和表指纹。系统保存 active_release_id；标签页临时选择保存在 sessionStorage；显式计算入参优先于标签页选择，标签页优先于系统默认。显式关闭 PIT 使用 `X-Pit-Off: 1`，不能用缺参表示关闭。

版本携带日期／模式，界面不重复维护另一份日期。旧版本缺日期回落到自身 available_through，缺模式不自动放松严格系统口径。切换后让旧结果失效；坏请求头返回 400，不能静默改用其他口径。`/api/pit/*` 不受失效临时覆盖锁死，用户始终能够恢复系统默认。

口径元数据（名称、备注、日期、模式）可按现有接口编辑并记录 updated_at；表清单与指纹不可改。日期不得超过该版本自己的 available_through。当前全平台使用的版本删除返回 409，先切换再删；溯源 parent 不作级联删除。

## 数据能力与诚实边界

A/B/C 是声明与体检的能力分级：可得时间覆盖、回溯修订、历史快照及声明滞后共同决定等级。严格模式按对应 gate 拒绝不合格输入；研究模式保留警告，不把未知当作干净。

封版中的 fingerprint 是元数据指纹，不是逐行内容 hash，不能据此证明物理文件未变或可还原任意 vintage。历史维表快照从采集时起积累；更早日期只能按 INTERVAL 或 LATEST_ONLY 解释。INTERVAL 可以恢复成员生命周期，不恢复当年的全部属性；人工批准／排除单列 manual_only。

## 消费链与共享实现

| 消费环节 | 合同 |
|---|---|
| 通用取数 | `pit/frame.read_pit` 按目录做维表回放、可得时间解析、截断和血缘；缺失公告时间按模式拒绝或显式降级 |
| 指标／评价方案 | 有研究日时跳过无 as_of 的全历史指标快照；产品池也经共用网关解析口径，不能成为第二个绕过入口 |
| 市场概览 | 仍可能使用全历史筛选快照，响应 `snapshot_is_hindsight` 提示；不冒充当日研究排名 |
| 大类构建 | 净值、合同分类、指标画像和可投资域均核对时点；无时间轴画像不能冒充历史版本 |
| 历史配置／SAA | 共用 `load_allocation_nav` 检查序列 as_of、available_at 和池子研究日；权重和前沿返回 PIT 血缘 |
| 回测 | 通过 `visible_at` 在每个决策日切窗；并行 worker 和缓存键携带同一口径 |
| 情景／TAA | 训练截止、状态确认信息和发布资格沿实际依赖传播；事后状态不能因为下游只是比较运算变成实时信号 |

净值计算日与池子选择日必须合成同一判定。前端显示 findings、decision_clock、产品域研究日及未知状态，不只展示最外层 warnings。

## 仍需核验的缺口

以下来自旧文档末轮记录，未在本次重新复现，保持“待核验”，不得当作已关闭或新确认缺陷：

1. `data_release_id` 是否在所有生产消费者中真正选择物理 vintage；仅保存引用不能证明使用了那一批数据。旧记录明确封版尚不能物理还原 vintage。
2. run_mode／严格门禁是否完整到达每个计算入口；旧“read_pit 仅测试调用”的结论已由合同分类接入部分取代，不能再照抄。
3. 可投资域 snapshot 创建时 research_date 与平台日期是否校验。末轮记录在大类决策点已有严格拒绝／研究告警，创建入口仍需检查。

核验需给出实际消费者、输入 vintage、决策日期反例与测试，不以页面已有版本选择器作为完成证据。

## 回归与历史决定

保留共享入口而不复制每个端点的日期兜底；显式参数仍优先。回归应覆盖研究日禁止快照捷径、发布日期改变回测结果、未来池子研究日、维表 INTERVAL/LATEST_ONLY、严格拒绝与研究警告，以及 worker／缓存口径一致。

旧文档九轮开发过程、旧页面草图和当时数据数量已移除；历史原文可从文档整理前 Git 基线追溯。具体回归入口由 repo_map 的 PIT 相关模块维护。
