# 峰谷定界法：事后牛熊震荡区间识别

本功能位于“情景算法中心 → 历史情景识别 → 事后识别”。采用 Pagan–Sossounov（PS）思想的确定性实现；不是作者原始程序的逐行复刻，也不是实时交易信号。

依据：[Pagan & Sossounov, A Simple Framework for Analysing Bull and Bear Markets, Appendix B](https://onlinelibrary.wiley.com/doi/full/10.1002/jae.664)。原文以局部极值、阶段长度、完整周期长度、样本端点及大幅涨跌例外筛选牛熊阶段。局部极值使用左右两侧数据，且端点筛选依赖全样本，因此本实现只允许事后研究。

## 默认流程与参数

沪深300收盘价 → 选择日频或月频 → 峰谷筛选 → 完整牛熊波段 → 震荡区间合并。

原“峰谷定界法”模板升级为版本2，保留月频；另有“峰谷定界法 · 日频牛熊震荡”入口。两者均默认启用震荡识别。旧定义未提供震荡开关时保持关闭，不改写已有定义或结果。

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| 左窗口 | 8 | 比较候选点之前8个输入观测 |
| 右窗口 | 8 | 比较候选点之后8个输入观测，独立控制确认延迟 |
| 最短牛熊阶段 | 4 | 相邻峰谷至少间隔4个观测 |
| 最短完整周期 | 16 | 相邻峰峰或谷谷至少间隔16个观测 |
| 首窗口 | 6 | 排除距连续有效样本开头不足6个观测的极值 |
| 尾窗口 | 6 | 排除距连续有效样本末尾不足6个观测的极值 |
| 大幅波动例外 | 0.20 | 阶段涨跌幅绝对值严格超过20%时，豁免最短阶段约束 |
| 启用震荡识别 | 是 | 新模板默认开启，旧方案默认关闭 |
| 小波段幅度门槛 | 0.03 | 单个候选波段涨跌幅绝对值不超过3% |
| 震荡最大振幅 | 0.06 | 合并整段原始价格最高值／最低值−1不超过6% |
| 震荡方向效率上限 | 0.25 | 净位移／累计绝对位移不超过0.25 |
| 最短震荡长度 | 日频20；月频3 | 结束边界索引减开始边界索引的下限 |

长度单位统一为**算子输入观测数**。月频的8表示8个月度观测，日频的8表示8个有效日频观测。切换频率后必须相应调整长度参数；缺失月份不会自动补齐为交易数据。例外不豁免完整周期要求。上述阈值是研究起点，并非实证最优参数。放大窗口和阶段／周期约束通常会得到更粗的划分，但因多条筛选规则相互作用，不保证所有参数变化都严格单调。

四窗口按字段分别兼容旧参数：未指定 `left_window/right_window` 时使用旧 `window`（再缺省为8）；未指定 `head_window/tail_window` 时使用旧 `endpoint_window`（再缺省为6）。新字段优先，单独改右窗口不会改变左窗口。界面仅显示四个新参数，打开旧方案时展示真实继承值。每个候选点仍同时受对应极值窗口和首尾窗口约束；缩短右窗口、尾窗口可能保留更近的拐点，但不外推最后一段。

## 确定性筛选规则

1. 不做平滑或趋势去除；缺失、无穷及非正价格切断连续样本，禁止跨缺失段连线。
2. 使用完整左右窗口找极值；平台同价保留较早候选点。同类候选连续出现时，峰保留更高者，谷保留更低者；相反类型还须满足正确的涨跌方向。
3. 排除被样本开头或结尾价格超越的首末峰谷。
4. 完整周期太短时，保留其中更极端的同类端点，移除较弱端点及中间反向点；同价保留较早点。
5. 阶段太短且不满足大幅波动例外时，边缘短段移除边缘转折点；内部短段比较两侧相邻阶段的绝对对数价格变化，移除相邻变化较弱一侧的端点，同强度移除右端点。
6. 每次删除后重新检查交替、端点、周期及阶段约束，直至稳定。每轮至少移除一个点，迭代有界。

上述删除顺序、内部短段择点、同价规则及缺失段处理是本项目明确规定的实现选择。

## 震荡合并规则

本项目增加的后处理规则，不属于原版PS两态算法：

1. 只在已保留峰谷界定的完整区间内寻找候选，至少包含两个相邻反向波段；每一段均须满足小波段幅度门槛。
2. 从候选起点逐段扩展，使用含左右边界的原始价格，计算整段振幅及 `ER = abs(末价 - 首价) / sum(abs(逐期价差))`。采用价格路径效率的定义见 [TradingView KAMA说明](https://www.tradingview.com/support/solutions/43000773012-kaufman-s-adaptive-moving-average-kama/)。分母为0时ER为0；原始峰谷算法没有完整边界的平价样本仍为未分类。
3. 同时满足整段振幅上限、ER上限、最短长度。若至少有两个峰和两个谷且峰、谷均严格连续抬高，或均严格连续降低，保留趋势，不合并为震荡。
4. 按时间从左向右选择最早起点可延伸到的最长合格区间；ER暂不合格仍继续检查后续反向段，振幅超限则停止扩展。不能跨越大波段或未分类段。
5. 相邻震荡色带不能拼成超出全段阈值的漂移区间：一个已接纳区间无法继续扩展时，至少保留紧接着的一个原始趋势波段，再搜索下一段震荡。此保守分段顺序是明确的实现选择。
6. 合并只改最终状态，保留原始峰谷、连线和单波段涨跌幅；新增独立的震荡起止边界、整段振幅、ER及波段数量用于结果解释。

## 区间与时点语义

- 原始波段谷到峰为牛市、峰到谷为熊市；只有满足上述合并规则的完整区间才改为震荡。启用震荡时状态按牛市、震荡、熊市排列；关闭时兼容旧牛、熊两态以及新三态定义。无法判定的样本仍为未分类。
- 完整区间采用 `[左峰谷点, 右峰谷点)`；共享转折点归入下一段。最后保留的转折点及其后的未完成阶段不外推状态。
- 首个保留点之前、最后完整阶段之后及缺失位置均为“未分类”。峰谷连线包含区间右端点，用于展示边界；连线不是滤波值或预测价格。
- 识别时间保守取峰谷输入全样本的最晚数据可用时间；补充后续数据可能修改历史划分。结果均无交易生效日、不可执行，`is_final=false`；已保存的结果制品仍保持不可变。
- 实时模式在前端禁止运行，并由服务端在读取数据、排队和执行前拦截。不能通过自定义图省略时点端口绕过限制。

## 验证
