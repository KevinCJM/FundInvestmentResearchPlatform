# 全项目审核问题修复设计

## 范围与基线

依据 `project_code_logic_audit_2026-09-10.md` 修复 A01–A07，核对 E01–E05。只修改已复现问题、阻塞链路及对应测试；保留工作区其他未提交改动，不提交、推送、重启正式服务或执行真实数据发布。

## 修复路径

### A01 / A05：时序轴与窗口边界

- 日期是否存在与值是否有限分离；Parquet 中已有日期必须保留，NaN/Inf 不补零、不删日期。
- 收益率从未压缩的净值轴派生；收益率作为日期轴也保留起点与缺口。
- 返回窗口的输入行数、收益观察数与净值前置观察点明确区分。只为确实依赖窗口前净值/日期的计算读取前置观察点，不把每条输入序列的首个有效收益无条件丢弃。
- 有限完整窗口不足时输出空；显式最少观察数仍由原合同决定。日期转换只在输入边界一次，窗口保持切片视图；输出与必要状态数组允许分配。
- 已保存表达式、revision 与快照不改写；运行引擎/缓存身份更新以避免命中错误旧结果。

### A02：PIT 与结果同一所有者

- 删除“最近一次取数”的进程全局变量与 getter。
- `compute_classes_nav` 返回本次计算的结构化结果（净值、相关性、指标、lineage、available_at），沿实际两条调用链显式传递。
- 对外 JSON 契约不变。Pandas 只在边界和结果封装使用，核心 NJIT 路径不变；不加全局大锁串行化计算。
- 用两线程受控交错验证各自 lineage 和可得日，用请求保存链路验证落盘使用自己的可得日。

### A03 / A04：跨中心统一滚动语义

- 使用共享的作用域感知检查，区分窗口内区间聚合和窗口外全样本聚合。不能简单将 mean/std 加入因果白名单。
- 原 `rolling_window → reducer` 合法；`rolling_apply` 的完整 body 按已有区间闭合契约审查；同一 reducer 被窗口外使用时仍须拒绝。
- 数值输入来自图上游；系统日期来自真实共同轴；年度配置来自锁定指标定义。系统绑定不作为用户数据端口，不接受伪造覆盖。
- 历史情景与择时均使用统一 Typed DAG + 预热 NJIT，旧引用保留版本身份，不新增中心专属 rolling 数学实现。
- 内置多通道、最少观察数、KDJ 状态、输出缺失和知识可得时点维持可追溯。真正的全样本、未来偏移、不明时点继续失败关闭。

### A06 / A07 与工程检查

- 非法日期与空 classes 在输入边界返回明确 400/422；不要把未知异常统统改为参数错误。
- 补齐风险模型中心导航语言项；校验导航与国际化合并结果。
- 修复 ETL 测试的真实类型错误、缺失导入和遮蔽测试，保留测试意图。
- Excel 校验独立统计口径与真实单元格关系，不只调整字符串。
- 浏览器用例更新为当前 UI 和作用域图，并验证真实编辑、预览、保存、窗口变化、无白屏及遮罩正确关闭。
- Hermes 未跟踪引用不通过放宽校验或擅自暂存其他任务文件处理；报告发布前需要的 Git 范围。

## 同轮复测补充

- 指标中心目录返回较慢时，初始化只补齐尚未更改的技术版本默认值，不能覆盖用户已输入的名称、公式或参数；注册表加载完成前不允许校验。增加人为延迟元数据响应的回归。
- 全屏图表同时更新 ECharts 画布尺寸和图内布局；ResizeObserver 使用实际容器尺寸，检查实例生命周期，不重新取数或重置缩放。覆盖增大/缩小视口与卸载清理。
- 浏览器用例按当前三步接口配置与模型独立参数面板操作，不强制点击隐藏元素；模拟复测还核对请求中的实际周期和路径数。
- 索引覆盖率测试固定研究时钟，不放宽生产数据时效要求；ETL恢复测试引用当前实际模块，不恢复已删除的兼容导出。
- 历史兼容矩阵扩展为两个下游中心 × 五个内置时序指标 × 三个 revision，逐通道比较实际数值和日期。PIT补充实际配置保存路径，验证另一计算插入后落盘可得日期仍正确。

## 验收

新增独立回归先复现问题；专项通过后跑后端全量、前端全量、类型/构建/国际化、浏览器矩阵及静态检查。跨中心检查必须包含 v3 的五个内置指标和自定义标量滚动，比较真实数组而非目录 available 标记。内核签名不增长、无 Python 回退、输入只读及视图共享须验证。

涉及的滚动控制只负责窗口作用域、统计/条件各有独立职责；继续拆分 K/D 递推会改变状态，故保留原耦合平滑内核。没有增加业务黑盒算子或第二套数值算法。
