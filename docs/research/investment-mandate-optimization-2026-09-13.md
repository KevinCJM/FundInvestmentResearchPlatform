# 投资目标与边界：优化方案与产品评审

检索与核对日期：2026-09-13。范围：投资目标工作台、CMA/SAA消费与政策应用门禁。不涉及真实交易、市场数据下载或Git提交。已有未提交的目标研究实现已在本轮开始时存在，作为现状保留，不重复实现。详细数据与数值设计见 `investment-mandate-research-design-2026-09-13.md`；实际运行结果另见验收记录。

## 一、调研结论：把愿望变成可核验的投资授权

| 一手来源 | 可采用的原则 | 产品落实与不能冒称的能力 |
| --- | --- | --- |
| [CFA：Portfolio Planning](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/basics-of-portfolio-planning-and-construction) | 先识别资源、目标、风险承受能力与意愿，再形成IPS；流动性、期限和实施约束不是可有可无的备注。 | 输入资金事实、目标类型和风险边界；不把风险厌恶系数直接等同客户风险测评分数。 |
| [CFA：Principles of Asset Allocation](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/principles-asset-allocation) | 资产端、相对负债、目标驱动配置的成功标准不同；规划与具体产品实施可以分层。 | 绝对预期收益、相对真实基准、终值与期间支付采用不同量化判断，不强迫金额目标填最低算术收益。 |
| [CFA Research Foundation：Risk Profiling](https://rpc.cfainstitute.org/research/foundation/2017/new-vistas-in-risk-profiling) | 风险意愿不等于资金损失承受能力；必要现金流、目标优先级及灵活性影响风险容量。 | 保留必要支付，显示现金缺口和预警，说明所需回报不是提高CMA预期的理由。本轮一个终值目标及多笔必要支付，不冒称多目标资金分配优化。 |
| [J.P. Morgan AM：Cash IPS](https://am.jpmorgan.com/us/en/asset-management/liq/insights/liquidity-insights/cash-investment-policy-statement/) | 现金流盘点在流动性目标前；运营、储备与战略现金分层；责任与复核机制需明确。 | 组合外储备与组合内流动性底线分开，后者由近期压力净支出推导，并与人工底线取更严。不是完整逐产品赎回、结算和市场冲击模型。 |
| [Vanguard：V-family models](https://corporate.vanguard.com/content/corporatesite/us/en/corp/what-we-think/investing-insights/v-family-models.html) | 前瞻市场分布、组合构建和财富生命周期计算相互连接；同时关注财富分布与耗尽风险。 | 复用CMA/SAA，输出支付不足概率、终值分位、平均缺口和调整代价；基线为透明月度组合代理，不宣称复刻VCMM/VLCM。 |
| [BlackRock：Capital Market Assumptions](https://www.blackrock.com/institutions/en-global/institutional-insights/thought-leadership/capital-market-assumptions) | 区分市场波动与均值估计不确定性；情景路径及现金需求影响配置。 | 中央假设与保守敏感性并列，后者不捏造发生概率；模拟采样区间不覆盖模型或预测误差。 |
| [W3C：Multi-page Forms](https://www.w3.org/WAI/tutorials/forms/multi-page/) | 按业务逻辑拆长表单，标识进度，使可选步骤和返回修改可理解。 | 四步导航、聚焦步骤标题、完整标签、明确未能继续的原因；主任务与历史版本分开。 |
| [NIST：Binomial Confidence Intervals](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm) | 成功比例的区间应与样本数共同解释，不能只展示一点估计。 | Wilson 95%采样区间作为明确诊断口径；追加资金测算同时给出点估计口径和与采纳门槛一致的保守口径。 |

以上来源支持业务原则，不为本项目默认数值、收益假设或算法表现背书。具体算法是本项目的可审计实现选择。

## 二、目标流程与交付物

资金与支付事实 → 选择成功标准 → 硬边界/偏好/预警分层 → 确定性资金测算 → 引用CMA并诊断代表组合 → 人工核对 → 不可变目标版本 → SAA重新计算并采纳 → TAA/产品应用的共用政策检查。

先保存输入再建立CMA是合法分支，必须标为“仅保存输入”；它不是可行性通过。已诊断但未通过的目标同样可以保留研究记录，不能因此绕过SAA采纳。历史研究可计算和保存；当前应用另行检查过期。

产物只有两项：**可执行的目标/约束版本**和**绑定输入及模型版本的诊断**。保存不是下单、外部审批或收益保证。

## 三、产品经理与需求分析师评审

| 用户疑问 | 必须呈现的答案 | 取舍 |
| --- | --- | --- |
| 我从哪里开始？ | 首先选成功标准，再呈现对应字段。 | 绝对收益不展示金额计划，相对目标必须有真实大类基准权重。 |
| 钱到底有多少可用？ | 总资金−组合外储备；近期压力净支出、支付缓冲和缺口。 | 流动性预算不重复从本金扣除；支付缓冲只是零收益场景算账，不是建议承担的市场损失。 |
| 需要怎样的回报？ | 覆盖支付和终值所需的固定年复合回报，含明确费用和通胀口径。 | 不直接拿复合回报替代CMA算术均值。 |
| 目标能否实现？ | 同一CMA下的代表组合概率、采样区间、缺口、支付不足和回撤预警。 | 没有CMA不显示概率；没有完整诊断证据不显示“通过”。 |
| 不可行时怎么办？ | 当前组合下所需追加资本、降低目标和增加本金的敏感性。 | 资金调整的点估计与采纳区间下界口径分开；不能用点估计资金数声称已经达到采纳条件。 |
| 我现在要读多少内容？ | 当前步骤的问题和摘要；模型设置、逐月/逐年表格在详情中。 | 结果不能只有图，关键分位数支持可访问表格核对。 |
| 我修改一个输入会怎样？ | 清空旧诊断、取消旧请求、重新核对确认。 | 旧版本只读，显式复制；不能以最新响应覆盖新输入。 |
| 后续模块会遵守吗？ | 授权资产/组边界只能收紧；资金诊断在SAA重新执行。 | 授权必须绑定具体大类方案，禁止仅按相同资产名迁移。TAA短期门禁不伪称维持长期成功概率。 |

评审结论：四步布局满足任务顺序，不再要求用户一次填写所有模型参数。真正的优先级是**证据与决策一致**，不是增加模型名称。新增能力必须有对应计算、接口门禁与独立测试。

## 四、本轮核对后完善的重点

现有未提交实现已具备三类目标、月度资金递推、CMA诊断与四步页面。本轮在其上补强：

1. 资金诊断增加近期压力支付后剩余缓冲，以及与Wilson下界采纳规则一致的所需本金；明确统计采样不足时不可给出该本金。
2. 后端与前端拒绝缺失、矛盾或非有限的目标诊断；不得把缺少`goal_check`解释成通过。SAA直接采纳也必须失败关闭。
3. 资产/分组授权绑定大类方案；确认与SAA下游不得通过同名资产转移授权。
4. 结果页增加逐年分位数表和明确统计口径；保持窄屏可操作、历史只读、异步失效与未知状态可见。
5. 补充数值、负向接口、页面交互和真实浏览器回归，最终全量测试与证据保留在独立验收记录。

## 五、验收底线

金额计划改变必须改变资金递推；改变CMA必须重新诊断；没有证据绝不通过；相同随机路径可复算追加资本；旧版本不覆盖；资金计划到期不等于禁止研究历史；试图放宽授权、伪造结果或用不匹配CMA都应拒绝。保存输入和资金不足是有用状态，不能为了流程顺畅隐藏或自动修正。
