# 情景研究：决策与验收纪要

当前入口为 [市场状态工作台](../regimes/README.md)，专业门禁见 [验证契约](../regimes/validation.md)。本页只保存历史决策和证据，不维持每轮审核、子任务交接或旧“暂不通过”状态的平行版本。以下测试属于2026年9月原记录，不是本次重新验收。

## 关键决策与关闭依据

- Historical Reference 是事后参考，Realtime 是实时识别；参考匹配、概率校准和部署前瞻资格分开。参考样本数量不等于可配对校准样本数量；静态 capability 不代替实际 audit_execution。
- 发布记录、运行、hash、状态映射和数据可得时点精确绑定；映射非恒等时，两条 TAA 消费链仍要一致。部分获资格状态才能贡献偏离，未获资格概率留在 SAA；chosen 状态未获资格则整体回退。
- 真实后续数据必须登记后捕获，参考成熟后评分；续接只允许已核验源前缀保持不变的新尾部。历史重放、bootstrap 或重新保存旧数据不创造真实前瞻资格。
- 质量、稳定性与 bootstrap 最初分工报告中的“未集成”已由父任务集成及续接最终测试覆盖；不能继续将这些阶段文字作为当前功能缺失。
- Realtime 的 cma_evidence 已移除；旧可靠性记录的 CMA Evidence 不能直接作为现在 LTCMA 采纳接口或长期假设认证。
