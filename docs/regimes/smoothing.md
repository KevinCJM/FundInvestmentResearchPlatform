# 市场状态研究流程与平滑算子

日期：2026-09-18。范围：市场状态研究工作台、历史参考绑定、三类平滑算子及新研究模板。本文记录本次需求、数学契约与验收；不宣称参数已经通过金融样本外验证。

## 用户流程

1. **历史参考**：定义研究对象、状态含义、频率和区间；预览原始数据与参考结果，确认保存冻结的历史运行。仅保存计算定义不能算完成此步。历史参考可独立用于复盘。
2. **实时识别**：新建时先选择精确参考的 `run_id/publication_id/content_hash`。空白模型继承状态定义，已有计算图必须显式映射不同状态。一个参考可供多个实时模型比较；不把参考的未来标签送入实时输入。
3. **验证与应用**：固定参考与评估时间块后，复用现有状态级准确性、遗漏、转折延迟、校准、稳定性和前瞻验证。原始模型概率、参考校准后的匹配概率、前瞻资格分别说明。保存研究版本不等于通过验证，应用时仍走已有有效性与用途门禁。

更换参考/映射/计算定义使当前草稿的校准和资格失效，保存为新修订；旧报告、发布版本和下游引用保持原样。高级入口允许无参考探索，能试算、保存定义草稿，但不能启用或发布新的应用研究版本。无 study 的存量定义保留兼容读取与原有契约。

页面复用现有三步骤工作台、共享控件、版本库、可靠性面板；不引入新的研究存储或任务状态机。选择目录失败时可重试；不可用参考阻止继续，状态不对应时直接编辑映射。步骤切换保留两份草稿；实时与验证共用模型草稿。

## 调研结论与来源

- [SciPy filtfilt](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.filtfilt.html) / [sosfiltfilt](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfiltfilt.html)：同一实系数滤波器前向、反向应用，组合零相位、阶数翻倍；边界延拓与初态影响端点。实现优先稳定的二阶节。
- [SciPy Butterworth](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.butter.html)：截止频率是单向增益降到 `1/sqrt(2)` 的频率；双向之后该处增益是 `1/2`。
- [SciPy SG 系数](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.savgol_coeffs.html) / [SG 滤波](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.savgol_filter.html)：局部多项式最小二乘、中心求值。标准库支持多种边界策略，本项目明确采用完整居中窗口，不外推端点。
- [Ehlers 与 Ric Way 原文摘要](https://traders.com/documentation/feedbk_docs/2010/11/Ehlers.html)和[原刊 Traders’ Tips 数学与代码](https://traders.com/documentation/feedbk_docs/2010/11/TradersTips.html)：误差校正 EMA 在有限增益网格中减少滞后，平滑与追踪速度存在取舍。不是严格零相位滤波。作者 MESA PDF 本次访问返回 403，因此以原刊资料核对计算式。

**零相位不保证任意原始局部峰谷的时间不变。** 由频率响应推导：`H(z)H(z⁻¹)` 在单位圆上为 `|H|²`，各频率的幅度仍会改变；多个频率叠加后的极值可移动或消失。一个简单反例：对 `[0,10,9,9,0]` 使用对称权重 `[1/4,1/2,1/4]`，原始峰值所在点平滑为 7.25，后一观测平滑为 9.25。此论证是数学推导，不是原文的逐字结论。

居中 SG 是对称 FIR：通带不引入时间平移，但频率响应可变号，不能把它全频段宣称为非负零相位响应。右侧半窗数据还未出现时，无法计算中心值。Ehlers 使用当前数据，但低延迟也不能保证当时识别所有真实峰谷。

## 一致输入输出契约

三个算子输入与输出都是同轴 `float64` 一维数值序列。间隔按**观测数**解释，假定样本在观测轴等间隔；不是对任意日历空隙作连续时间滤波。日频交易日、周频、月频应分别选择参数；缺失数据不填零、不跨缺口。指数、净值、数值特征均可输入；只有后续价格区间算子另要求正价格。

通用内核与唯一元数据位于 `computation_graph/smoothing_numba.py`、`smoothing_operators.py`，通过现有 Regime Graph `NODE_REGISTRY` 适配；不在不同中心复制算法。画布、参数表、公式作者模式、执行计划、节点预览共用相同节点契约。当前接入市场状态工作台，不声称已加入指标中心的另一套标量 DSL。

## 1. Butterworth 双向零相位低通

节点：`filter.butterworth_zero_phase`，节点契约版本 1，内核修订 `smoothing/1.1`。

本次提供**固定二阶**低通，避免不必要的任意阶设计器。参数 `period=P` 为整数 3…5000，默认 20。`fc=1/P` 周/观测，归一化 Nyquist 截止 `Wn=2/P`。使用双线性变换，令：

```
k = tan(pi/P)
d = 1 + sqrt(2)k + k²
b0=b2=k²/d, b1=2k²/d
a1=2(k²−1)/d, a2=(1−sqrt(2)k+k²)/d
H(z)=(b0+b1 z⁻¹+b2 z⁻²)/(1+a1 z⁻¹+a2 z⁻²)
```

每个方向使用直接 II 型转置递推：

```
y = b0*x + z1
z1 = b1*x − a1*y + z2
z2 = b2*x − a2*y
```

每个有限段先按最大绝对值归一化，在同一个独占工作区执行滤波，最后恢复量纲；零段按尺度1处理。这利用线性齐次性，避免有限大值在奇延拓和递推中提前溢出，不增加输入副本。直流增益为 1。每个方向按首个输入 `x0` 设置稳态初值 `z1=(1−b0)x0`、`z2=(b2−a2)x0`。从首端到末端一次，再从末端回首端一次，保留原时间坐标。

边界：每个有限连续段左右各奇对称延拓 9 点；左侧为 `2*x0−x[9:0:-1]`，右侧对称定义。长度≤9的段全为 NaN；NaN/Inf 切断段。结果与 `sosfiltfilt(butter(2,2/P,output='sos'), segment, padlen=9)` 对照。延拓不证明端点可靠；新增观测可能修订结果，不自动生成“成熟标签”。极端幅值导致非有限输出时保留 NaN，不产生 Inf。

时点：事后，完整输入知识；节点输出的可得时点保守取上游全部输入最大可得时点，并向下游传播。实时执行、实时节点预览和实时发布路径禁止使用。全样本定界的有效交易日期为空。

颗粒度：双向滤波的递推、边界初态与反向处理是一项耦合求解。它只输出平滑线；峰谷、收益、分类不包含在内。状态范围为一个有限连续段，两个定长遍历结束，不存在收敛循环。时间 O(T)，工作内存 O(T)。

## 2. 居中 Savitzky–Golay

节点：`filter.savitzky_golay_centered`，版本 1。

参数：奇数窗口 `W=3…501`（默认21），多项式阶数 `d=0…5`（默认3），且 `d<W`。`m=(W−1)/2`，局部坐标 `u_j=j/m`，`j=−m…m`。

```
A[j,k] = u_j^k
beta = argmin_beta ||A*beta − x_window||²
y_t = beta[0]
```

采用归一化坐标与两次重正交的修正 Gram–Schmidt 构造 `A=QR`，不用条件数平方的正规方程。中心投影权重为 `w_j=sum_k Q[m,k]*Q[j,k]`。参数确定后只生成一次权重，逐个完整窗口做点积；不逐窗口拟合或复制原始窗口。

边界：前后半窗 NaN；窗口内任意 NaN/Inf 则该中心 NaN；短于窗口全部 NaN。不使用 SciPy 默认的端点插值。d=0等价完整居中均值；不产生导数等独立输出。允许阶数接近小窗口长度，此时可能几乎不去噪。

时点：数学上中心 t 需要直到 t+m 的观测。本项目第一版保守记为 full_input 事后研究快照，不能作为实时信号或用下游滞后绕过门禁。不声明它在实时端点可用。中间完整窗口在后续追加数据时稳定，尾部留空直到窗口完整。

颗粒度：一个局部多项式投影，基础算子；继续拆分矩阵乘法没有独立业务意义。系数求解 O(Wd²)，应用 O(TW)，工作内存 O(Wd)，输出 O(T)。

## 3. Ehlers/Way 误差校正滤波

节点：`filter.ehlers_error_correcting`，版本 1。

参数：`period=L=2…5000`（默认20），`gain_limit=G=0…100`（默认50，单位十分之一）。设 `alpha=2/(L+1)`：

```
EMA_t = alpha*x_t + (1−alpha)*EMA_(t−1)
g ∈ {−G/10, (−G+1)/10, …, G/10}
EC_t(g) = alpha*(EMA_t + g*(x_t−EC_(t−1))) + (1−alpha)*EC_(t−1)
g_t = argmin_g |x_t−EC_t(g)|
y_t = EC_t(g_t)
```

两端包含，固定步长0.1；严格 `<` 更新误差最小值，并列保留较小增益。不是 ZLEMA 的“价格外推再 EMA”变体，不把不同算法混用名称。G=0得到两级 EMA，不是单级 EMA。

每段第一个有限样本初始化 EMA与EC为该样本，连续有效样本满 L 后输出。NaN/Inf或数值溢出重置并重新预热。只返回 EC，不把独立信号、交易规则、准确率混入算子。

时点：当期与历史；输出保守携带上游可得时点的前缀最大值，未来扰动与截断不改写已有前缀。它消减滞后，不承诺数学零相位、无过冲或准确峰谷时间。输入数据的公布、修订风险仍独立检查。

颗粒度：EMA、EC递推状态与当期增益选择属于一个误差校正问题；有限网格搜索终止，不做模型训练。时间 O(T(2G+1))，除了输出 O(1) 工作空间。

## 新模板与旧结果

新增两个可展开编辑的日频平滑参考模板，当前为 `market-trend-smoothed-butterworth-reference-v2` 与 `market-trend-smoothed-savgol-reference-v2`：

```
原始指数 → 平滑 → 局部峰谷 → PS约束筛选（仍使用同一平滑线）→ 相邻峰谷区间
原始指数 + 区间 → 原始价格区间涨跌幅 → 独立阈值分类
```

原始与平滑数值通道同时输出，支持同图对照。默认63观测平滑、20观测阶段/120观测周期、±15%分类门槛均为研究起点。历史月频原始峰谷模板保留其实际算法语义与 ID，不替换存量定义或版本。收益与风险不能因为平滑而缩小口径。

本次不自动把平滑峰谷映射到邻近原始极值；那需要另一个明确窗口、重叠/并列与顺序契约的领域步骤。界面和文档均不承诺“滤波峰谷必然与原始峰谷重合”。

- 直接传递 source.values；不为节点或窗口复制输入。Butterworth分配一份输出和最多T+18的独占工作区，在两方向复用；SG只分配权重和小型正交基；Ehlers仅输出。日期轴复用，上游可得时点派生数组属于必要输出。
- NaN、Inf、空样本、短窗、参数边界、只读/负步长视图、输入不被写入、确定性、签名不增长均纳入测试。仅凭装饰器不作为执行证据。

## 当前边界补充

### 发现与修复

1. **组合模板混用两条价格线会清空峰谷**：候选来自平滑线，PS首尾极值约束却使用原始线。在900点慢周期叠加快噪声样本上，6个候选转折全部删除，最终没有区间。修正为在同一平滑线上定位、筛选，独立区间收益仍接原始线。模板升级v2；不修改已保存定义/运行，不保留另一套旧数值实现。
2. **Butterworth 有限大值提前溢出**：40个 `1e308` 常数原来因 `2*x` 与递推中间量溢出全部变成NaN，理论结果仍应是该常数。按有限段最大绝对值归一化，复用原工作区滤波后恢复尺度；不把真正超出float64范围的输出写成Inf。内核修订 `smoothing/1.1`，Regime kernel版本 `2.11.1`。
3. **极大整数参数导致服务器异常**：`10**400` 转float会抛OverflowError。共享参数校验现在安全判定有限数值，标量/列表/集成权重检查共用该判定；无效参数由真实prepare API返回422，不能落入计算。
4. **结果展示混淆**：纯滤波分类原来被描述为“峰谷定界”；并且PS改接平滑线后，原始指数证据会被平滑值覆盖，原始区间收益证据可能遗漏。现在按最终分类实际依赖的区间统计选择价格来源，分别提供原始指数、平滑指数和原始阶段收益；纯滤波使用对应说明。没有改写历史运行内容。

### 加强的验收

- 原常数测试只比较有限输出，存在全NaN也通过的空集漏洞；补上精确有效观测数量。
- Butterworth：全部4,998个合法整数周期与独立SciPy二阶节对照；另有长短样本、分段缺失、±1e308/±1e-300常数、脉冲对称性、截止频率幅度为1/2且相位对齐的检查。
- SG：全部1,496组合法窗口/阶数组合与缩放Vandermonde的独立SVD系数对照；检查多项式重现、中心输出数量与缺失窗口，不依赖大窗口下未经缩放求解的误差。
- Ehlers：最小/默认/最大周期及增益边界与独立SciPy EMA加向量化增益搜索对照；G=0明确等价两级EMA，保持满窗口预热、缺失重置及未来扰动/截断前缀不变。
- 服务层直接记录实际进入的数组：只读步长视图与上游共享内存，日期轴保持同一对象，输出不共享输入；调度实际进入注册的CPUDispatcher，签名不增加。
- 事后滤波再接普通滞后节点仍在读取数据之前拒绝实时运行。检查实际 `recognized_at/effective_date/executable` 字段及非空分类结果，避免用不存在字段或空结果证明门禁。
- 两个v2模板执行900点完整链路，检查保留充分完整区间，牛熊均出现；逐点核对原始价格收益、原始/平滑两条证据，末段未分类且没有有效交易日期。
- 真实API覆盖错误类型、空值、布尔、小数、越界、极大整数、SG联合约束和增益上限。
