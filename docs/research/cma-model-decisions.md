## 数理边界与反驳

### 不确定性

Box：`haircut = penalty * sum(abs(w_i) * u_i)`；其半宽可以是人工区间或模型边际参考，不是组合的联合 95% 置信保证。连续分布中“角点概率为零”不能用来否定整个不确定集。

椭球：`haircut = kappa * sqrt(w' U w)`，U 是均值估计协方差，不是资产收益协方差。高维联合半径也可能比 box 更大，不能承诺必然少扣收益。

令 d 为 U 中严格非零方差的坐标数，不是通过特征值阈值估计的秩；确定性零方差坐标不计入 d。

- BL：在声明的高斯均值模型下使用 `kappa² = chi2(d, confidence)`。非零方差子块正定时为该模型的联合可信域；奇异时 d 可能大于实际秩，采用保守半径并明确提示，不通过数值阈值删除小方差方向。
- NIW：边际均值为多元 t，要求均值协方差正定，此时 d=N。以协方差 U 表示时，`kappa² = d * (df - 2) / df * F(d, df; confidence)`，`df = nu_n - N + 1`，不得把 t 的协方差误当尺度矩阵。
- Historical：未收缩、独立正态样本且非零方差子块正定时使用 Hotelling `kappa² = d*(T-1)/(T-d)*F(d,T-d;confidence)`；要求 T>d。使用收缩或奇异样本矩阵时不宣称精确覆盖，须明确确认高斯插件近似。全零 U 使用半径 0，不把样本零波动宣称为未来无风险。
- 缺失均值协方差不得用资产风险代替；多 CMA 的均值误差交叉协方差尚未定义，本次明确不支持多 CMA 椭球，不擅自平均协方差。

### 协方差收缩

相对原样本：`Delta variance = -2*lambda*sum_{i<j}(w_i*w_j*S_ij)`。正的加权交叉项使风险下降，负的交叉项使风险上升；都不能推出相对未知真实风险的偏差方向。常相关不是逐组合风险上界，Ledoit–Wolf 的矩阵损失优化也不等于保守风险估计。审核建议的 `r_bar/rho_ij` 写法在零相关处无定义，不采用。

### 状态持续与多期分布

`Var(sum_{t=1}^H r_t) = H*Gamma_0 + sum_{k=1}^{H-1}(H-k)*(Gamma_k+Gamma_k')`。波动率聚集不等于收益正自相关；如果各状态条件均值相同且创新不相关，状态可以很持续而收益自协方差仍为零。不从转移矩阵单独推算“十年风险低估百分比”。

相邻状态统计只使用真实相邻的已知状态；未知状态是断点。无出边或不可确认唯一平稳分布时，输出不可用原因，不补自循环、不编造平稳概率。经验持续期是一步 Markov 解释下的观察期数，不直接冒充月数。

年度情景矩只规定单期分布的两个矩；未定义情景内分布、情景选择时点及跨期规则。按月重抽年度情景并不能保留年度混合风险。单因子对数正态与左偏情景分布的成功率差异取决于目标阈值和现金流，验收不能预设所有例子都同方向。

### ddof 与样本

状态 ML 矩按 `n_s/T` 混合，在原占用率、无收缩下重构全样本 `ddof=0`。全样本无偏协方差需组合 `sum((n_s-1)*S_s + n_s*(mu_s-mu)*(mu_s-mu)')/(T-1)`；只替换每状态分母不等价。

审核附录 A 的历史均值协方差写成 `Sigma_annual/T`，遗漏 252；当前代码 `252*Sigma_annual/T` 才是日频样本年化均值的协方差。

### 数学与用途约束

长期默认使用同一有效样本上的时间占比，保留共同状态轴、未知断点与现金固定收益。联合风险包括状态内风险和状态间均值差异，先按基础周期混合，再按现有周期算术口径年化。收缩来自自动估计且记录政策，不能用投资目标反推“需要的 CMA 收益”。不通过降低危机权重或删除真实下跌样本保证目标达标。

条件模式从核验后的当前概率出发。实时识别置信度不能冒充未来概率；状态识别验证与未来预测验证分别记录。期限累计分布与年化矩不能互换，模拟误差与经济不确定性分开。事后标签不构成可执行信号；PIT 只读日期截断也不自动证明数据版本在历史上可得。

条件结果允许明确标记为研究结果保存；在缺少经过验证的期限到 SAA 适配前，单 CMA、先验和多 CMA 消费均阻断，不能由一个前端复选框解除。长期统计参考的可采用不表述为预测模型已验证。已有直接假设、BL、人工情景、历史统计、NIW 和历史状态契约继续有效。

需覆盖：唯一参考主动选择及已保存绑定回显、多候选选择、空列表通过下拉框进入事后情景识别、不合格原因、PIT 锁定及变化刷新、代理继承、计算／返回修改／保存／重新读取、长期 SAA 交接、条件保存但不可交接、API 绕过尝试、旧模型回归、桌面／平板／手机布局与对比度。源码／合成数据测试不作为真实市场预测有效性、正式部署或投资资格认证。

## 按配置事实复用 LTCMA（2026-09-22）

### 问题与目标

同一资产范围未修改内容再次保存会创建新记录。原 NIW 与 SAA 选择逻辑直接比较范围记录 ID，导致资产、代理、币种均相同的已确认 CMA 被排除。记录身份继续用于历史引用和完整性校验，兼容性改由明确的配置事实决定。现有冻结记录、ID、hash 及模型结果不迁移、不改写；读取时即可解释已有的重复记录。

### 配置事实契约

共享事实由计价币种、有序资产 ID、逐资产币种、经济角色、流动性与研究代理构成。代理只包含类型、现金收益率、再平衡规则，以及来源类型／序列／字段／权重；成分按来源键排序，权重不近似舍入。范围记录 ID、创建时间、名称、说明、来源标签、替代关系不参与兼容性判断。资产 ID 与顺序仍明确对应收益向量及协方差轴，不按同名猜配或自动重排。

服务端用规范事实和固定契约标记计算 SHA-256 配置指纹，供保存去重、目录与诊断使用。整份记录的 `content_hash` 保留原含义。研究日、PIT、收益矩、费用／汇率、退役状态及用途限制独立检查；NIW 允许较早的先验，多 CMA 仍要求同一研究日，不把日期从业务检查中删除。

### 后端修改

1. 共用配置事实提取与差异判断，基于已核验的冻结范围快照生成 CMA 的事实；不以当前同名范围替代历史来源。目录新增只读事实与指纹，历史文件缺少这些派生字段时即时计算。缺少可核验事实时不得放行不同 ID；相同 ID 的历史调用保留原检查。
2. 范围编辑保存继续在治理锁内核对预览、活动状态、名称和目标绑定。完整定义及目标绑定都未变化时返回原记录；备注／名称等真实编辑仍被保存，但不会改变配置兼容性。并发无修改保存应返回同一 ID，过期编辑和退役记录仍拒绝。
3. NIW 用配置事实替代范围 ID 相等条件，并核对实际输入与先验冻结的研究代理。人工先验没有统计代理时不伪造代理证据。资产轴、币种、收益口径、先验日期、用途与退役继续校验；样本重叠、NIW 续更与强度仍由既有模型处理。返回具体差异，不再将所有失败归为“没有先验”。
4. 多 CMA 比较同一事实契约，并保留每个来源自己的 ID/hash、当前来源完整性、收益口径和实际研究代理校验。融合结果仍保留全部原始来源，不改冻结记录。单 CMA SAA 使用被选 CMA 自己的来源；实施映射继续核验其精确绑定，不把研究等价扩展为任意执行映射等价。

### 前端修改

目录和详情沿用现有 API，增加事实字段；前端通过一个共享比较函数服务 NIW、SAA 单选／多选及 LTCMA 交接，服务端计算前仍独立重验。函数直接比较明确字段，不另实现浏览器哈希。用共同契约样例核对前后端规则。

NIW 保留可用候选并显示方法与取样窗口，近 2 年／近 5 年可区分；不适用的记录保留为禁用选项，附币种、日期、资产、代理或口径原因。不存在任何已确认记录与“有记录但不适用”分别提示。已选择后修改代理等配置，立即标出失效选择并阻止继续使用旧资格。

SAA 同配置跨记录选择不再被 ID 阻挡。交接逐项检查各自冻结来源与范围，而非将所有来源的记录 hash 与第一项比较；目标关联仍明确，不能静默替换不同的投资目标。字段缺失、加载失败及 PIT 未知保持失败关闭。UI 沿用原生下拉、现有工作台令牌和中英文词条，不向用户展示技术指纹。
