# 自上而下配置研究：前后端详细设计

依据：同目录 `top-down-allocation-research-2026-09-12.md` 与本轮 CodeGraph/实际源码。状态以验收文档为准，不以本设计宣称已交付。

## 1. 范围与四问

本轮贯通“投资目标 → 已有资产分类 → 前瞻假设 → 政策权重 → TAA → 产品预算”，不重写已工作的历史优化和 TAA 回测。补充多折 TAA 稳定性研究，以及原 SAA 回测结束日契约。已有未提交的视觉/指标修改保留，不提交或推送。

| 改动 | 属于本需求？ | 原有能力是否足够？ | 最小必要改变 | 不做的扩张 |
| --- | --- | --- | --- | --- |
| 投资目标真实存储与计算约束 | 是，自上而下缺起点 | 演示页面不足 | 不可变目标版本 + 真正消费风险/流动性限制 | 不建设资管合规权限或负债优化 |
| CMA + 经济大类说明 | 是，历史收益不能代替长期预期 | 分类、净值读取可复用 | 前瞻收益/均值不确定性、风险矩阵、角色/币种/流动性及依据 | 不自动猜测宏观敏感性，不填造外部预测 |
| SAA 政策候选与采纳 | 是 | 历史目标与输入不同 | 新增均值/协方差候选评价，复用现有约束修复与不可变存储 | 不重复实现历史前沿、风险预算或 TAA 引擎 |

| 审核整改：历史实验与门禁 | 是，直接影响本链正确性 | 三个代表点的局部精炼不足以恢复原始前沿功能 | 恢复 20／200 个收益目标的逐点受约束优化；目标点数与单点迭代预算分开；采样、局部精炼、网格解合并后统一筛 Pareto 和三个代表点；保留已修复风险与日期门禁 | 不冒用 SLSQP，不引入 Python 数值回退，不扩展成新策略家族或整数权重求解器 |

## 2. 用户操作

### 投资目标

首屏只问：方案名称、研究日、计价币种、投资期限、目标收益、最大波动、最低流动性比例、最高非流动性比例、TAA 主动风险预算。数值用百分比显示，参数说明放在标签下。保存明确产生新版本；列表可重新选择，旧目标不可覆盖。风险厌恶与政策复核/再平衡描述收在高级区。明确目标收益为约束，不是承诺；本轮不计算目标达成概率。

### 大类与长期配置

沿用产品池、手工/自动大类构建。长期配置新增真实工作台，按四个连续步骤工作：**选择目标与分类 → 填写长期假设 → 比较政策候选 → 确认并进入 TAA**。原有效前沿/风险预算页保留为“历史配置实验”，不是新旧两套同算法；主 SAA 页面直接显示入口，历史实验的散点/近似前沿默认展开，方案切换始终停留在 `allocation-lab`。

每类展示已有代理产品，要求确认经济角色（增长/利率防御/通胀分散/信用/流动性/其他）、流动性和选择理由。角色是用户声明的政策分类，不是模型校准的 beta；一个产品仍只能归属一个预算类别，禁止靠重贴标签规避限制。聚类/PCA只作辅助证据。

预期收益不预填示例值。波动/相关性可显式点击“读取历史风险参考”，读取真实共同样本后回填风险参数，不自动把历史均值写成未来预期。历史参考当前只接受 **SSE 连续开放日的日频轴 + 252 年化**；所有资产共同缺失某个开放日同样阻断，周/月频必须先有显式重采样契约。矩阵按资产名字列示，下三角联动上三角；修改是对称输入编辑，不是数值修复。缺数值、不同币种、非对称/非半正定矩阵、空来源或样本不足时就近说明。

比较结果显示权重、预期收益、波动、保守收益、风险贡献和约束状态。名称使用“候选中较优”，不写“保证最优”。采纳要求明确理由，只在“确认采用”时写政策版本；前端参数变化立即作废结果，迟到请求不得覆盖新输入。旧版本可读、可复制输入，不可变更历史。

桌面采用主编辑区 + 紧凑步骤导航；窄屏单列，宽矩阵局部横向滚动。复用 `ui.tsx`、`ResearchUI` 与前端设计令牌；有标签/错误/焦点/空态，数字右对齐、表头 scope，不套用营销页 hero。

### 历史有效前沿：第四轮原始功能恢复

完整技术设计、数值契约和本轮验收见 [第四轮目标网格设计](frontier-grid-round4-design-2026-09-12.md)。此前限定“只处理三个代表点、不做整条前沿”是需求解释偏差，本次不再沿用。

生成按钮附近直接配置“前沿目标点数”（默认20、支持200）与“单点最大迭代次数”（默认300）。服务端先求解端点，再对每个收益目标求满足单资产、分组和目标收益约束的最小风险组合。均值—方差及EWM风险采用固定签名NJIT主动集QP；非二次风险采用局部BFGS-SQP，真实算法不叫SLSQP。

曲线按目标顺序使用真实坐标，失败处断开；所有目标保留状态、迭代、实际权重、实际收益/风险、约束违反量和残差。采样取整与连续网格不是同一约束域，同时启用需显式确认；不承诺所有目标都能成功或产生不同权重。新草稿独立使用 `frontierGrid.point_count/max_iterations`，不改写旧局部精炼参数语义。网格修改使旧图失效，迟到响应不能回填。

### TAA

保留现有规则、情景与版本流程。新增可选“多段样本外检验”：选择滚动/扩展训练、训练期数和每段验证期数，默认关闭以保留旧请求契约。结果逐段显示训练/验证日期、当时所选强度、净超额、跟踪误差、换手与未通过原因。该诊断不改变主研究已经声明的训练/留出选择，也不自动用最好一段替代原决策。每段独立从 SAA 起步，禁止拼接连续净值。

## 3. 对象、API 与存储

新增 `backend/strategic_allocation/{contracts,kernels,service}.py` 及服务路由。复用 `ArtifactRepository`，复用 `TacticalAllocationData` 作为分类/净值来源，复用 `TacticalAllocationRepository.save_baseline` 保存可被 TAA 直接消费的政策基线。

- `GET /api/strategic-allocation/catalog`：已有分类、目标版本、CMA版本、政策版本摘要。
- `POST /mandates`：保存目标版本；不写示例数据。
- `POST /risk-reference`：仅计算真实历史风险参考和来源指纹，不持久化。
- `POST /cma/preview`：验证完整资产轴、角色/币种、年化算术口径、风险矩阵和数据来源，返回预览及 hash。
- `POST /cma`：确认后复算并核对预览 hash，保存不可变假设和来源/数组。
- `POST /policy/preview`：消费目标/CMA版本与权重边界，计算同一候选集合中的名义效用、稳健效用、最小风险等候选。
- `POST /policies`：确认理由 + 候选 id + preview hash；服务端重算并保存唯一 SAA baseline，冻结目标/CMA/经济分类/约束/核验结果。研究确认不冒称独立风控审批。
- GET 对象端点可读取历史目标/CMA。策略目录可重新打开已保存基线；后续源文件变化不能改写旧版本。

每个 CMA 使用明确的基准币种、期限、`annual_arithmetic_total_return` 口径。几何 CAGR、名义/实际收益、外币未对冲收益不可静默混用。CMA 期限须匹配所选目标。当前基础只支持同计价币种、long-only、无杠杆；跨币种/私募现金流并无已验证实现。

预览不得调用 save、mkdir、锁文件写入或外部下载。保存复用原子成果库与磁盘守卫，校验失败没有可用版本。JSON 限制资产≤30、组合分组≤30、候选≤5000、文本长度、有限值；用户不能上传计算结果或冻结审计字段。

## 4. 数值契约

### 历史风险参考

在明确的共同日期区间读取 `returns[T,N]` 与可得日期，只做参考风险估计。样本协方差复用统一 `covariance_2d` NJIT 内核，采用明确给定的对角收缩：

`Sigma = periods_per_year * ((1-a)*S + a*diag(S))`。

a 是研究设定而非自动估计的 Ledoit–Wolf 强度；方法标签不得混淆。引用来源指纹、真实观察起止与未知时点计数。重复/非有限/净值断点阻断。共同日期轴必须逐日对照 SSE 开放日；不能只依赖资产间交集判断完整性，也不能把不规则/周频收益静默按 252 年化。

### 前瞻政策候选

CMA 显式输入 `mu[N]`、年化 `vol[N]`、`corr[N,N]`、均值不确定半宽 `u[N]`。`Sigma_ij=vol_i*corr_ij*vol_j`。校验形状、有限性、正波动、相关系数边界、对角1、对称、半正定；不偷偷改成最近正定矩阵。

在可行 long-only 资金单纯形生成确定性候选，复用 `optimizer.repair_weights_kernel` 的单类/组边界修复；每个候选再次检查约束。统一计算：

- 预期收益 `mu·w`；方差 `w' Sigma w`；风险贡献 `w_i*(Sigma w)_i / variance`（零方差时明确不可定义）。
- 名义效用 `mu·w - gamma/2 * variance`。
- 区间稳健效用 `mu·w - k*u·abs(w) - gamma/2 * variance`。

最低目标收益和最高波动、现金/流动性下限、非流动性上限均为真实候选/采纳门禁。不可行时说明“未找到可行候选”，不把随机搜索失败等同数学不可行；不擅自放宽。候选数量/种子固定并留痕。CMA本身不是预测保证；保守收益是区间假设，不是概率分位数。

### TAA 与政策边界

新政策基线保留原类内产品及上下限/组约束，并冻结目标与 CMA。TAA 请求不能扩大政策主动风险预算；当前拟议权重同时按冻结协方差计算总波动与前瞻主动风险 `sqrt((w_TAA-w_SAA)'Σ(w_TAA-w_SAA))`，分别对本次 TAA 上限与政策预算做共用门禁，预览与产品应用不得分叉。政策建立日、研究/决策日、行情观察截止和数据可得日分开；行情可滞后于决策日，旧政策允许读取其冻结历史之后的追加新观察，但冻结前历史一旦被改写仍失败关闭。旧基线不伪造新字段；到期只能新建研究，不能改日期续命。完整历史 PIT 仍标研究限制。

### 多折验证

最多 40 折。训练/留出各至少20个观察期，留出不重叠；滚动取最近训练窗口，扩展从初始训练起点累计。每折训练收益必须在该折训练截止时成熟；未知/未成熟收益保留为受限或阻断折，不能将其当成合格证据。复用已构建的因果信号和同一 TAA 组合内核，候选仅按训练选；固定假设若某折训练超出风险/换手限制，该折记 `blocked` 并继续后续折，绝不偷偷改选别的强度。分段独立资金口径明确。按当时训练时点裁剪成熟尾部，禁止压缩中间缺失日期改变收益轴。

## 5. NJIT、内存与颗粒度

数值函数固定签名，声明只读任意步长数组作为输入，输出/必要工作区独占。生产主进程预热纳入 readiness，记录 PID；未预热失败，不临时编译/回退。样本协方差、矩阵验证、候选评价、风险贡献、多折数值汇总进入 NJIT；Python只解析/取数/编排/序列化。

边界 Parquet 对齐与 dtype/布局规范化是必要复制；训练/验证区间用原始只读切片共享内存，不按每折复制原始历史。小型候选权重和输出允许分配。固定种子作用域不污染其他 NumPy 随机任务。

颗粒度：协方差估计、风险矩阵验证、约束候选生成、候选评价是独立语义；受联合约束的候选修复是已有耦合内核，继续复用。工作台不是新黑盒算子；数学工具不在各中心复制。前瞻均值效用与历史路径收益是不同语义，保留两者不是存档式双实现。
