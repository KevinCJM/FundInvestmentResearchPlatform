## 修复后再次审核

使用更新后的 CodeGraph 追踪以下实际调用链，并逐段核对当前源码和反例：

- `calibrated_output → 两条TAA消费者 → 数值权重/贡献审计`：完整概率轴保留；新 TAA 使用零化未授权 tilt 行满足概率合计1的原内核契约。
- `指标定义保存 → 冻结数组制品 → 输入/评价读回 → as_of切片 → prepare/run_saved`：没有删除指纹校验，也没有自动改写旧绑定。发现评价对象旧绑定遗漏及只读数组签名不兼容后均补修。
- `真实推荐图 → 因果执行 → 单指数续接 → 签名捕获 → 后续参考身份 → 逐状态资格`：频率从实际输出推导，执行器指纹覆盖新增模型依赖；不放开跨对象、跨频或算法变更。
- `preview → 发布重试/新周期 → 旧制品读取 → 依赖失效列表`：请求身份与内容身份分离，旧记录不可变，失效成果消费继续失败关闭。
- `页面请求/编辑 → 真实HTTP校验 → 保存版本 → 下一步交接`：复核空筛选、乱序响应、未应用编辑、错误状态和旧数据兼容；浏览器新增发现的按钮悬停与步骤编号对比度已修复。

新增累计水平与剩余响应计算进入固定签名 NJIT 及启动预热。冻结序列的持久化数组为只读，而既有图核使用可写数组签名，因此在I/O边界一次性生成独立输入缓冲区，三个数值数组为 `3×N×8` 字节（5000点最多120KB）；后续端口和切片复用，不在节点内反复复制，不修改共享制品。此处明确记录必要复制，不声称全链零拷贝。

旧指标窗口若已被外部修订且没有可还原的原值，仍拒绝冒用旧指纹，提示显式重绑后保存新修订。新增数据不会改变已冻结研究窗口；采用新增数据需要新版本。
