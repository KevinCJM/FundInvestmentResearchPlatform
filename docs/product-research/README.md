## 如何使用

选择产品与指标版本、所需区间和截止日。截止日留空继承平台研究日；从指标名查看定义，展开行修改已开放参数或查看不可计算原因。结果必须来自保存的版本，不在页面重新实现公式。

产品详情采用“行=指标、列=区间”，区间最多 6 列。产品对比采用“行=指标、列=产品”，保留各指标自己的区间偏好；两者存储和最佳／最弱语义不混用。不存在真实数据时报告不可用，不把演示数据自动补成真实结果。比较页显式 preview=demo 仅供演示。

## 当前展示与容量

- 不设 8 个指标的产品选择上限，显示实际已选数量。evaluate 请求受 MAX_EVALUATION_INDICATORS=200 保护，批编译／评价方案规模独立维持 10。
- 列头只有各单元格起止日期相同时才共享窗口，否则在行内解释差异。不再用隐藏的 observation_count 决定显示口径是否相同。
- 数值右对齐，不用颜色比较不同期限大小。方向使用“越高越好／越低越好／仅展示，不判断优劣”。版本移入定义或提示，主表不重复印观察值数。
- 单格不可用或失败不牵连其他产品／指标，保留中文原因、输入来源和实际窗口。完整加载、空态、错误、禁用及旧结果失效。
- 参数只覆盖已声明输入，默认值和覆盖值按同一后端归一化；结果键包含版本、参数和区间，不能仅按指标名称覆盖。

## 响应式与异步

工具栏按选择指标、区间、截止日靠左排列，控件底边对齐。窄屏表格在自身容器横向滚动，固定名称列，页面不横向溢出；字号、颜色、焦点和表头语义遵循前端设计准则。

输入变化取消或忽略旧请求，不将旧参数响应写回新表。删除数量上限不代表无限计算或已完成任意规模性能验收；资源超限应给出操作性原因。
