# 通用编排器与全数据流程

## 审计结论

运行表单由 EtlDefinition.parameters 渲染，没有按流程 ID 分支；旧模板却只有一只 ETF 和一只场外基金。下载编辑器还根据输出字段猜测 symbol/ts_code，并按供应商显示示例，不能代表真正的输入合同。本轮保留旧流程，另建全数据流程，不删除用户配置。

## 通用边界

前端只理解节点类型、后端任务目录、参数定义和输入依赖，不出现供应商 API、产品参数 ID、模板 ID 分支。普通接口参数由请求字段合同提供；没有请求字段定义时使用通用键值参数编辑，不从响应列猜测输入。运行参数定义和绑定提供通用可视化编辑。

增加 `task`（数据集任务）节点。后端注册经过审核的任务适配器，目录提供任务 ID、名称、分类、参数、输入能力要求和产出。用户可以从目录重建任意模板，同样可以改变顺序、参数绑定和快照位置。不存在用户任意 Python/shell 执行入口。供应商相关采集协议属于后端 Connector，不属于某条流程或前端页面。

## 全数据流程范围

Tushare 全数据同步覆盖项目 T01_get_data.ACTION_LABELS 中全部 30 个动作及独立指标快照，共 31 个节点：基础目录和日历、全部 ETF、全部场外公募基金、基金规模/经理/持仓/分红/复权/基准、指数目录与各类行情/估值/成分权重、宏观/货币信用/利率/发布日历，以及本地派生快照。不是 Tushare 全站数百个 API，也不包含项目尚未接入的股票行情。

运行只需历史起点、截止日期和全量/增量，不要求填单产品代码，不设置产品数量限制。内部复用现有下载器的产品目录遍历、日期分片、分页、共享限流、有界重试和检查点，不再复制一套全市场下载算法。任务粒度明确到数据集，不把整条流程藏进一个不可编辑按钮。

## 运行与隔离

全量从空的私有工作区开始。增量复用同一流程、来源配置及历史起点的最近成功私有结果；没有匹配基线时明确初始化。基线在运行启动时冻结并校验，不默认读取 active 目录。每个节点从前置工作区复制到独立写入区，优先 Copy-on-Write 克隆，不用可被原地写入破坏的硬链接。成功节点的 inventory/文件校验和固定，失败可继续当前节点的原生分片检查点。

全局 ETL 锁贯穿任务，并传入工作子进程；父进程退出时子进程仍持锁，工作进程有总时限。参数不接受任意目录、命令或产品 limit。凭据仅在子进程内部从受控来源存储读取，不进入命令行、运行配置、日志或任务结果。来源/接口/代码变化禁止以新合同恢复旧运行。

Tushare 数据集任务同时保留原始批次、标准映射候选和原有兼容 Parquet。大量全市场数据不经过单接口 100000 行内存归并器。映射错误明确记录为需复核，不能声称标准数据已全部就绪。快照任务读取明确的私有兼容工作区及冻结指标定义；不借此绕过多源取值，也不自动发布正式研究数据。

任务缺依赖时校验失败。来源停用、必要接口未配置或独立授权未确认时运行前阻断；权限错误不得被当作空数据或成功。全数据定义可以保存，保存不证明全部权限或全部在线接口可用。每次真实请求继续执行来源和接口的较严格限额，不因全数据流程提高配额。

“调度服务中断”不等于工作进程停止：数据集子进程继承全局锁，旧父进程退出后可能继续下载；不可仅根据 ETL 元数据的 INTERRUPTED 就重复启动。运行查询对中断/失败/取消记录附带 `recovery`：列出持锁、执行指纹变化等快速阻断条件；它不扫描大型数据文件，也不保证文件完整性已验收。实际续跑仍需重新获取锁，并核验代码、来源修订、成功制品校验和及冻结配置，防止查询和执行之间的竞态。

恢复按钮采用页内二次确认，不依赖浏览器原生 confirm；发送后原位置显示核验状态并禁用重复提交。成功立即更新该运行状态；后端拒绝、网络错误就地显示，不只显示在长页面顶部。已知不能恢复时，按钮旁展示所有阻断原因。旧后端没有 `recovery` 字段仍兼容，拒绝请求的原始业务说明同样就地显示。取消操作使用相同反馈方式。

执行指纹变化不静默覆盖旧值，不假装“新建运行”能够复用全部旧结果。原地续跑只允许相同执行合同；跨版本复用需独立核验和迁移设计。本轮修复不终止遗留进程、不删锁或检查点、不重写历史冻结记录、不启动全量重取。首次现场核查：旧运行前 10 步成功、持仓步骤调度中断；原工作进程仍持锁，恢复接口实际返回 `409 DATA_TASK_RUNNING`，同时磁盘执行指纹与旧运行不一致。这是当次观察，不是永久运行状态。

### 节点实时进度（2026-09-07）

运行记录中的活动节点展示当前阶段、阶段进度条、已耗时、累计接收批次/行数及最近 20 条脱敏日志。仅从采集器明确的“进度 X/Y”识别阶段总量；日期、重试次数和页码不作为完成率。下载、合并、输出文件校验分阶段展示，下载到 100% 不等于节点成功。未知总量显示不定进度，不估算虚假剩余时间；累计接收行数含重试/重复批次，不等于新增或最终有效行数。
