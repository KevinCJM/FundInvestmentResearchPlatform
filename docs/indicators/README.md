## 公开对象

一个标量指标定义一个 number／date／duration 结果。`result_kind` 为 scalar 或 time_series；时序原有多通道保留。多标量、父子结果、`scalar_outputs` 和 `output_id` 已退役，含空值的退役字段也明确拒绝；不能把内部多根共享计划暴露成新的业务类型。

指标定义不绑定某个运行周期。运行实例由锁定版本、有效参数、目标、区间与研究日确定；产品域和组合域分开，组合指标只消费不可变组合快照。
## 定义期无周期

指标定义默认支持引擎提供的全部周期，定义页面不再要求用户勾选“可用周期”。当前规范字段为 `period_policy=all_supported`。

- `POST/PUT /api/custom-indicators`、`/validate` 和内联定义不需要提交 `periods`。
- 后端仍接受历史客户端携带的 `periods`，但不会把它解释为能力子集；服务端统一使用全部 `SUPPORTED_PERIODS`。
- API 读取历史定义时仍可能返回 `periods`，其含义是引擎兼容信息，不是用户在定义期设置的限制。
- 单产品 `/evaluate` 必须显式选择本次运行周期；评价方案的每个指标项也锁定运行周期。
- `/evaluate-portfolio` 不接收周期。组合的起止日、共同日期、成分和权重来自不可变运行快照，前端只展示“快照窗口”。

运行周期由一个服务端注册表统一定义，并分成三类：

- 滚动区间采用“数字在前”的代码，例如 `1Y`、`2Y`，以有效截止日为终点向前滚动。
- 完整自然区间采用“单位在前”的代码：`Y1`/`Y2` 分别表示去年/前年，`W1`/`W2` 分别表示上周/上上周，`M1`/`M2` 分别表示上月/上上月。自然周按周一至周日划分，且只计算已完整结束的区间。
- `ALL` 表示成立以来，从首个真实有效净值点计算至有效截止日。

完整自然区间会携带区间开始前最后一个有效净值点，以覆盖第一个区间内收益观察值；响应仍返回实际使用的起止日、观察数和数据最新日期。普通预览、变量可用性、评价方案批量计算和缓存均复用相同的边界解析器。

## 类型化变量与真实数据

公开变量目录由版本化变量注册表生成，而不是由前端手写。单产品域当前包括：

- 复权净值、复权净值普通收益率和复权净值对数收益率；两类收益率的名称、说明和数据口径都必须明确其由相邻复权净值派生；
- 原始日 K 的开盘、最高、最低、收盘、前收、价格变动、行情涨跌幅、成交量和成交额；这些变量始终保留在构建目录中供发现，构建阶段不因当前选择的产品而隐藏或禁用。正式预览时若产品没有对应行情数据，必须明确报告数据源未配置，且不能用净值伪造行情；
- 单位净值、累计净值、累计分红、净资产和资产总额等条件可用的净值字段；
- 收益观察数、窗口实际自然日数、年化因子以及无风险收益率等运行时标量。

组合域变量来自锁定快照，包括多资产普通/对数收益矩阵、末期权重向量、动态权重路径、可选基准收益和无风险收益率上下文。产品变量与组合变量按 `context_kind` 隔离。

每个变量元数据至少描述类型与 Shape、`semantic_role`/量纲、价格口径、单位、频率、规范字段名、按产品类型配置的 `source_bindings`、替代变量、缺失策略和运行时可用性。ETF 与基金共用 `adjusted_nav`、`returns`、`market_high` 等 DSL 名称；底层数据集和源字段由 binding 决定。复权净值与原始行情具有不同价格口径，不能因为 Shape 相同就被当作同类价格隐式混算。

## Availability 契约

`POST /api/custom-indicators/variables/availability` 用于运行前检查。可使用兼容的 `kind + product_id` 单产品请求，也可以使用 `targets` 一次检查最多 10 个产品；两种方式不能同时提交。请求同时包含变量列表、运行周期和可选 `as_of`；响应按变量和产品返回：

- `available`、`partial`、`source_unavailable`、`field_missing`、`no_observations` 或 `insufficient_window` 等状态；
- 数据覆盖率、实际 Shape、实际窗口和数据最新日期；
- 稳定错误码与用户可读原因。

Availability 使用与正式运行相同的真实数据和切窗规则。公式编译后按 `required_variables` 检查实际数据源、字段、有效值、覆盖率及共同样本；`applicable_product_kinds` 只保留为目录提示，不再提前拒绝计算。稀疏可选字段不会缩短无关变量的窗口，缺失值不会前值填充或补零。

指标中心的公式构建阶段与产品选择解耦：资源目录和算子参数抽屉不请求、筛选或展示具体产品的 availability，只依据变量定义和当前计算域展示资源。变量条目展示含义、类型、Shape、来源、口径、频率、单位和适用范围，不出现“所选产品可用性”、覆盖率、观察数、数据最新日期或产品级错误。只有在用户选择产品并执行预览或正式计算后，系统才按实际产品、周期和 `as_of` 判断能否计算，并通过 `input_requirements` 和 `target_data` 返回中文字段原因、当前已有数据和技术明细；混合批次中单个产品缺字段不会影响其他产品。`POST /api/custom-indicators/variables/availability` 仍可供确有运行前预检需求的其他消费者使用，但指标中心构建目录不依赖该接口。组合域目前没有独立的 availability 请求，变量是否可执行由锁定快照、类型校验和组合运行诊断共同确定。

### 无数据时的日期说明

指标结果可附带 `data_context`，展示产品成立日期、上市日期、请求截止日，以及各输入源的首末数据日期和日期/公告过滤前后行数。这些字段来自已读取的身份信息和 lineage，不增加数据扫描；全量源日期仅供解释当前数据覆盖，不作为历史可用性或投资信号。

日期说明统一使用解析后的 ISO 截止日，兼容 API 已接受的紧凑或未补零日期。仍在使用的非 typed 标量入口保留身份日期和实际选中的数据源，行数以该入口完成缺失/无效值清理后的有效序列为基准；通过有序日期边界统计截止日内行数，不再读取 Parquet、不改变原窗口或 ETF 行情优先顺序。该入口只按数据日期切窗，`uses_disclosure_date=false`，不能当作已按公告日期认证。

前端逐来源说明公告筛选策略。`uses_disclosure_date` 表示该来源使用或要求公告日期策略，不代表已接受记录；`disclosure_status` 区分 `not_applied`（未执行公告筛选）、`applied`（已执行，可为零条）及 `required_unavailable`（要求公告日期但字段缺失，已拒绝使用）。单次、批量与时序入口保留同一状态。字段缺失在读数据前失败时，原始条数和日期筛选后条数保持 null/未核实，已接受条数为 0；不得将其描述成仅按日期使用了来源或本地源数据为空。旧结果缺少新增状态字段时按既有布尔策略展示；新结果明确拒绝状态优先于该布尔值。混合来源分别解释，没有截止日时不宣称执行过历史日期或公告筛选。

无有效观察值时，诊断区分 `PRODUCT_NOT_ESTABLISHED_AS_OF`、`NO_DATA_BEFORE_CUTOFF`、`NO_DISCLOSURES_AS_OF` 和一般字段缺失；源字段缺失等已有底层诊断保留具体错误码（如 `SOURCE_FIELD_MISSING`），不再统一包装为 `VARIABLE_UNAVAILABLE`。成立日期不作为额外过滤条件，数据起点也不等同于成立日期。时序计算已读入输入但全部结果非有限值时，返回 `NO_FINITE_SERIES_RESULT` 警告，仍保持结果不可用和缺失值语义；不改动数学公式或 NJIT 执行路径。

## 类型、公式与目录

类型同时约束 dtype、名义轴、shape、语义量纲与价格口径。只允许受控公式语法与注册算子；禁止任意 Python、属性调用、导入、文件或网络操作。infer 可以检查中间形状，公开标量输出则须满足对应类型与状态契约。

规范公式是可执行真相，display_latex 只是排版。画布、向导、公式往返必须保持参数、根与引用；旧可执行定义不能因当前目录无法结构化展示而被改写。资源目录按计算域和类型展示，真实目标 availability 留到预览／计算阶段。

## 四类唯一职责

| 类别 | 职责 | 示例 |
|---|---|---|
| 数学/统计原语 | 明确的通用数学运算 | 加减乘除、abs、mean、std、covariance、quantile、matvec、solve |
| 序列/状态原语 | 扫描、滑窗、递归或同一次模型拟合 | drawdown_series、last_drawdown_interval、rolling_mean、linear_fit |
| 索引/字段原语 | 只取值，不能再次扫描或拟合 | value_at、interval_start/trough/recovery、fit_slope/intercept/residual_sum_squares/total_sum_squares/count |
| 独立指标公式 | 用上述原语组合研究含义 | 累计收益、年化收益、主动收益、最大回撤幅度、日期、持续时间、R²、回归残差标准误 |

不增加新“组合算子”目录。既有指标复用仍按锁定版本展开为透明计算图。兼容旧表达式的语法适配只能在编译阶段展开，不能保存第二套生产数值实现。

## 本轮算子处理清单

基础算术16项、比较6项、线性代数8项、掩码14项、滚动5项、序列2项，以及常规归约/统计原语按原契约保留。方向、轴、自由度、NaN/Inf及样本下限不因为包装调整而静默改变。

重点调整：
- total_return(r) → product(1+r)-1。
- annualized_return(r,P) → (1+累计收益)^(P/length(r))-1；显式保留P>0、增长因子非负的输入限制，不能只展开公式而丢失原有边界。
- cumulative_return(r) → cumulative_product(1+r)-1。
- active_returns(a,b) → subtract(a,b)，保留同日期轴及收益语义检查。
- portfolio_returns(R,w) → matvec(R,w)，这里仅指单一静态权重收缩，不把真实动态权重会计收益偷换成固定权重。
- quadratic_form(w,A) → dot(matvec(transpose(A),w),w)，以基础算子表达原有先左收缩再求内积的顺序，不把历史公式擅自重排为另一个浮点求值次序。
- interval_depth不再作为新建指标可选算子；幅度从回撤序列通过最小值/位置取值与取负构造。
- date_at → 通用value_at，数值序列输出保留原量纲/价格基准，日期序列输出date；严格检查索引与类型。
- linear_slope/intercept/r_squared/regression_standard_error不再是独立拟合入口。一个linear_fit节点产生共享拟合状态，字段投影及普通数学构成独立结果。

累计收益、年化收益等仍可作为独立内置指标使用，不要求普通用户手写全部算子。旧协议/已保存公式中实际使用的名称可作为输入适配保留，但必须编译到当前唯一实现，并有范围/类型/结果一致性测试；不再放入新建资源目录。

## 通用索引、回撤区间与日期

value_at(x,k)使用零基位置：k必须是有限整数且在[0,n)；无位置、不合法位置返回不可用，不能隐式取整、负索引或填零。输出继承x的数值量纲和价格基准；date只能来自真实日期轴，不能把普通数值伪装成日期。days_between(a,b)负责日期差，返回自然日数。

回撤D_i=P_i/max_{j≤i}P_j-1。选中谷底t*=max argmin D_i（精确相同取最后一次）；p*为谷底前最后一个D=0的位置；r*为谷底之后首次D=0的位置。所有派生日期和时长引用同一个区间。

幅度：-min_i D_i，或者对存在的回撤区间计算-D[t*]。前者在无回撤时自然等于0，不制造虚假回撤日期。开始、谷底、恢复日期分别为d[p*]、d[t*]、d[r*]；下跌、恢复和完整时长分别为d[t*]-d[p*]、d[r*]-d[t*]、d[r*]-d[p*]。没有回撤事件时日期/事件时长不可用；没有恢复时只让恢复相关结果不可用。

区间识别只存峰值、谷底和恢复位置及必要的有效性状态，不再对外提供“深度”计算包装。不要把最长水下区间的日期或时长混入最深回撤。

## 共享回归状态

linear_fit(x,y)与linear_fit(y)使用同一带截距一元OLS算法；一输入时x为0..n-1，不分配无谓索引数组。输入至少2项，日期/长度须一致，有限值且解释变量有正变异；缺失值不在此处私自删行。

共享拟合状态保存beta、alpha、残差平方和SSE、总离差平方和SST及有效样本数n。投影算子每次只读取一个字段，不再次拟合。R²由1-SSE/SST构成；标准误由sqrt(SSE/(n-2))构成。SST=0时R²不可用；n≤2时残差标准误不可用，但已经有效的斜率和截距不受影响。状态类型不能被当成普通scalar/matrix参与加减、不能直接发布为指标结果。

线性拟合的数值内核只保留一份。旧四个结果名经编译展开后必须指向相同状态节点。状态共享的键包括算子与数值版本、输入顺序、完整类型及参数，不按显示名或随意代数等价合并。

## 编译器与执行

流程：受限源码解析 → 原接口参数/类型校验 → 业务语法展开 → 原语DAG类型检查 → 公共节点去重 → 多指标运行计划合并 → 选择根依赖闭包 → 已预热NJIT。

语法展开只由服务端受控规则进行，不能eval用户文本；不能新增不受约束的循环或Python回调。规范表达式、DAG、LaTeX说明与Excel必须表达同一计算。相同子表达式在展开后统一身份；历史源码和业务版本不原地重写。

正式运行不临时JIT，不因计划缺失退回逐指标重复计算；已准备的超集计划用enabled根掩码裁剪。显式准备阶段及启动预热负责新组合，结果缓存必须在执行之前检查。

共享节点复用不等于所有数组只扫描一遍。循环融合单独验收，不能用一个HTTP或一个njit装饰器作为证据。以生成图中的状态节点/调用次数和数值回归证明同一次拟合及回撤识别共享。

编译计划身份必须包含本次lowering/compiler修订，避免命中旧生成代码；结果缓存还须区分数据代际、有效日期轴、窗口、输入及参数。不同样本集合不为共享而强制取交集，错误按依赖隔离。

## 前端

保留“基本信息 → 单一结果设置 → 计算逻辑 → 校验预览”。资源目录只显示可用原语、状态和投影；退役业务包装不再是可选项。状态输入标为“回撤区间”或“回归拟合结果”，投影参数明确“取哪个结果”，没有多标量指标或指标组概念。

用户构建开始日期：最后一次最大回撤区间 → 起点位置 → 按位置取值（日期轴）。构建幅度：回撤序列 → 最小值 → 取负。构建R²：同一次拟合 → 残差/总离差平方和 → 除法 → 1减比值。普通用户可从已有独立指标展开修改。

公式主展示使用数学LaTeX：D、I*、p*/t*/r*、x_k、日期差、alpha-hat/beta-hat、SSE/SST、1-SSE/SST；不得用原始函数名替代数学公式。源码编辑与展示公式分离，简称符号仅展示，不冒充可逆编译源码。状态选择、画布节点摘要、公式说明和详情也使用同一后端数学记号。

## 最大回撤的唯一业务规则
给定日期升序、严格有限且为正的净值 P_i：H_i=max_{j≤i}P_j，D_i=P_i/H_i−1。回撤序列为非正值。

- 最大回撤幅度 M=−min_i D_i。
- t*=max argmin_i D_i：若多个位置具有相同最大回撤，选最后位置；同一回撤段出现多个相同谷底，也选最后谷底。
- p*=max{j≤t*: D_j=0}：谷底前最后一次历史峰值；重复峰值选最后一次。
- r*=min{j>t*: D_j=0}：选中谷底后首次恢复峰值；不存在则恢复日期及恢复时长不可用。
- 最大回撤开始日期为 d[p*]；最大回撤结束日期明确命名“最大回撤谷底日期”，为 d[t*]，不与恢复日期混淆。
- 最大回撤持续天数（下跌阶段）=d[t*]−d[p*]，单位自然日；恢复天数=d[r*]−d[t*]；完整持续天数=d[r*]−d[p*]。
- 如需观察期数，使用位置差算子，单独标明“观察间隔数”，不能冒充自然日。
- 所有日期与持续时间均取同一最大回撤区间，不再以最长水下段替代最深回撤段。
- 无回撤：幅度0；开始、谷底、恢复日期以及事件持续时间均不可用，因为不存在回撤事件，不虚构一个零长度区间。空输入、非有限/非正净值在数值入口失败关闭；日期按数据提供器的对齐、排序和重复处理契约验证。
- 相等采用规范回撤序列的精确浮点比较，不用宽泛 isclose 将真实不同深度误判为相等；展示四舍五入相等不代表计算深度相等。
- 未恢复不填0、不把截止日伪装成恢复日；相关结果携带 DRAWDOWN_NOT_RECOVERED 状态。最大回撤率仍可使用。

参考概念：VectorBT 官方将 peak/valley/end 及 Active/Recovered 分开；本项目起点、谷底并列规则以本文件的用户需求为准，并不宣称与其他库默认选择规则相同。https://vectorbt.dev/api/generic/drawdowns/

## 多个独立指标如何共享执行
### 逻辑合并

批次按真实输入域、日期窗口、数据快照/可见时点、频率和缺失策略分区。对每个分区把独立指标根合并到同一 DAG。节点身份包含：算子ID+版本、完整输入类型/语义、规范常量、按顺序的父节点身份及实际参数绑定。不能仅按节点ID、公式显示文本或指标名称共享；不同无风险利率等绑定保留区别。

只合并纯函数中确定相同的节点，不做改变浮点计算顺序的代数重排，不跨币种/区间/数据代际合并。共享缺失字段不强迫无关指标使用交集样本。多根仅为执行计划内部结构，与业务指标类型无关。

### 物理执行与裁剪

固定签名批计划接受输出选择掩码，按选中根求依赖闭包；只有被依赖的节点执行。共享节点只执行一次，缓存值和独立状态供所有依赖者使用。每个根分别产生数值和状态，局部分支失败不牵连不依赖它的指标。

公共节点复用与循环融合分别审计：前者必须保证，后者只在语义等价且基准更快时采用。不要把“一次HTTP”“一个njit函数”称作“只遍历一次”。

### 预热与任意选择

不枚举所有指标组合。显式准备阶段编译兼容指标的共享计划；已保存评价方案/快照编译其固定计划。可利用已预热超集计划和选择掩码执行任意子集；若没有覆盖所选指标的预热计划，需先经准备入口编译，正式 evaluate 失败关闭，不能退回逐指标重复执行或临时JIT。

编译计划缓存绑定算法/类型，结果缓存绑定指标版本、参数、实际窗口和数据指纹。必须先检查结果缓存再执行计算；命中不能只是“结果取缓存但计算已经跑过”。跨请求复用只限相同数据代际的显式缓存，不能使用进程级可变上下文混淆请求。

## API 与前端

result_kind 仅 scalar/time_series。标量结果新增/确认 value_type（number/date/duration）、日期 ISO value、duration_unit、status/warnings。日期只展示/筛选，不参与评分；持续时间可由用户明确配置优劣方向。

保留 indicator_id+revision 作为公开引用；不再要求 output_id。多指标批请求仍返回独立 results[]，列表、详情、对比、评价、组合诊断、快照和导出统一使用这些独立引用。前端不展示共享编译内部根/组；只在诊断信息中显示计划和缓存统计。

输出来源与引用解析由服务端规范化；不在浏览器正则猜算子输出。画布单标量只有一个最终结果，时序保留多通道。编译/校验错误定位节点，日期算子输入类型不匹配时给出中文诊断。

## 快照与公开 API
标量配置按锁定指标版本、周期执行已准备的共享计划；日期以 ISO 日期保存。时序配置必须指定 channel_id 和 last_finite，不能送入标量执行接口，也不能把两个通道写入同一字段。同一时序指标版本和目标的多个通道只运行一次原有时序计划。

内部快照模式在完整请求区间内通过固定签名 NJIT 取末个有限值，然后记录 value_date；不从最多5000点的图表序列反推，不使用预热区间的有限值补齐本期结果。所取值早于区间末日时显示说明；全缺失返回不可用而非零。快照缓存与普通图表缓存区分，参数/源数据/版本仍参与身份计算。元数据保留通道、归约、锁定展示信息及值的实际日期。生成期间源数据代际变化则拒绝产出；完成或失败均关闭本任务的计算资源。

## 持久化、并发与规模

- `data/custom_indicators.json` 保存工作区指标当前版本和历史版本；`data/evaluation_plans.json` 保存评价方案及锁定的指标 revision。
- 写入使用锁文件、临时文件、`fsync` 和原子替换。更新和删除携带 revision，版本冲突返回 HTTP 409。
- 内置指标只读；仍被评价方案引用的工作区指标拒绝删除。
- 计算缓存键包含定义/算子/变量/数据契约版本、产品或组合快照、运行周期或快照窗口、有效截止日和源数据指纹。
- 公式、DAG 深度、观察数、产品数和中间数组预算仍按后端契约限制；指标请求容量见下节。

## 版本与容量的现行解释

研究看板没有 8 项的产品选择上限。批编译宽度／评价方案规模与 evaluate 请求容量分开：前者 MAX_INDICATORS=10，后者 MAX_EVALUATION_INDICATORS=200；不能因页面列表不限而取消服务端资源保护。走势图按时序接口上限分批，见产品图表契约。

参数契约新增注册表 2.4.1，DSL 仍为 2.4.0；历史注册表的表达式能力按锁定版本适配到唯一当前计算实现，不原地升级历史定义。此前“typed 2.1 是所有新建的当前版本”的叙述只属于旧基础文档。

最大回撤并列规则变更不能回写旧运行。另一工作区若发现真实多标量旧引用，须单独制定迁移；本工作区历史扫描为空不证明所有部署都没有旧引用。

市场归因不再作为指标中心内置黑盒；自定义 math／regression 原语仍可组合研究，风格暴露和收益贡献由[因子研究](../factor-research.md)负责，不因清理旧说明而移除现有能力。

验收包括独立数值参考、状态／缺失、参数身份、共享节点只算一次、缓存命中零计算、准备不足失败、签名不增长、画布与 Excel 一致。历史证据见[工程验收纪要](../verification/engineering.md)。
