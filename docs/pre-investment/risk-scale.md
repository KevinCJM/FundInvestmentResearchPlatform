# Universal 风险标尺

本页是 Settings → 风险等级配置中心的主要入口。它定义统一 C1–C5 参考，不预测某个投资者的收益，也不依赖 LTCMA 或 Mandate 投资期限。

## 核心业务

Risk Scale 是系统级 Universal benchmark。流程固定为：参考资产历史数据 → 严格共同区间 → 历史年化收益/协方差 → 有效前沿 → C1–C5。Risk Scale 不依赖 CMA、预测期限或某个 Mandate 的投资期限。

参考资产只有两类：

- `cash`：纯现金。无代理、无再平衡，用户直接填写年化收益率，默认 0%；波动率及与其它资产协方差固定为 0。
- `market`：非现金。选择指数、ETF 或基金代理。指数按用户选中的指数值序列计算；ETF/基金只使用复权价格或复权净值。

Risk Scale 不需要“经济角色”。增长、利率、信用、通胀等标签不参与有效前沿或 C1–C5 数学计算，因此不要求用户填写，也不写入参考资产契约。Mandate 如需现金角色，只在消费边界按 cash/non-cash 映射。

## 数据与时间

- 参考研究日不可编辑：有 PIT 用 PIT 日期；明确无 PIT 用当天日期；PIT 尚未确认时禁止开始计算。
- 预计复核日可选：提前 30 天提示，到期继续提醒，但不自动失效。
- 用户不输入样本区间。系统对所有非现金代理真实有值日期取严格交集，现金不缩短区间。
- 前端展示共同历史区间、观测数以及各大类历史年化收益/波动率。
- 冻结参考版本同时保存大类 ID 与人类名称；UI 永远优先显示名称，不把内部 `asset-*` ID 当业务名称。
- 代理来源冻结时同时保存名称与代码；旧版本若缺少展示名称，编辑页可按冻结 `series_id` 从当前数据目录精确回查名称，仅用于展示，不改写历史冻结版本。

## 代理与再平衡

代理选择不受市场、币种或产品池门禁影响；这里只消费历史收益变化，不做产品可投资性筛选。来源仍必须有真实可读取序列，ETF/基金仍必须使用复权数据。

非现金大类再平衡规则：

- `daily`：默认；每个共同有值日恢复目标权重后计算下一期收益。
- `monthly`：每月最后一个共同有值日期收盘后恢复目标权重。
- `quarterly`：每季最后一个共同有值日期收盘后恢复目标权重。
- `yearly`：每年最后一个共同有值日期收盘后恢复目标权重。
- `buy_and_hold`：仅初始按目标权重配置，之后自然漂移。

## 约束

无做空、无杠杆、权重合计 100% 是固定基础契约。

单大类约束和分组约束默认都为空，即没有额外限制。前端默认收起；用户展开并修改时才写入稀疏约束。单大类恢复为 0%–100% 后自动从 `asset_limits` 删除，不把“无约束”保存成冗余数据。

## 分档与人工微调

算法先生成一套初始 C1–C5 边界。自动算法结果允许通过 `adjusted_caps` 做精确人工微调；这不是重新选择另一种算法，原始算法身份和原始边界继续保留在诊断证据中。

自动分档同时支持“收益等分”：在现有五段可行约束下，将有效前沿最低到最高的预期年收益跨度按 20% / 40% / 60% / 80% 寻找最接近的分界节点，再把这些节点对应的波动率作为 C1–C4 风险上限；C5 使用前沿最高风险端。风险等级仍由波动率边界定义。

边界始终严格递增，区间语义保持：C1 为 `[0, C1]`，后续为 `(前一档上限, 本档上限]`。因此用户调整某一上限时，相邻两档自动联动，不存在独立可编辑的下限。

边界变化后只重新分档，不重新读取历史数据或重算有效前沿；后端使用调整后的边界重新选择每档代表节点，因此代表权重、预期收益、波动率、ES 和回撤画像同步更新。前端使用精确数值输入作为主要微调方式，图表竖线随新的后端结果同步移动；不以拖拽作为唯一编辑方式，避免基点级误差。

选择新的分档算法或修改有效边界后，前端自动请求重新分档；不再提供“更新前沿与分档预览”按钮。连续输入采用短防抖，并取消过期请求。

## 前端业务视图

前端只展示业务用户需要理解和操作的信息；不可变 ID、内容哈希、预览哈希、内部来源 ID、执行审计、求解器逐点诊断等仍由后端完整保存，但不作为普通用户界面内容。

“参考资产与代理”中的“添加参考大类”固定放在所有大类配置的底部，避免配置较多时反复滚回顶部；删除“待配置”“名称待补充”等无动作价值提示。代理选中后只显示人类名称、来源类型和权重，不展示内部 series ID 或字段名。

“历史参数与约束”只展示共同历史区间、大类名称、年化收益/波动和业务约束；不显示 reference ID 或内容哈希。“前沿与五档”只保留有效前沿、C1–C5、代表组合和用户可理解的风险画像；删除“历史参数与来源证据”“求解、网格稳定性与逐点诊断”等后台计算审计面板。发布详情和版本比较同样不展示内部 ID/哈希。

## 系统默认与治理

发布仍生成不可变版本；编辑已发布方案生成新版本，不覆盖历史。系统默认通过独立绑定指针管理，不改变既有引用。

风险等级配置中心列表同时读取默认绑定。如果某个发布版本当前是系统默认，状态栏直接显示“系统默认”；临近复核/已到复核日提醒可与默认状态同时展示。

## 数值分档契约

以下保留连续动态规划、区间和代表组合的专业定义；另支持收益等分及人工精确微调。历史文档中的“选择单套 CMA”界面已被共同历史矩生成取代。
## C1–C5 分档算法与边界

### 分档算法策略与默认方法

分档算法本身是**可配置、可版本化的策略**，不是 RiskScale 写死的一段逻辑。所有自动方法消费同一组已经通过连续性、非支配性和数值校验的前沿节点，统一输出四个切点、五个风险上限、代表点及诊断；它们不得各自重算历史矩 或维护另一套前沿求解器。

当前注册以下方法（新增收益等分保留五档风险上限语义）：

| UI 名称 | `algorithm_id` | 核心含义 | 定位 |
|---|---|---|---|
| 前沿形状（推荐） | `frontier_shape_dp_v2` | 同时利用标准化风险变化、收益变化、局部角度／曲率特征和弧长权重，寻找五段内部形状较一致的连续区间 | **系统默认** |
| 风险等距 | `equal_volatility_v1` | 在 GMV 到前沿右端的风险轴上按 20%／40%／60%／80% 等距切分 | 简单、可解释的基准方法，不作为默认 |
| 前沿弧长等分 | `equal_arclength_v1` | 按标准化风险收益曲线的累计弧长 20%／40%／60%／80% 切分 | 同时考虑风险和收益的几何距离，但不识别曲率结构 |
| 收益等分 | `equal_return_v1` | 按前沿收益跨度20%/40%/60%/80%选节点，返回相应波动上限 | 自动分档选项 |
| 人工风险阈值 | `manual_volatility_bands_v1` | 维护者直接输入五个风险上限并说明依据 | 治理／外部政策模式，不属于自动失败 fallback |

这里**明确允许风险等距**，但不能把它误写成“有效前沿天然应当按 X 轴五等分”。它只是用户主动选择的一种校准规则。同理，弧长等分也是显式算法选择。

算法注册项至少声明：`algorithm_id / version / input_contract / parameter_schema / complexity / deterministic_tie_rule / supported_risk_basis / execution_kernel_id`。RiskScaleVersion 冻结实际采用的算法 ID、参数和执行版本；以后新增分档模型时扩展注册表，不修改已经发布版本的语义。

所有方法遵守统一输出契约：

```text
cut_node_indices[4]
risk_caps[5]
representative_node_indices[5]
segmentation_status
algorithm_id / algorithm_version / parameters
quality_diagnostics
```

切换方法只重新运行分档内核与代表点选择，复用同一前沿数组。后端应预先计算并复用标准化坐标、边长及累计弧长；各算法不得重复复制整条权重矩阵。数值实现继续使用预热、固定签名 NJIT；请求路径禁止临时编译或 Python fallback。

#### 默认：`frontier_shape_dp_v2`

沿用上位文档的形状分段作为系统默认，不替换为收益五等分、裸斜率聚类或风险等距默认值。它的目标是依据**风险增加、收益增加以及前沿方向／弯曲程度的变化**寻找分界，而不是只看 X 轴距离。

设经过连续性与非支配检查的前沿节点为 i=0…J，按照风险递增排列。标准化：

\[
x_i=\frac{\sigma_i-\sigma_0}{\sigma_J-\sigma_0},\qquad
y_i=\frac{\mu_i-\mu_0}{\mu_J-\mu_0}.
\]

跨度小于冻结数值阈值返回 `DEGENERATE_FRONTIER`。不从重复风险点构造零长度有效边。

每条边计算：

\[
\theta_i=\operatorname{atan2}(y_{i+1}-y_i,x_{i+1}-x_i),\qquad
h_i=\sqrt{(\Delta x_i)^2+(\Delta y_i)^2}.
\]

用 h、hθ、hθ² 三组前缀和得到区间代价：

\[
E(l,r)=\sum_{i=l}^{r-1}h_i\theta_i^2-
\frac{(\sum_{i=l}^{r-1}h_i\theta_i)^2}{\sum_{i=l}^{r-1}h_i}.
\]

只有可解释的舍入误差负值允许置零。非有限值、零权重区间或明显负代价直接报错。

#### 可选基准算法

**风险等距 `equal_volatility_v1`** 只在用户显式选择时使用。令前沿左端风险为 `sigma_0`、右端风险为 `sigma_J`，四个目标边界为：

\[
\tilde b_k=\sigma_0+\frac{k}{5}(\sigma_J-\sigma_0),\qquad k=1,2,3,4.
\]

再映射到满足顺序、最少边数和最小跨度约束的最近有效前沿节点，`b5=sigma_J`。这里的“最大风险”仅指**有效前沿最高收益右端点的风险**，不是全部可行权重中的最大方差。该方法容易解释，但不会识别“多承担风险却只能换来少量收益”的弯曲区，因此不作为系统默认。

**前沿弧长等分 `equal_arclength_v1`** 使用与默认算法相同的标准化 `(x_i,y_i)` 和边长 `h_i`。令累计弧长：

\[
H_j=\sum_{i=0}^{j-1}h_i,
\]

四个目标位置为 `k*H_J/5, k=1..4`，再选择满足顺序和最小跨度约束的最近有效节点。它同时吸收风险和收益两个方向的变化，但只按“走过的曲线距离”分段，不判断局部方向变化是否形成新的风险收益区域。

两种基准算法均为确定性 O(J) 算法，可以与 `frontier_shape_dp_v2` 共用标准化数组与累计弧长缓冲区。比较算法时只生成不同的切点索引，不复制 `weights[J,N]`。

### 连续动态规划

\[
D(k,j)=\min_{i<j}\{D(k-1,i)+E(i,j)\},\quad D(0,0)=0.
\]

其余初值无穷大。k=5；默认每档至少 5 条有效边、标准化风险跨度至少 0.05。候选区间 `[i,j)` 的风险跨度为 `x_j-x_i`，回溯得到的切点是节点索引，不是再加一后的边索引。

并列最优按四个切点的字典序选择最早组合。不能简单认为“取当前最小前驱 i”就等价，也不能在每一层累积使用一次 tie 容差，最后超过总目标的允许误差。

具体实现：先计算各起点、剩余段数的后缀最小代价，得到完整最优值；再从左向右选择最早的合法切点，要求“已采用代价 + 当前段代价 + 最优剩余代价”不超过完整最优值加一次全局 tie 容差。选中后递推，最终再次复核总目标。这样将全路径字典序与总容差放在同一个契约中。

前缀和让区间查询 O(1)，总计算仍为 O(5J²)。不构建 J×J 的区间代价矩阵；保存 O(5J) 的后缀 DP 状态及少量切点，空间 O(5J)。

### 近直线与稀疏曲线

当且仅当当前显式选择的是 `frontier_shape_dp_v2`，且全体有效角度变化小于版本化阈值（上位文档初始值 0.02 弧度），该算法内部采用明确记录的累计弧长 20／40／60／80% 切分作为**近直线退化处理**。这与用户主动选择 `equal_arclength_v1` 是两个不同语义：前者仍记录主算法为 `frontier_shape_dp_v2` 并附 `fallback_reason=near_linear_frontier`，后者直接记录弧长等分算法。

取满足最少边数与最小跨度的四个不同有效节点；若最近点局部选择冲突，使用受约束的有序切点选择，不按独立四舍五入制造重复边界。

DP 无合法解且不满足近直线条件时，返回 `SEGMENTATION_INSUFFICIENT_RESOLUTION`；不能无提示切换等波动宽度或人工阈值。

### 稳定性复核

同一冻结输入分别求 101 点和 200 点前沿。边界比较使用同一组已核验端点作为标准化尺度，先检查两次端点一致性；不能各自随意缩放后掩盖端点漂移。

\[
\Delta_b=\max_{k=1\ldots4}\frac{|b_k^{101}-b_k^{200}|}{\sigma_{right}-\sigma_{GMV}}.
\]

超过初始复核阈值 0.02 时，输出 `unstable_calibration`。用户可以调整输入、提高来源质量，或由有权限维护者记录复核理由后采用明确标记的版本；自动模式未经确认不得设为默认。该测试只是网格稳定性，不是模型样本外有效性检验。

默认采用 101 点结果，200 点用于验证。人工选择采用更密结果时也要明确记录，不能后台交换发布边界。

### 分类区间与数值契约

上限 `0 <= b1 < b2 < b3 < b4 < b5`；不得出现倒置或重复上限。自动模式须满足最小分段跨度，b5 为前沿右端风险。人工模式 b1=0 表示 C1 仅包含零风险点，并非数据缺失；其下游可用性须另查零上限支持能力。

```text
C1: [0, b1]
C2: (b1, b2]
C3: (b2, b3]
C4: (b3, b4]
C5: (b4, b5]
大于 b5: above_scale
低于参考 GMV: 保留 C1，并附 below_reference_range
NaN／无可比口径: unavailable，而不是 C1
```

恰好等于边界属于较低档。固定比较容差同时作用于“是否属于某档”和“是否超过授权上限”；只要一个组合被分类为不超过 C3，就不能被同口径的 cap 检查判定超限，反之亦然。对差值在容差内的贴边点记录 `within_boundary_tolerance`，不依赖显示舍入。

不能将上限之外风险钳制到 C5，不能将不合法负波动取绝对值，不能将零方差视为计算失败；零方差可以分类为 C1，但可能无法支持完整前沿分档。

### 人工阈值

人工模式保存五个严格递增、首项非负的上限、来源和说明；来自自动覆盖时还保存自动值。重复、倒置或负上限拒绝，并给出字段错误。零上限不偷偷改为一个小正数；若目标消费者不支持，应显示“零上限尚不能用于该目标接口”，保留正确的标尺内容。

超过参考最大风险的部分标为 `not_calibrated`。某档在可用前沿内没有有效节点时，代表权重、收益和画像均为空并附原因，不取邻档组合冒充。

手工阈值可以有外部政策依据，但系统不据此认证适当性。当前研究只实现数字授权，不能将人工说明转换成尚未执行的风险保证。

### 代表组合

按实际分类区间选取有效节点，再取档内累计弧长的中位节点。边界点属于较低一档，高一档的代表选择必须排除该点，避免表内出现代表风险不属于本档的情况。

代表点仅用于解释；不是该档中风险最高、回撤最大或唯一可持有的组合。

## 参考画像：波动、ES 与回撤

### 基础指标

每档基础展示为参考 CMA 下的代表组合年化预期收益及波动：

\[
\mu(w)=w^\top\mu,\qquad \sigma(w)=\sqrt{w^\top\Sigma w}.
\]

对浮点级微小负方差按已验证容差处理；明显负值作为矩阵或计算错误，而不是开方前全部截零。

### 历史画像

第一版支持共用真实收益面板上的历史 VaR／ES 与历史 MDD，置信水平默认研究设置为 95%，并在表中显示实际观察频率与样本区间。

参考权重的历史回放需冻结独立的组合再平衡规则：与“类内 Proxy 再平衡”不是同一个层次。可默认按月重设大类代表权重并明确标注。无数据或存在持有期缺失时，相关画像返回 unavailable，不能用剩余资产补齐。

冻结权重来自当前参考研究时，这一历史回放是事后参考组合画像，不声称当时已确定该组合。

每日历史 ES 不乘 sqrt(252) 后称为年度 ES；年度、月度、模拟与压力画像分别拥有自己的指标契约。

### 经验 ES 的一致实现

损失定义 L=−R，正数越大表示损失越大。设 B 个等权损失样本降序排列为 `L_(1)…L_(B)`，`q=(1-alpha)B`，`k=floor(q)`，`f=q-k`：

\[
ES_\alpha=\frac{\sum_{i=1}^{k} L_{(i)}+fL_{(k+1)}}{q}.
\]

f=0 时不读取下一项；0<q<1 时取最大损失。该分数尾部规则与上位文档的经验 CVaR 优化表示一致。VaR 使用冻结的经验逆分布分位数规则，不能展示与门禁各调用不同插值方法。

尾部样本不足时保留技术计算值与“不足以稳定估计”的状态，并按画像质量策略决定是否展示数值；不把单个样本当作可靠尾部估计。所有收益为正时 ES 可能为负，保留其含义，不把负 ES 直接改成零。

排序使用结果专属损失缓冲区，不能原地排序只读收益面板。

### 回撤

\[
MDD=\max_t\left(1-\frac{V_t}{\max_{u\le t} V_u}\right).
\]

V 使用剔除外部现金流影响的参考市场净值，包含初始净值作为首个峰值候选。资金支付造成的余额下降不是市场回撤。

仅给定 mu／Sigma，不能得到唯一真实 ES 或 MDD。参数分布、Monte Carlo 与压力画像列为可扩展能力；未实现或缺模型时显示未计算，不自动假设正态、不在本模块新建另一套情景引擎。

### 下游意义

画像用于理解参考组合。除非下游求解与最终门禁明确消费了相同指标、期限、置信水平和来源，否则它们都不是硬约束。

缺少可选历史 ES 不必否定一个数学上有效的波动标尺；但必须显示未提供画像。低风险锚、冻结历史矩合法性等默认资格的必需证据缺失则不能被当作可选警告跳过。

## 后端边界

沿用FastAPI模块化单体和 `backend/strategic_allocation` 领域，复用成果仓储、原子存储和统计/QP内核。参考来源由历史数据冻结生成，不要求用户提供LTCMA发布版本。新功能必须通过依赖注入在离线测试中运行，不能初始化或污染正式磁盘。

| 层 | 职责 | 不做什么 |
|---|---|---|
| reference输入 | 必需的参考现金及市场代理历史输入与冻结 | 不重建独立CMA研究中心、不修改投前流程 |
| 矩参数前沿 | 直接读取冻结mu/Sigma，复用共享QP/LP内核 | 不构造伪历史数据、不调用历史HTTP接口 |
| 风险分档 | 形状DP、风险等距、弧长等分、人工阈值 | 不生成另一条前沿、不改变市场假设 |
| 服务编排 | 校验、读来源、计算准入、确定性哈希、结果封装 | 不承载数值循环、pandas计算 |
| 存储薄层 | 草稿修订、版本、幂等确认、默认CAS、退休 | 不重写历史、不复制第二套成果数据库 |
| 路由 | 类型化契约、错误映射、能力查询 | 不静默降级、不藏数值错误 |

共享层只修改本模块必须用到的接口；原签名保留时委托唯一当前内核，并进行既有调用回归。不得增加未使用的通用插件、任务平台或新依赖。

## 有效前沿与分档的具体实现约束

### 复用现有SAA求解路线

固定采用目标收益扫描，不新增风险网格求解器：

1. 求GMV；对PSD且多最优的GMV进行最高收益并列处理。
2. 求最高可行预期收益，再取该收益面上最低方差作为右端。右端不是全空间最大方差。
3. 在两个端点收益之间生成101个目标点；每个目标求 `min w'Sigma w, mu'w >= target`。200点用于稳定性复核，保持现有上限，不擅自开放500/1000。
4. 直接消费矩，不在每个点重新计算统计或扫描历史收益。热启动须先保证新目标下可行；失败目标保留状态与缺口。
5. 共享QP需要的一般等式/可行初点支持只在单一内核及薄适配中补齐；结构矛盾、初点不可行、迭代耗尽、数值失败分开。没有证书不宣称严格不可行。

“按风险上限最大化收益”与“按收益下限最小化风险”是两种参数化，不是严格意义的拉格朗日对偶问题；本轮采用后者以复用存量实现。

### 可选分档

默认 `frontier_shape_dp_v2`：对标准化风险收益曲线的局部方向角作弧长加权连续DP。它反映方向变化，并非直接计算二阶微分曲率，也不声称发现客观投资偏好。

可选 `equal_volatility_v1`、`equal_arclength_v1`、`equal_return_v1`、`manual_volatility_bands_v1`。共同冻结算法ID、版本、参数和数值策略；切换仅重分档，不重新估计历史矩/重求前沿。

自动切点满足最小边数、跨度、顺序约束，保持五个严格递增上限。最近节点需要全局约束选择时不宣称总是O(J)：采用有界DP并记录真实复杂度；不独立四舍五入产生重复点。形状法近直线退化到弧长须记录原因，与用户主动选弧长法区分。

人工模式保存五个上限及依据；超前沿范围无虚构代表组合。统一分类容差，等于边界属于较低档；超过C5返回above_scale；无值返回unavailable。
## 发布审核补充：当前引用资格与列表治理

- SAA/TAA 历史记录继续读取冻结数值。当前产品应用额外按调用方明确传入的战略研究根目录读取标尺治理状态（生产装配读取 `STRATEGIC_ALLOCATION_DATA_DIR`，不把产品域目录当作成果目录）、校验引用指纹及冻结来源；停用、失效、无法读取或缺少上下文均不能获得当前应用资格。TAA 预览显示阻断原因，导出和直接产品写入在共享应用门禁重新检查，不能只信任保存时的可用标志。
- 列表删除当前默认版本必须勾选明确清空默认的确认；提交前重新读取默认状态。版本在对话框打开后变成默认时，要求补充确认，不能自动发送 `clear_default=true`。
- 发布版本行可选择恰好两个不同 ID 进入现有比较页，草稿不参与比较。选中状态可以跨已加载页面保留，删除版本会移除相应选择。
- 列表按 API 的 `next_offset` 逐页加载，保留先前行并按 ID 去重；不会把第一个 100 条当作全量。删除已加载版本后修正下一页偏移，避免跳过紧随其后的记录。

- 101/200 点自动分档复核不稳定时，研究版本仍可在确认警告后发布，但默认资格阻断；基于该不稳定算法的人工微调同样阻断。设置默认及读取已有默认时重新检查冻结的稳定性证据，不能沿用旧版本误记的 eligible=true。独立人工阈值模式保留原契约，本次未加入自动绕过。
- 版本查询单独返回 `current_default_eligibility`，详情页用当前默认资格禁用激活并显示原因；冻结 `preview.default_eligibility` 只作为发布时证据，不再作为旧版本当前可激活的唯一依据。

## 草稿并发与历史发现

从草稿进入的预览（含实时分档调整和方法比较）携带 `draft_id` 与加载的 `draft_revision`，发布复用预览回显，服务端在预览及确认事务内检查修订和方案归属。修订号表示已保存的编辑基准，当前内存修改由 preview_hash 绑定，不要求含 UI 元数据的草稿 JSON 与数值定义逐字相等。另一个标签更新或删除草稿后返回 REVISION_CONFLICT；重新加载才可继续。保存新修订会使旧预览失效并回到计算步骤，防止沿用旧修订发布。

风险标尺列表增加“显示已停用的历史版本”，通过 `include_retired=true` 获取带 retired 状态的可分页目录。历史行提供只读详情及比较，不提供重复删除或直接编辑；普通目录继续排除退休版本，目标的研究日适用选择逻辑保持原契约。历史查询不改变成果指纹或恢复默认资格。

## 现金端点与画像再平衡证据

系统默认要求低风险端点的冻结权重由唯一合格现金大类组成（现金权重1，容差1e-7），同时仍须通过原零波动/求解状态检查。其他市场代理即使恰有零历史方差，也不能替代被约束排除的现金锚。当前默认资格复核同样检查历史冻结端点权重，不只沿用旧 eligible 字段。

代表组合 ES/MDD 的外层回放使用月度再平衡，该规则以 `result.diagnostics.representative_portfolio_rebalance=monthly` 冻结并参与预览/成果指纹；前端独立展示外层规则与代理内部规则的区别。旧版本没有该证据时明确显示未记录，不补写历史、不默认解释成买入持有。本次未改变回放数值算法。

## 不可变版本与治理

预览、草稿、发布版本分开；发布校验输入、前沿、分档与 preview hash。已发布版本不可覆盖，默认绑定是独立指针。版本退休阻止新引用，历史结果仍可读取；复核提醒与自动失效不是同一状态。

沿用现有 scope 权限与统一错误适配；页面不展示内部 ID／hash，但后端必须冻结这些证据。前端修改依赖时废弃旧预览，自动刷新分档只使用既有前沿，不重复取数。

仅数值可行不等于端点最优或前沿稳定；迭代、容差和分档稳定性不通过时不得发布校准版本。现金零方差、纯现金／退化前沿、稀疏曲线、边界等号和代表组合重选需要分别验收。

下游[投资目标](mandate.md)消费冻结分档，实际组合由[SAA](saa.md)在自身 CMA 下重验。历史证据和未完成边界见[配置验收纪要](../verification/allocation.md)。
