# 全量文档审核报告（2026-10-04）

## 1. 结论

本报告记录2026-10-04文档审核完成时的范围与结果。下文“本轮”指审核阶段；后续提交、推送、PR及其CI属于单独的发布阶段，以实际PR记录为准。

本轮对全部71篇既有 `docs/` Markdown及项目根 `AGENTS.md`、`README.md`、`deploy/README.md` 完成逐篇全文审阅，对高风险业务主张、关键前后端/数据/AI调用链和文档时效冲突进行有界核验。原123个Docs文件逐项归属见[覆盖台账](audit-files-2026-10-04.md)。这不是“每一句都已证明正确”，也不是全量业务测试、投资资格或生产部署认证。

已原地修订确定的事实勘误、陈旧实现说明、引用断链和证据过度表述。保留批准目标、历史证据、未复验结果和待决定事项；没有修改业务源码、算法、运行环境或安全配置，没有提交、推送、启用vault/CLI、安装插件或迁移数据。

最重要的剩余问题：

1. **RiskScale币种证据缺口**：请求标签固定CNY/no-conversion，但静态源码没有逐代理币种认证/换汇证据。跨币种原值混合只能解释为合成参考，不能自动视为CNY可投资组合风险。
2. **因果审计覆盖缺口**：公式超过节点预算时会产生未审warning，汇总仍可能为CAUSAL。该枚举不能证明全图或所有输入已审。
3. **复权经济口径尚缺独立证据**：同源价格/涨跌幅恒等及极小数值残差不能证明企业行动、分红再投或正式因子等价。
4. **历史实证未独立复现**：本云检出不存在正式 `data/`，因子、状态、行情与部分原验收制品不能重跑；原收益、IC、R²和历史通过数仍只代表旧记录。
5. **生产与外部框架未核**：本平台代码已在Dev；外部Agent当前发布制品、生产身份/网关、真实模型效果、成本和生产切换不由此得到证明。
