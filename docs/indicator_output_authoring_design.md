# 指标中心：结果配置与计算逻辑分离

## 问题与本次范围

截图中的常驻“多结果计算 → 最大回撤分析 → 使用此计算”把单个算子的快捷入口当作通用指标架构；它与“添加结果”和三种公式编辑方式重复，还使用户误以为每个结果必须各写一条公式。本次统一标量和时序的操作层级，不新增第三种用户可见结果类型，不改变数学口径，也不接入尚未完成的研究参数中心。

## 用户界面

页面按“指标定义 → 输出结果 → 计算逻辑 → 校验与预览”组织，快照加速保持折叠。输出结果是与计算逻辑并列的区块，不再包在“指标公式”内。

标量与时序都通过结果标签选择当前输出、设置名称/单位/精度；标量另外设置评分方向，时序保留量纲与时间轴契约。只有一个标量时仍按原单值契约保存，不因调整显示格式而变为多结果指标。添加第二个结果才启用具名结果组；删除至一个结果时不隐式改变已保存身份。

最大回撤等多输出算子从原有“变量 / 算子 / 已有指标”构建资源选择，与普通算子同入口。用户配置一次输入、应用一次，服务器返回的具名端口自动成为结果标签。去掉常驻的专用算法选择框、“使用此计算”按钮和覆盖整套公式的快捷通道。

已绑定同一算子的结果：输出区显示来源与可补充的输出；编辑输入使用同一个构建向导，修改一次更新所有已有绑定，保留名称、顺序、稳定编码及未选择的状态。需要额外派生结果时可添加自定义结果，再使用普通公式或画布。高级公式仍允许单独修改端口表达式，校验以服务器为准，不静默重写其他结果。

窄屏纵向排列；标签支持左右键/Home/End；编辑器有未应用改动时禁用结果设置，避免覆盖画布。修改逻辑后清空预览和编译令牌；异步构建回包不得覆盖已切换的草稿。

## 后端契约

复用 /api/custom-indicators/compose 与 /infer，不新增最大回撤专用路由。类型推断结果为 record 时，返回 output_ports：每项有稳定 port_id、结果名、类型、单位、精度、评分方向及投影表达式/可编辑LaTeX。端口只能来自当前注册算子的静态类型契约，由后端生成；前端不编造位置索引，也不执行用户公式。

保存/校验继续使用现有 scalar_outputs 和命名端口 DSL。具名字段只投影同一个共享DAG节点；正式计算继续复用固定签名NJIT，禁止用三个/四个独立回归或扫描实现冒充多输出。

## 验收

1. 普通单标量和时序不再显示额外“多结果计算”算法卡片。
2. 输出配置与计算逻辑区块互为并列，单/多结果展示清晰。
3. 空白草稿通过常规算子向导创建四结果回撤指标；只配置一次输入。
4. 同一次计算的输入可在向导修改；既有输出ID、名称、排序和删选状态保持。
5. 保存后重载、画布往返、公式投影、单结果评分、Excel继续正确。
6. 新旧公式和参数化时序回归；移动/平板/桌面浏览器；中英文文案。
