# 连续实时市场状态

## 需求与边界

用户要求牛熊状态完整覆盖研究序列，中间不能因低置信或等待确认而断档。状态判断、证据强弱、交易使用资格分开。此次修改针对这套实时研究方案，不改写原保存版本和事后参考。

新增领域算子 `state.continuous`，只负责状态保持和新候选确认。上游仍独立计算趋势、门槛、条件与候选，置信校准仍由可靠性模块负责。完整算法由真实可编辑节点组成，不封装成一个新的牛熊黑盒。

## 类型与递推

- 输入 `candidate: state_codes<int64>`：合法状态码或−1。−1在此端口明确表示没有新切换候选，不代表缺少市场数据。
- 输入 `initial: state_codes<int64>`：首个观测的因果初始判断。首点必须为合法状态；之后不用于重新初始化。
- 输入 `value: series<float64>`：原始价格，必须同轴、有限且大于0。非法价格使计算明确失败，不静默填充一个市场状态。
- 参数 `confirmation`：1…252，默认1。已有上游连续确认的候选无需再次等待，使用1。

首点以 `initial[0]` 初始化活动状态。没有新候选时，清除待切换计数并延续活动状态；候选等于活动状态则确认当期方向；候选相反时积累连续次数。达到门槛的当期切换，不回填前面的等待期。计数未达标仍输出活动状态。

输出 `state` 每个有效观测恰有一个合法状态。辅助 `evidence` 编码：0为初始化估计、1为候选成立、2为延续已有状态、3为新方向待确认；`pending_count`为连续等待数。三者共享一次状态递推，并非独立风险指标或预测概率。无新候选的状态可能长期延续，证据字段应表达这种事实。

耦合内核保留原因：活动状态、候选身份和连续计数共同决定输出；普通无反馈连接不能等价表达递推。状态边界是本次有序输入序列；单次扫描自然结束，无收敛或无限循环。时间O(T)，工作状态O(1)，输出O(T)。

## 当前牛熊方案

主方向由价格相对252观测长期趋势决定：偏离≥0为牛候选，偏离<0为熊候选；新方向连续3期后切换。原波动自适应较高门槛与42观测短期预警保留为辅助证据及可预览强信号，不能否决或清空主状态。最终连续算子只在未完成新方向确认时延续旧状态。这样避免主状态长期等待稀疏强信号。

为使历史首日也有完整分类，新增同版本沪深300前收盘序列，与收盘显式对齐。首日收盘≥前收盘初始化牛市，首日下降初始化熊市。持平取牛是明确的平局约定；首日涨跌只是建模初值，不宣称能凭一个日收益高置信地判断完整牛熊周期。初值影响在运行证据中显示，不能借后面的成熟候选回填起点。

原定义的置信校准不沿用。全部有效日期必须重新评价，不能继续只统计原来输出高置信信号的日期。2021年后仍是已看过的复核样本，不恢复为独立测试。完整分类不会自动提高精确率或获得前瞻资格。

## 执行、缺失、时点与兼容

`condition_numba.py` 中唯一固定签名NJIT实现通过现有 `CONDITION_KERNELS` 进入Regime注册、预热、计划和执行审计。内核输入使用readonly任意步长视图，不复制状态/价格数组；分配三个独占输出。新增前收盘源通过既有显式对齐边界与收盘统一轴，对齐层必要的索引和输出分配不宣称为全链路零拷贝。无Python数值回退、新请求签名编译或新依赖。

候选和初始状态保持名义类型，不能直接接数值、条件或phase编码。参数、数组长度、合法编码和原始价格都校验。显式初值缺失时失败，禁止从未来寻找初值。可得时点取所有输入的逐期最大值后再做前缀最大，状态保持不能把已使用的晚到信息改成早可得。所有上游事后依赖继续向下游传播，增加状态保持不能绕过实时门禁。

原 `post.confirmation`、`model.hysteresis` 等算子不改变行为，新算子不是它们的替换副本：它明确满足“无新候选时连续保持、显式初始化、缺失数据报错”的新独立契约。旧定义、运行和报告不改写，新模型另存修订并重新运行。

## 验收

单测覆盖无候选、首次初始化、确认计数重置、新方向当期切换、前缀一致性与未来扰动、空序列、非法价格/状态/数组/参数、只读非连续输入、签名不增长。服务测试覆盖目录、公式往返、实际预览和NJIT调用、状态可得时点传播、结构化数据错误，以及事后祖先在读取数据前被拦截。真实沪深300运行需确认观察日期完整、全部状态合法且没有分类空洞，报告按全部日期重新计算。

### 规则与选型

复用现有10个可编辑节点：沪深300收盘/前收盘来源、严格日期对齐、126观测单向 Super Smoother、价格相对趋势偏离、条件比较、状态选择、初始化及连续确认。收盘价在趋势线上方或相等为牛候选，下方为熊候选；相反方向连续3个交易日成立后当日切换，等待时延续旧状态。最初125个趋势预热观测保持首日涨跌初值并标记初始化证据，不能解释为已确认牛熊。每日收盘数据生成的判断不得当作当日收盘前已可交易的信号。

原参考的双向零相位滤波需要后续数据，不能直接作为实时滤波。[SciPy 方法说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.filtfilt.html)明确其前后两个方向；新模型复用项目单向递推实现，方法背景见 [Ehlers 原文](https://c.mql5.com/forextsd/forum/122/predictiveindicators.pdf)。单向平滑减少噪声仍会产生转折延迟，不能宣称无延迟复现事后峰谷。
