## 接口

| 接口 | 当前行为 |
| --- | --- |
| `GET /api/historical-regimes/preview-runs/{id}/overview` | 新增。读取已完成试算的冻结定义和完整最终序列，返回总览，不重新运行 DAG。 |
| `GET /api/historical-regimes/preview-runs/{id}/series` | 复用分页接口，`offset ≥ 0`，`1 ≤ limit ≤ 5000`；最终输出不传 `node_id`。 |
| `GET /api/historical-regimes/runs/{id}` | V2 正式结果详情新增同形 `overview`；`series` 仍随已有详情返回完整序列。 |

总览只适用于完成任务。未完成、失败或取消任务返回 409；任务过期或最终结果不可用返回 404。

总览字段分为：

- **身份**：`run_kind`、`run_id`、定义 ID、`revision/definition_revision`、定义和图哈希、`mode`、`as_of`、数据快照、创建时间。
- **冻结展示**：状态 ID、名称、颜色、排序和角色。草稿排队时深复制，返回的总览亦与内部缓存隔离。
- **完整区间**：`segments` 与 `unknown_intervals`，含真实起止日期、全局 `start_index/end_index`、样本数和首点可确认的证据。
- **全样本统计**：总样本、已分类、未知、各状态样本数和相邻已分类状态的切换次数。未知区间两边不计作直接切换。
- **走势引用**：`primary_series` 明确使用最终序列的 `value` 和 `observation_date`；试算从分页响应 `items` 读取，正式结果从详情 `series` 读取。
- **评估信息**：仅转交当前运行已有的 `evaluation_results`。试算目前只有评估对象元数据，正式结果才包含既有条件表现统计。

正式结果的总览在读取时生成，不写回旧结果文件，不改变原保存内容或哈希。

## 日期与数值口径

1. 所有色带目前都是 **观测日期口径**（`time_basis=observation`）。事后模式仍需标明“事后解释”。
2. 区间使用 **0 基全局行索引，起止双闭**。单日区间允许 `start_index=end_index`；前端须按交易序列单元绘制，不能用同一天的两个相同像素端点。
3. 未分类保留独立区间，不冒充震荡。无法区分预热、缺失和规则未命中时，原因明确为未知。
4. `confirmed_at` 来自原序列的 `recognized_at`；`effective_start` 来自 `effective_date`。这两个字段不足以构成完整生效时间轴。
5. `capabilities.effective.available=false`。前端不能自行平移色带或将观测区间当成可交易状态。
6. 最终轴的频率或日历无法从冻结元数据可靠确定时返回空值，不用源频率推测经过重采样后的频率。
7. 未显式声明概率或置信度输出时，其可用性为 false。默认确定性状态编码不包装成模型概率。
8. 分段与统计进入固定 `int64`、连续内存的 NJIT 内核；模块导入时编译固定签名并关闭新签名编译，服务初始化检查并预热。请求期间无 Python 数值回退。

## 前端使用与维护

1. 在目录选择“从模板开始”，通过引导配置数据、规则和输出状态；需要自定义结构时切换“自由画板”。两种编辑方式操作同一份计算图，保留参数、连线和高级配置。
2. 画板独占构建主体。添加节点、节点参数、输出状态、复用资源和版本发布通过按需抽屉打开；抽屉不改变画板宽度。支持专注模式、缩放适配和键盘关闭。
3. 运行完成后进入“结果”，展示完整最终走势、冻结颜色的状态色带、全样本摘要和区间证据。节点调试单独按需打开，只表示所选运行的局部序列。
4. 修改计算参数、识别模式、数据绑定或截至日会提示原试算与当前配置不同；修改名称和颜色只提示展示差异。历史结果始终保留本次运行的冻结定义。
5. “实验对比”复用既有验证与批量实验能力；“版本与发布”保留保存、正式运行和发布流程，并可打开正式运行的冻结结果。

前端职责边界：`HistoricalRegimeWorkbench.tsx` 负责视图和草稿/运行状态；`regime-workbench/` 下的引导编辑器、抽屉、结果适配器、图表和证据面板分别负责交互与展示；`regimeGraph.ts` 负责接口与执行审计。正式使用资格按 V1/V2 对应门槛校验，TAA 和研究回测共用资格适配，避免只认旧版门槛。
