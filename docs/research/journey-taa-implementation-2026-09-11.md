# TAA 连续研究体验优化

对应体验审计 J16–J25，并承接 J02/J07/J09。这里记录本次 TAA 前端工作及真实体验发现的趋势时点修正；真实服务、全链路及手机浏览器验收由主任务统一记录。

## 页面设计

用户先确认“本次在研究什么”，再进入四项工作：观点与规则、回测与选优、情景模拟、版本与审计。四项入口移到权重表之前，手机排列为两行；已选长期组合收为一行，可展开更换或返回同一 SAA。

顶部摘要区分 SAA 方案日期、行情截至、研究日与知识截止，直接显示训练区间、独立验证区间和单边成本。计算之前就显示数据数量级检查与训练标签可得资格。继承的是权重、资产和约束；TAA 按本页日期、日频再平衡和费用重新计算，原 SAA 历史曲线不直接沿用。

观点页有明确的下一步。计算后显示 SAA 与拟议权重，并可展开每项信号值、信号日、方向、原始偏离与约束后的偏离。无合格状态版本时说明需要实时验证和发布，并保留当前 TAA 返回上下文。

## 功能与边界

| 项目 | 已实现行为 |
| --- | --- |
| 条件预检 | 200ms 防抖请求服务端 `/preflight`；未完成、失败或门禁未满足时关闭计算，失败可重试。过时响应不能回填 |
| 训练时点 | 显示不可得与未知数量、最早可得日。用户明确点击“采用建议日期”或“改为固定假设比较”；不会自动关闭搜索或绕过 PIT |
| 平台 PIT 切换 | 通过 `useResearchDay` 读取平台截止。旧草稿日期冲突时保留输入、阻止计算/保存/交接；有共同覆盖才提供显式日期修正。历史保存版本仍可只读查看，不能标成当前口径结果 |
| 数量级异常 | 显示资产、日期和原因，返回当前大类处理。这里只检查数量级断点，不宣称全部数据质量合格 |
| 草稿 | 按基准 ID 保存输入、页面位置、名称、结论与情景定义；浏览器不保存业绩结果。返回草稿需重新计算，已保存版本从服务端恢复 |
| 情景 | 最多 12 个具名实验；不同名称并列比较，同名动作明确为重新计算。输入在界面用百分比，API 使用小数；收益差和贡献差统一为百分点 |
| 历史区间 | 默认来自已计算覆盖且不晚于研究日。失效草稿日期会禁用计算，并可一键使用当前范围 |
| 情景留存 | 完成实验随保存请求提交定义，由后端重算、冻结。改变研究条件后保留定义、清除旧结果并标为待重算；不将旧实验冒充当前证据 |
| 结论保存 | 单独填写采纳/不采纳理由和复核计划；保存期间继续编辑时，旧响应只进入历史列表，不覆盖新草稿 |
| 版本保护 | 编辑保存版本生成新草稿，原不可变版本保留；旧版本缺少情景字段时按空集读取 |
| 交接 | 服务端生成产品映射；URL 携带 universe 和 decision。返回 SAA 保留 allocation 与 universe，过期、质量问题和验证超限仍阻止应用 |
| 展示 | 重要入口前置；PIT 重复说明在审计组内去重；风险模型作为进阶内容展开；表格局部滚动，移动端使用卡片 |

## 后续观察

当前浏览器草稿按基准分隔，不是多人协作系统；本地缓存只便利恢复，不提供研究证据。固定假设比较仍属于研究，不代表正式 PIT 或未来可投资性；趋势窗口的未知可得信息不产生有效信号。数据修复必须由来源核验确定，界面不自动猜测复权倍数。


## 真实体验发现的趋势窗口问题与修正

真实全链路发现：60期趋势的训练候选得分全部为0，原因是原算法总取紧贴当期的窗口，最新净值T+1公布便使整期停信号。已改为版本 `available-window-relative-momentum/2.0.0`：每期使用最近完整且全部已公布的连续窗口，并按既有有效期判断能否继续使用，不改变源数据公布日期。算法、边界和性能详见 [数值契约](taa-numeric-contract.md)。

页面增加训练/验证实际有效信号期数；没有训练信号时关闭搜索，固定比较必须用户明确选择。当前信号可展开查看观察起止、最晚公布与滞后天数。旧冻结结果不会采用新预检的计数冒充历史证据。TAA决策日期只改变TAA输入，不再反向覆盖上游范围研究日。

同份数据复核：训练有效信号0→1411/1472，验证66→731/731，来源哈希完全不变。非零偏离在训练/验证均弱于SAA，仍选SAA；现在是有效比较后的结果，而不是无信号时的零分并列。后端91项定向回归通过；真实浏览器最终由主任务统一验收，子任务未重启服务或修改正式数据。


最终定向验证：TAA前端 **24项通过（7.25s）**，包含零信号显式固定比较、旧冻结计数隔离、TAA日期不覆盖范围研究日；`npx tsc --noEmit` 与改动文件 `git diff --check` 通过。后端完整TAA定向 **91项通过**，补充启动实际走已知窗口后的 numeric **36项通过（24.22s）**。独立审核另以800组数据、40,438个时点、194次未来/不可得单元扰动对照穷举参考全部通过；12组长期未知前缀压力未出现伪信号。此处不替代主任务最终全套与真实浏览器结果。

## 初始 PIT 日期读取竞态

初始读取平台 PIT 时，页面尚无 request/decision，不再执行草稿失效或递增版本号。否则 pending 保存版本响应会被当成过时请求丢弃，而且不会自动重新发起。基准输入创建仍取 `platformRef` 的当前日期；历史版本加载后由既有日期冲突规则保持只读并禁止交接。已有输入后的真正 PIT 切换继续使预览失效、保留草稿。

新增延迟 decision 响应期间 null→2014-12-31 的 PIT 读取测试，以及已计算研究期间真实切换测试；TAA 前端 **26项通过（8.02s）**，完整 TypeScript 与 diff 检查通过。此次仅修改前端 effect 与测试，未动后端或重启服务。
