# 投资目标与约束

本页负责资金事实、成功标准、风险授权、诊断及版本治理。用户先选择适用的[风险标尺](risk-scale.md)，再确认目标；正式 CMA 在后续 SAA 选择。

Reference CMA 在本主题指风险标尺冻结的历史参考矩，不是让 Mandate 依赖一个 LTCMA 预测版本。参考诊断不能替代实际资产范围下的正式 SAA 验证。
## 核心业务契约

### 风险标尺

- 用户选择已发布 RiskScaleVersion。
- PIT 开启时，目标研究日自动跟随当前 PIT，页面不可修改；只列出该研究日可用的 RiskScaleVersion。
- PIT 切换、恢复旧草稿、编辑旧版本或手动修改研究日时，不自动改写现金预算的余额日期。本金、储备及现金流保留原基准；用户核对并明确确认按新研究日使用后，才更新预算日期并按新基准解释现金流月份。确认前禁止诊断和保存。
- PIT 关闭时，用户可以手动选择目标研究日，再按该日期列出可用版本。
- RiskScaleVersion 的 C1–C5 永久冻结；本页重新计算有效前沿时不得重新分档。
- RiskScale 的 base currency 自动成为本目标计价币种，只读展示，不要求用户再次输入。

### 两条有效前沿

前端同时展示：

- Reference Frontier：RiskScaleVersion 原始参考有效前沿；
- Constrained Frontier：相同 Reference CMA + 本次现金约束重新求解得到的有效前沿。

C1–C5 仍使用 Reference Frontier 发布时冻结的波动率边界解释两条前沿。

### 投资目标

保留三种目标类型，但不再单独设置“成功标准”步骤：

- absolute_return：用户输入最低预期年收益；
- funding_goal：用户输入期末目标金额，可同时维护期间投入/支付；
- benchmark_relative：基准自动采用所选 RiskScale 风险等级的代表组合，默认填写目标年超额收益；也可记录合同基准原文，或在同一冻结资产轴上显式设置基准权重。合同原文只留痕，不参与数值计算。

正式 CMA 不在本页选择；历史 `cma_id` 请求继续兼容，但新 UI 不再暴露。

### 现金约束

用户只面对：

- 最低组合内现金占比；
- 可选现金流计划：总资金、期间投入/支付及其频率；
- funding_goal 时的期末目标。

通胀、额外费用、随机种子、路径数、不确定性惩罚、流动性窗口、投入压力比例、概率门槛不作为普通用户输入。现有数值模型仍复用，固定模型约定被冻结到预览/保存结果中，不能在运行时静默变化。

## 前端设计

### 主页面：投资目标与约束列表

参考风险等级配置中心，`/pre-investment/objectives` 首先展示当前可用的已发布目标列表，而不是直接进入编辑器。列表展示名称、目标类型/目标值、研究日、风险等级、现金底线、发布时间及操作，并提供：

- **添加**：进入新的两步编辑器；
- **查看**：点击名称进入 `?view=<id>`，显示保存时的冻结诊断和只读输入；后续投资范围链接明确携带正在查看的目标 ID，不继承其他目标的浏览器旅程。
- **修改**：读取所选已发布版本形成可编辑副本，重新诊断并保存为新的不可变版本；新版本通过 `supersedes_mandate_id` 替代原版本进入可用列表，原版本不原地修改；
- **删除**：写入独立 retirement 审计记录，将版本移出可用列表，不物理删除历史成果；
- 已被新版本替代或删除的版本仍可按 ID 读取，保证历史 SAA/审计引用不失效；删除后不得自动恢复更早的被替代版本。

修改或恢复绝对/相对目标时，现金预算中的显式支付保护、期末底线及名义/实际金额口径一并保留，不得因精简表单而清空 `cash_protection`。已删除或被替代的目标不能再预览或发布新 SAA 政策；发布在写入前使用与目标生命周期相同的锁复核可用状态，既有历史目标和政策继续可读。

编辑工作台收敛为两步：第一步按研究信息、风险标尺、风险与现金、投资目标顺序填写，第二步诊断并确认。

2. 读取用户选择的 C1–C5；

### 现金模型约定

复用现有 `goal_kernels.py`，不复制现金流递推。普通 UI 不暴露模型参数；后端将当前模型约定冻结到解析后的 definition/assessment 中：

- 现金保障窗口：默认 12 个月，但不超过投资期限；
- 压力下认可投入比例：50%；
- funding 概率门槛：80%；
- 通胀与额外模型费用：新 UI 默认 0；
- 搜索/验证路径数与种子沿用固定默认并保存在 planning_settings。

这些是模型约定，不冒充用户风险偏好；结果页高级证据可查看。

### 约束有效前沿

复用 `frontier_moments.solve_frontier`：

1. 从 RiskScale frozen context 读取同一 `mu`、`covariance`、标准权重约束；
2. 计算现金流推导的 `funding_floor`；
3. `effective_cash_floor = max(min_cash_weight, funding_floor)`；
4. 把现金角色大类增加为 `weight >= effective_cash_floor`；
5. 重新求解有效前沿；
6. 仍用 RiskScale `applied_boundaries` 对结果解释 C1–C5。

不通过过滤原 Reference Frontier 伪装重新优化。

ReferenceDiagnosis 增加：

- `reference_frontier`；
- `constrained_frontier`；
- `risk_boundaries`；
- `cash_constraint`。

### 正式 CMA 边界

`MandateStudyRequest.cma_id` 保留兼容，但新 UI 固定为 null。Investment Objectives 只消费 RiskScale 的 Reference CMA。正式 CMA 由后续 CMA 模块产出，并在 SAA 时重新验证 Mandate。

### 已发布目标的修改与删除

不提供原地 UPDATE，也不物理删除冻结研究成果：

- `ConfirmMandateRequest.replaces_mandate_id`：修改已发布目标时指向当前活跃版本；服务端确认其仍为活跃版本后保存新 MandateVersion，并冻结 `supersedes_mandate_id`；
- `DELETE /api/strategic-allocation/mandates/{id}`：创建 `investment_mandate_retirement` 审计成果，接口保持幂等；
- `catalog()` 仅返回未被 supersede、未 retired 的目标；
- `get_mandate(id)` 继续允许读取历史版本，因此既有下游研究引用不会因主列表删除而损坏；
- 如果替代版本随后被删除，不恢复更早的 superseded 版本，避免“删除新版本导致旧政策意外重新生效”。

## 统一解析与版本

原始请求保存在assessment.request；后端解析后的definition保留实际cap及政策快照，供现有SAA/TAA冻结消费者使用。新的有效值不得覆盖原始输入和来源。

只有preview→confirm创建目标；confirm重算并匹配preview_hash。默认标尺变化不改变已绑定版本；历史读取显示原结果，不重新拟合。参考ID、hash、资产轴、币种、风险口径、预测期限、可得日、退休/过期状态分别核验。

已保存目标的 `?view=<id>` 页面在 PIT 初始化、日期切换、关闭或读取失败后，继续保留原始研究日、冻结标尺引用和诊断，只读状态不变。时钟变化只作废可编辑草稿的旧诊断与引用，不把历史查看转换为新建或修改。

上述保留仅展示成功读取的保存版本。版本读取失败时，查看和修改入口仅显示错误、返回列表和重试，不暴露本地草稿或诊断/保存操作；PIT 恢复不解除该限制。重试成功后，查看恢复冻结只读版本，修改才进入对应版本的可编辑副本。

目标诊断对全局参考使用其冻结CMA；实际CMA诊断仍保留。基准或资产授权不能合法映射到Universal时返回awaiting_actual_scope，不按同名资产猜测。

退休/过期影响新引用和当前使用，历史只读仍可用。参考历史PIT尚未证明时继续标注，不因目标页接入就升级为正式PIT证明。

## 资金与现金保障

可投资本金W0=总资本−组合外储备，组合外储备只扣一次。模型月末：收益与费用→投入→必要支付；一次未支付即永久记录失败，不用后续投入抹掉，也不允许隐含负余额融资。

复用有界二分求required_effective_return；它不是CMA算术均值。实值预算和终值分别按其口径转换，名义目标不能重复通胀。

现金需要：L_need=max(0,max_t Σ(O_i−eta C_i))，t限制在已确认保障窗口；funding_floor=L_need/W0。大于1明确报资金冲突，不裁成100%。

新版分别执行：
- 可交易流动资产权重≥政策流动性底线；
- 有明确现金角色的可流动资产权重≥max(政策现金底线,资金推导底线)。

两组可能重合，不双重扣减本金。旧请求继续其原有liquid语义，新版将现金保护落实到现金组。非流动性上限与TAA上限仍是明确授权，不用“1−流动性”或“剩余波动”冒充完整风险能力计算。

## 分布适配与唯一数值实现

当前funding_paths_kernel以一年简单收益矩匹配对数正态。将其口径转换提取为适配器，月度资金递推保持唯一。

适配A annual_moment_proxy_approximation：v=log(1+sigma²/(1+mu)²)，drift=(log(1+mu)−v/2+log(1−fee))/12，scale=sqrt(v/12)。旧结果含义保持不变。

适配B base_period_moment_match_v2：先取有明确频率的基础期m,c；v=log(1+c/(1+m)²)，月漂移=a*(log(1+m)−v/2)/12+log(1−fee)/12，月方差=a*v/12。没有基础期或明确年化关系时不得声称精确还原，只能明确选择适配A。

两者共用资金支付、财富、成功事件、Wilson和资本补足实现。mean<=−1、非法方差、非有限数及指数溢出失败关闭，不能裁剪。年化算术参数不直接称CAGR。

## 参考搜索与独立验证

1. 解析RiskScaleVersion的参考矩、资产轴和标准约束。
2. 加上本目标现金/资产约束，复用前沿求解器生成约束后的参考前沿。不能只过滤原前沿后就宣称新约束无解。
3. 按显式候选及稳定ID保留搜索集合，非只取五个代表组合。有限搜索与数值失败都如实记录。
4. 使用NJIT批量计算候选矩与约束，搜索随机数在候选间共享。
5. 资金成功为全部必要支付完成且期末条件满足。沿用Wilson双侧95%区间下界作为单候选门槛，采样区间不覆盖模型错误。
6. 搜索中按风险升序、成功率、期末缺口、稳定ID选择；冻结候选后才用独立validation_seed验证。
7. 验证失败不能拿同一验证集再选第二名。返回validation_failed，不伪造独立确认。
8. 验证通过后映射C1–C5；不把minimum_tested_feasible_level添加成最低波动约束。

保存已测试结果、冻结候选、独立验证、两个seed、路径数、适配器、版本/hash和限制。提高授权上限时保留低风险候选，不能出现更宽松授权反而把原候选排除。

无参考、需实际范围、当前搜索未找到、独立验证失败、数值失败、明确约束冲突分别返回状态；保存研究输入不等于采纳资格。

绝对目标保留同口径预期收益检查；相对目标保留明确基准与TE。不能映射全局参考则保留实际CMA路径，不假装已实现主动前沿全局最优。

## 调整情景

优先复用追加本金：固定候选/路径下求资本秩，向上取到分，再正向回灌。显示金额必须真正通过对应统计门槛。改变资金可能改变流动性约束，应用调整只生成新草稿并重新诊断，不自动修改已确认目标。

降低终值等现有敏感性保留并标清口径。若搜索未找到通过候选，但仍存在满足硬约束的候选，按“搜索成功率较高 → 风险较低 → 稳定ID”冻结一个仅供资本诊断的候选，用独立样本测算追加本金并回灌核验。返回`adjustment_diagnosis`，明确不是配置推荐；原`selected_candidate`、最低已验证等级及自动风险上限仍为空，不因追加本金测算可用就把原目标标为通过。没有合法候选则不编造调整金额。

全自动多变量调整、任意小数期限和假设期限单调的二分不属于本次承诺。
## 量化语义

### 资金与现金流

可投资本金 = 总资金 − 组合外储备；储备不参与收益模拟，也不再次扣除。流动性底线是组合内需保留的预算，仍属于可投资本金。

现金流按月末：本月市场收益及按月费用 → 本月投入 → 本月支付；不足支付即记录违约，后续有新投入也不抹除失败历史。金额以名义值或研究日购买力输入，后者按明确通胀路径转为各月名义金额。费用使用年有效财富扣减比例，月系数`(1-fee)^(1/12)`。支出含税可以输入，但模型不计算税法。

固定收益所需回报使用有界二分，满足所有支付和期末金额；输出为固定年度有效收益率，明确不是CMA均值、不是IRR多根问题。找不到根返回边界/状态，不静默补值。

流动性储备按声明窗口内压力投入折扣后的最大累计净支出计算，与用户下限取更严。资产liquid标签只约束预算，不认证实际变现/结算能力。

### 前瞻诊断

复用`policy_candidates_kernel`和`portfolio_moments_kernel`，先执行授权范围、均值/波动、相对基准主动风险等约束；对生成的四类代表组合诊断。未找到合格代表不证明数学上无解，也不声称最大化了全局成功概率。

金额诊断采用“年度简单收益矩匹配的月度独立对数正态组合代理”作透明基线：

`s² = log(1 + sigma²/(1+mu)²)`；`m = log(1+mu) − s²/2`；月度增长`exp(m/12 + sqrt(s²/12)*z)`。

因此一年无费用复合的简单收益均值/标准差匹配输入mu/sigma。它不是日收益乘252的再次年化，也不是直接把算术均值当对数漂移；它不模拟各资产逐期权重漂移、厚尾和状态转换。共用已有固定签名随机抽样与分位数内核，四个候选和压力条件共享随机数降低比较噪声。

成功 = 每笔必要支付均足额且期末余额达到目标；同时显示Wilson 95%二项区间，仅表示模拟采样误差，不覆盖模型误差。采用门槛使用该区间下界，不能仅靠点估计刚好达标宣称通过。保守条件用明确的CMA均值不确定性折扣和投入折扣，单独展示，不给该情景捏造发生概率。

给定同一组合/同一模拟路径，可以精确反推支付与终值所需初始资本：以增长累计因子P_t和现金流的路径现值计算各时点资金下界，取最大值；其目标概率分位数给出所需本金及缺口。此项不是融资建议，不能在内部自动增加本金、降低目标或放宽风险。

市场回撤按不受外部投入/提款影响的单位化增长计算；资金不足按实际现金余额计算，两者分开。

### 相对目标

明确基准大类权重b；预期超额`(w-b)·mu`，主动风险`sqrt((w-b)'Σ(w-b))`。这与TAA相对SAA的风险预算是两个不同基准。相对约束在候选筛选与采纳/TAA政策门禁共用，不凭同名基准猜测序列或币种。
