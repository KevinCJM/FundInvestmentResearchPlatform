# 自定义标量指标：多结果设计与实施

## 用户操作

保留“标量指标 / 时序指标”两个入口。标量默认仍是一条公式；点击“添加结果”后，按名称切换各结果，独立编辑公式、数字/百分比、小数位和评分方向。新结果默认“仅展示”。复制生成新 ID；改名、排序不改 ID；最后一个结果不可删除；已保存多结果不隐式退回单值。

校验、预览、保存均作用于整个指标。错误带结果名称，可定位当前结果。向导、高级公式、画布共用草稿；未应用画布不能被静默丢弃。画布通过多个命名输出绑定实际计算节点，不增设空的“最终结果”计算节点。

## 契约

内部新增 `result_kind=scalar_bundle`、`output_contract=scalar_bundle`、`output_schema_version=1`、`scalar_outputs`（1—8 项）。每项包含稳定 `id`、`label`、`expression`、`description`、`display_format`、`precision`、`unit`、`direction`；编译器锁定量纲与依赖。整个组没有默认评分值，不取第一项充当组结果。

引用为 `indicator_id + indicator_revision + output_id + period`。旧单标量继续按原接口和历史版本执行；多结果用于评分或公式输入必须显式指定 output_id。输出名称、翻译、排序不是身份。

响应逐结果包含 value/null、status、warnings、实际窗口及锁定 presentation。组结果可部分可用。未选中的兄弟结果失败，不影响选中结果的评分资格。缺失不填零。

## 计算

多个受限公式合并为共享 DAG，每个根必须是数值标量。相同上下文、算子版本、类型和参数的节点复用；节点级错误只向依赖它的结果传播。整体图受节点数、深度、内存和计算预算约束。

使用固定签名 NJIT，显式校验/保存/启动预热；正式运行只取已预热计划，不临时编译、不回退 Python。输入读取与数据窗口复用现有提供器，不伪造数据。数值输出数组、整数状态数组按不可变输出顺序映射回命名结果。

缓存锁定整个定义、所有输出、版本、数据代际和窗口；选择部分结果只投影结果，不临时构建未预热子计划。组合域继续使用不可变研究快照。

## 下游

详情按父指标分组展示，比较按子结果分行，产品研究按子结果分列。评分和公式构建只选择具体结果，neutral 不自动标最佳/最弱。快照指定 output_id，不借用时序 last_finite 归约。产品池复用评价证据，不新增评分算法。单标量、时序和历史方案不原地迁移。

新增系统操作文案使用系统 i18n，用户名称保留原文。所有操作支持键盘，窄屏结果栏可换行。

## 验收

定义/安全/类型检查；1—8 输出；改名与顺序稳定；旧版本回放；部分缺失；数值参考一致；共享节点；运行无新签名；评价独立权重；公式/画布往返；页面格式一致；旧单标量/时序回归；构建及浏览器操作。

## API 与生命周期

- `/validate` 对全部输出返回结果级 `output_inferences`、命名 roots、执行审计和当前进程的 `compile_token`。
- 创建/更新仍走原 CRUD。内部 `expression` 不代表默认输出，多结果以 `scalar_outputs` 为真相；读取时可提供独立的可逆 LaTeX。
- `/evaluate` 支持整组 `indicator_ids` 或具体 `indicator_refs`。同一请求不得混用来源；结果引用为结构化字段，不把中文标签作为主键。
- 内联预览和导出必须携带与当前草稿完全匹配的校验令牌。保存后源码或元数据可能改变，前端清除旧校验，后续操作重新校验，不能复用旧令牌。
- 评价方案、快照与滚动派生保存具体 `output_id` 和指标 revision。遗漏输出选择时明确报错，不回退第一项。
- 退役输出编码不在同一指标后续版本中复用。旧版本仍保持可回放；新版本改变显示顺序不改变既有引用。

## 人机交互细节

点击“添加结果”保留原公式，自动生成新编码，新结果公式为空并聚焦名称。标签可通过方向键、Home、End 切换。复制沿用公式但创建新身份；删除最后一项被禁止。八项上限同时在前后端校验。

每次仅编辑一个结果的公式与格式；编辑其他结果不会清空当前草稿。结果编码默认折叠为只读技术信息。组级保存一次产生统一版本，不让用户分别保存八个结果。

画布结果绑定只是对实际节点的输出声明，不在数值 DAG 中制造空算子。共享步骤可供多个结果引用。未应用画布期间禁止用旧公式保存或预览；不同编辑方式复用同一个定义。

## 结果状态与窗口

每个输出独立携带数值、警告、展示协议和实际样本窗口。若所有窗口一致，组标记 `window_scope=common`；否则标记 `per_output`，组级不假装使用第一项窗口。界面在每项中显示真实区间。

同依赖组只加载一次并共享节点；不同物理依赖组保持各自严格样本，不把行情缺失传播到只依赖净值的结果。运行期间数据代际变化则失败关闭。数据缓存统计返回真实命中数。

## 下游具体行为

| 入口 | 行为 |
|---|---|
| 产品详情 | 父指标卡片内分项，定义抽屉逐项显示公式和评分方向 |
| 产品比较 | 一个结果一行；neutral 不自动标注最佳/最弱 |
| 产品研究 | 子结果作为可选择列；网络层转换为结构化引用 |
| 评价方案 | 每项独立周期、方向、权重和版本；缺失检查仅针对已选择项 |
| 组合诊断 | 使用不可变组合快照；未提供基准时只阻止依赖基准的结果 |
| 快照 | 独立输出列及展示元数据；无时序 reducer，保存一个输出时保留同版本其他输出配置 |
| 滚动派生 | 选择具体标量结果，冻结来源 revision、output_id、定义哈希与窗口 |
| Excel | 汇总一行一个产品/输出，每个结果保留自己的输入、窗口、原生公式和 NJIT 对照值 |

## 当前边界

本次提供通用多标量能力，不新增市场归因专用算法或不具备的数据源。原始残差序列仍应定义为时序，不能标记为标量。不同物理依赖组可能分别扫描同一来源文件，尚未承诺所有组全局只扫描一次；也未宣称实测性能提升倍数。

快照结果可按具体输出配置和生成，但整组实时预览仍沿显式预热的计算路径执行，不承诺自动由部分快照拼接整组。Excel 使用原生公式并保留对照值；本次未调用独立 Excel 引擎重算，缓存值不作为独立数值一致性证据。
