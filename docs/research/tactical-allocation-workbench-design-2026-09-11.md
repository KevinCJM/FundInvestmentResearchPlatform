# 战术资产配置工作台：需求、设计与验收

## 用户要完成什么

研究员从一份明确的 SAA 出发，判断是否临时调整大类预算，查看风险与成本后保存可复现的研究决策，并将大类预算带入产品配置。整个页面始终回答：为什么调整、调整多少、何时复核。没有可靠证据时，保留 SAA 是有效结果。

## 页面与交互

1. 顶部选择 SAA 版本，显示来源配置、研究日期和数据覆盖；没有版本时提供去 SAA 的直接入口，并允许明确建立研究基线。
2. 主区为资产表：SAA、拟议权重、相对 SAA 偏离（百分点）、约束；实际持仓需用户显式提供，才能显示交易差额。
3. 决策摘要解释采用的规则、训练选择、留出验证、信号日期、复核日期与阻断原因。只有与当前输入一致的结果才能保存和应用。
4. 页签为“观点与规则、回测与选优、情景模拟、版本与审计”。可读表格和图表为主；高级参数、数据指纹与执行证明折叠呈现，不要求填写 JSON。
5. 输入支持负号、小数、空值编辑；百分比和百分点明确区分；加载、空状态、错误、过期结果均有下一步操作；窄屏表格可水平滚动，按钮与输入带可访问名称。

## SAA 联动与版本

SAA 页面每项策略提供“以此为 SAA，研究战术偏离”。服务端从真实配置读取类别、产品权重、可投资域和数据版本，冻结用户选定的大类比例及逐类限制。新 TAA 请求引用不可变 baseline_id。SAA 后续修改不会改写旧版本；源配置不匹配时要求重新建立版本。

保存决策前，服务器重新计算并核验预览指纹，保存请求、结果、输入指纹和时间证据。预览和情景比较不自动持久化。保存只是研究版本；应用生成产品配置输入，不执行交易。

产品权重 = TAA 大类预算 × 类内产品权重。产品层保留 SAA/TAA 引用和类别预算，不可默默重新等权。缺少可投资域或产品映射时明确阻断应用，保留研究结果。产品替换和择时研究不得无提示改变大类预算；需要改变时回 TAA 重新计算。

## 偏离、选优与回测

支持三种可解释输入：过去窗口相对强弱、人工零和偏离、已发布因果市场状态的逐状态零和规则。前两者与状态概率清楚区分；状态概率不是配置盈利概率。规则、限额、搜索范围在运行前确定。

用户输入都按业务含义展示：长期权重与资产上下限用百分比，战术增减配用百分点，费用用基点，时间用日期或交易期。默认观察窗口 60 期、单类最大偏离 10 个百分点、费用 10 基点、信号有效期 31 天、研究复核期 30 天；这些是可修改的研究起点，不是收益承诺。参考持仓默认不提供，不能拿 SAA 冒充用户持仓。

趋势规则比较此前完整窗口的累计收益：最强资产增配，其余资产分摊减配；并列最强平均分配增配，全部相同保持中性。人工规则逐类填写零和偏离；状态规则逐状态填写零和偏离，并按当期已知概率加权。原始偏离乘以候选强度后，依据逐类权重边界、单类偏离上限及组合分组边界统一收缩；禁止为了满足总和而偷偷改变方向。

对每组规则搜索固定强度 0、0.25、0.5、0.75、1、1.25、1.5。逐类最低/最高权重与最大偏离共同约束，统一收缩保持资金守恒。零偏离永久加入比较。训练目标可选风险调整主动收益、净超额、最小回撤；跟踪误差与换手限额过滤不可行候选。结果称“训练窗口内候选最优”，不声称全局最优或未来最优。

按时间切分训练/验证，各不少于 20 期。只按训练值选择，留出区不能决定自动排名；用户人工改选会被标记。验证使用冻结规则和参数。日频观测、每日目标再平衡；SAA 与 TAA 使用同一资产轴、收益、成本、建仓规则。训练和验证各从同一 SAA 起点独立推进，图表显式区分两个分段，不拼接成未经验证的连续实盘曲线。

净收益、SAA 收益、超额、波动、最大回撤、跟踪误差、换手及成本并排展示。回测目标权重与当前建议分离：当前建议必须使用截至研究时点的最新可得输入，不能把最后一根历史权重误当成今天建议。复核到期或信号失效提示回归 SAA，并生成新研究，不改历史快照。

风险调整主动收益采用年化平均主动收益减去风险惩罚系数乘以主动波动方差；主动风险为相对 SAA 的跟踪误差。净超额采用两者期末净值之比减一。训练不可行候选不可选择；验证超限保留结果并阻断应用，不拿验证区重新挑一名“赢家”。这次实现为单次训练/留出验证与固定强度搜索，尚不包含自动滚动调参或全空间优化。

## PIT 与数据契约

保留观察日、可得时间、决策日、收益期起止与版本创建时间。只使用决策时可得的输入；收益期结束的信号不能作用于自身收益。动量特征使用此前完整窗口，延迟可得数据令该期回归 SAA。缺失时间证据不填造，标记事后研究；当前新建规则/SAA 对过去的回放不能升级为当时已部署的策略证据。

读取真实类别净值，按所有资产共同日期对齐；拒绝重复资产日期、不完整映射、无效净值和不足样本，不前填、不补零、不偷偷重新归一。缺失可得时间与有效时间证据分别呈现。新工作台保留研究模式，不能借新 API 绕过数据发布或历史状态正式门禁。

## 情景模拟

假设冲击：用户按大类填写一期收益冲击，比较 SAA/TAA、贡献和同口径交易成本。历史重演：明确选定真实历史区间，将当前拟议大类权重作为每日固定目标置于该区间比较，说明是假设回放；它不重新训练信号或搜索强度。二者均不编造发生概率，不冒充 VaR 或预测。已发布宏观传导/产品风险模型继续通过现有产品快照压测入口使用，避免从类别名称猜测产品暴露。

情景的“相对改善”是两组合收益的百分点差，与回测的相对净值超额分开标注。逐资产贡献、扣除的交易费用与净收益同表对账。产品配置既有回测是静态目标的毛收益口径，TAA 页面负责动态、扣费的战术回测；交接横幅直接说明二者区别。

## 研究对象与异常处理

| 对象/状态 | 用户操作与系统行为 |
| --- | --- |
| SAA 基准 | 冻结长期权重、类内产品、约束、数据/可投资域指纹；后续源数据变化要求建立新版本 |
| 编辑中的研究 | 修改任何规则或日期立即使旧结果失效；迟到响应不覆盖新输入 |
| 预览 | 只计算，不写入决策库；输入必须与结果一致才可保存 |
| 保存版本 | 服务端重新计算、核对指纹，保存不可变结果和原始数组；不能覆盖历史 |
| 复制研究 | 保留原版本，复制参数后要求重新计算 |
| 到期或信号失效 | 取研究复核日与有效信号到期日中较早者；应用时再次按当天校验 |
| 带入产品配置 | 服务端重新核验版本、实际可投资域、产品归属与大类预算；不能只相信前端标签 |

产品层可在已冻结的产品映射内调整类内比例，但不得改变大类总预算或把产品改贴成其他大类；更换映射回 SAA 建立新基准。缺少映射仍可做研究，应用入口提示缺项。数据为空、日期不合法、样本不足、结果过大、数据指纹变化均返回具体原因，不使用示例业绩填充。保存结果限制在持久化读取预算以内，防止“保存成功但无法重新打开”。

## 数值与颗粒度

基础语义分离为：真实数据/时间对齐、因果信号、零和偏离约束、候选选择、组合推进、指标评价、情景冲击、类别到产品预算合成。组合推进含持仓漂移与成本递推，作为耦合内核保留；不能将整套工作台做成不可展开的单一算子。现有 TAA 推进内核继续唯一；旧 API 是有测试覆盖的兼容入口。

所有新数值路径为固定签名 NJIT，启动预热和 readiness 失败关闭。计算不回退 Python/Pandas；输入边界一次 dtype/布局规范化，窗口和分段以只读视图进入内核。输出与工作缓冲允许分配。验收覆盖数值等价、缺失/非有限值、时点、只读/非连续视图、共享内存及新签名零增长。

## 验收清单

- SAA 一键进入带完整类别预算和产品映射；无版本与失效版本有行动入口。
- 改参数后旧结果立即失效，迟到响应不覆盖新输入；保存由服务端复算校验。
- 零偏离与 SAA 净收益一致；训练选择不受验证未来收益改变影响。
- 约束、负号、空值、偏离不守恒、缺失数据、时间倒置有明确报错。
- 动量仅看过去、延迟数据不提前用、状态发布门禁复用、当期末信号不能影响本期。
- 假设冲击与历史重演贡献可核对；缺类别冲击失败而非默认为零。
- 决策不可变、修改数据不篡改旧快照；应用预算守恒且保留来源。
- 后端定向测试、前端交互测试、构建、浏览器桌面和窄屏验收；另外自审核跨模块约束与错误路径。

## 研究依据
