## 实际链路与边界

`PolicyRequest → multi_cma.resolve → compatibility.calculate → 各模型独立锚点 → 全模型交叉诊断 → compatibility_solver.solve → 原始风险复核 → 全模型候选门禁 → 独立资金验证 → 冻结政策 → cma_application / policy_gate → TAA`。

| 项目 | 已实现行为 |
|---|---|
| 输入 | `mode=compatible_all_models`，1–20 个同轴、同日期、同口径且可引用的 V2 CMA；引用包含 ID/hash，weight 必须为空 |
| 目标 | `minimax_regret` 默认；可选 `maximin_return`。绝对目标用预期收益；基准目标用各模型预期超额收益 |
| 约束 | sum(w)=1、long-only、资产和重叠分组上下限、现金／流动性、逐模型收益下限、波动上限、基准超额与 TE |
| 锚点 | 每个 CMA 单独解最大收益问题，再用全部 CMA 评估同一权重；保存参考收益、可核验上界、状态及交叉检查 |
| 最终配置 | 直接求解共同可行集的一套权重，不平均独立最优权重；每个来源均通过才可采纳 |
| 数值执行 | 唯一共享 active-set 核心；固定签名 LP／Phase-I／支撑切面和真实风险检查，按 worker PID 预热；无 Python 数值回退 |
| 资金 | 各来源年度矩分别进入既有资金代理模拟；仅筛选一个共同候选。确认时各来源使用独立于搜索的冻结随机流；失败不等于全部权重空间无解 |
| 保存 | schema 2 政策冻结全部来源、模式、目标、锚点、最终检查、求解状态／目标界及资金验证；旧政策不重新拟合 |
| 展示矩 | 内部等权矩仅为展示兼容字段，标注 `display_reference_only`；权重和风险门禁从不以其替代原模型 |

## 数值证据与停止规则

历史 `feasible_qp_kernel` 和矩阵 QP 的四项返回 ABI、容差、状态保持不变，均委托唯一 `_active_set_qp_solve`。新增 `bounded_lp_kernel` 取得乘子，对不等式乘子作非负约束，并把残余梯度在已声明有限 box 上的最小值计入下界，再扣除浮点裕量。未收敛的可用下界仍是下界；残差本身不能证明不可行。

Phase-I 使用一个公共非负松弛，最小化所有归一化不等式的最大违反量；硬 simplex/box 保留。相比原草案“松弛和”，零最优值的可行性含义相同，并避免为每个切面新增变量。只有松弛下界大于 1e-8 才标记 `infeasible`。QP 状态失败、未找到初值、迭代／时间／切面预算耗尽分别保留明确状态。

共同模式独立重查归一化线性约束及有限 box，容差 1e-10；不沿用历史 QP 较宽的可行残差。每轮 LP 后用原 covariance 重算真实波动和 TE；满足切面不等于满足风险。目标上下界差≤1e-7 且真实风险残差≤1e-10 才报告 `converged`。矩阵对称及 PSD 校验容差为 1e-10；这是有限精度数值证据，不是符号代数证明。

默认 64 轮（请求上限 128）、每个 LP 500 步、最多 2,048 个切面。锚点与联合问题共享 30 秒轮间检查预算；单次内核不可抢占，不是进程级硬超时。资金路径月预算 `M×(M+2)×paths×months≤50,000,000`，中央／保守最多两倍；冻结 JSON 继续限制为 7 MB，保存前复核。

二资产文档样例的独立锚点约 76.4575%／23.5425%，互相未通过；共同解为 50%／50%，两个模型均为收益 6%、波动约 14.1421%。将收益下限提高至 6.1% 后，Phase-I 正下界约 0.0098058，返回无共同解及空候选。

## 算子和内存边界

- `prepare_problem_kernel` 只负责有限维约束与参数校验；`quadratic_support_kernel` 只计算真实风险及有效切面；`worst_model_summary_kernel` 只作明确的最不利指标摘要，均可独立检验和替换。
- active-set 的活动约束/KKT 状态、Phase-I 可行起点及逐轮切面累积具有耦合求解语义。终止由残差、上下界与有限预算决定，不能拆成无状态普通串行公式后声称等价。来源读取、交叉展示、资金验证和持久化保持外围独立步骤。
- JSON→float64 以及 M×N 均值、M×N×N 协方差堆叠是必要输入边界复制；同一只读输入在全部锚点和共同求解间复用，锚点使用基础切片视图。切面矩阵按上限一次分配，主问题读取其视图。
- 小型迭代点、Phase-I/KKT、梯度与输出工作区允许分配；没有历史面板反复拟合或 M×候选×路径×月份×资产张量。只读、非连续视图由 `np.shares_memory`、输入不变和无新增签名测试验证；不宣称全链零分配。
