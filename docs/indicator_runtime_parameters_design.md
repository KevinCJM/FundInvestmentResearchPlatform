# 时序指标可变参数：交互与实现设计

## 1. 目标与边界

用户创建指标时，系统识别哪些常量输入具有参数化能力；用户决定开放哪些输入，并配置默认值、合法范围和步长。使用指标时，无需额外操作即可使用默认值，也可在当前页面修改后重新计算。

- 本次面向 `time_series`，不改变标量/多标量结果契约。
- 参数在一次计算中是固定的标量，不是逐日变化的数据序列，不是优化器自动搜索参数。
- 不允许通过参数改变算子、数据字段、价格复权口径、日期轴、输出结构或代码执行逻辑。
- 不把公式中数值相同的不同常量自动合并；共享参数必须由用户明确选择。
- 不改写已有指标历史版本。已有固定公式继续固定，旧参数元数据仍按原契约使用保存时默认值。

## 2. 用户操作与页面布局

### 2.1 定义指标

保留指标库、编辑区、预览区现有布局。在公式编辑区之后、校验按钮之前增加“计算参数”卡片。引导、公式、画布三种编辑方式共用这张卡片，避免维护三套参数设置逻辑。

```text
公式编辑区（引导 / 公式 / 画布）
──────────────────────────────────────────────────
计算参数                         [识别可调输入]
未开放的输入保持固定；这里只影响指标的定义。

可调输入                   当前值     操作
MA / 滚动平均 / 窗口期数       20      [开放为参数]
K / 递归平滑 / 周期             3      [开放为参数]

已开放参数
显示名称  参数代码  默认值  最小值  最大值  步长
窗口期数  window_1    20      1      500     1
[固定为默认值]    使用位置：MA · 滚动平均 · 窗口期数
──────────────────────────────────────────────────
[解析并校验全部通道]       [保存修改 / 另存为新指标]
```

操作原则：

1. 用户先完成公式或应用画布，再点击“识别可调输入”。系统从受限语法树识别算子参数位置，不进行字符串数字替换。
2. 每行同时显示输出通道、算子和输入名称，避免多个“3”无法区分。系统生成合法且不冲突的代码；用户主要编辑人类可读名称，不要求理解 DSL。
3. 点击“开放为参数”默认使用当前常量值。默认收起高级设置；可修改默认值、范围、步长和说明。
4. 可将另一个输入关联到已有参数；服务端检查所有引用位置的类型/范围交集。K、D 的平滑周期默认独立，不能因为当前都是 3 就自动绑定。
5. “固定为默认值”把该参数的全部引用恢复为其默认常量，删除无用参数定义，不残留未引用 schema。
6. 不支持的位置不展示开放操作，并解释“数据输入和公式结构常量保持固定”。第一批开放滚动窗口、最少观察数、平滑周期、滞后期数和裁剪上下界；自由度、幂指数、结构系数等继续固定。
7. 参数定义变化使旧校验/预览失效；保存后形成新 revision。画布未应用时禁用参数操作；新参数化公式必须能重新载入画布，不能丢失参数身份。

### 2.2 使用指标

预览页和产品详情的自定义时序指标使用同一个运行参数组件。

```text
指标：自定义 KDJ v3
参数：窗口=9，K平滑=3                 [展开]
  窗口       [ 9 ]    2–250，整数
  K平滑      [ 3 ]    1–50，整数
  [应用参数]   [恢复默认]
  仅影响当前页面，不修改指标默认值。

实际计算：自定义 KDJ v3 · window=14 · k=5
[结果图表 / 数据表]
```

- 初次加载零配置使用默认值。
- 输入编辑态与已应用参数分开；清空、输入一半、不合法值不触发计算，不转成 0。
- 应用时校验，显示紧邻字段的错误；请求开始清除旧结果或明确标记加载中，防止旧结果配上新参数。
- 恢复默认清除覆盖值；恢复的是当前所选指标 revision 的默认值，不是最新版本默认值。
- 参数值按指标 ID + revision 隔离，产品切换和迟到响应不能污染其他指标实例。
- 默认不持久化临时页面覆盖，不写全局定义、不偷偷保存到浏览器偏好。
- 产品详情支持从真实时序指标目录选取自定义指标，独立图表呈现多通道，不将不同量纲强行叠在价格轴。
- 所有控件有标签，可键盘操作；窄屏表格横向滚动、表单改单列；不依靠颜色传递唯一状态。

## 3. 权限与数据契约

系统能力、作者选择、运行覆盖三层分离：

1. 系统能力：算子 + 参数位置白名单，包含数值类型、硬范围、人类名称。
2. 定义：显式 `parameter_contract_version: "1.0"`，`parameter_schema` 声明开放参数；公式以参数代码引用。未开放输入仍是 literal。
3. 实例：`indicator_id + indicator_revision + parameters`。只允许覆盖已声明代码，遗漏键使用默认值。

新契约显式版本用于区别仍需复现的旧存储数据；不是保留第二套计算实现。旧定义读取不可被自动升级为可调。

```json
{
  "parameter_contract_version": "1.0",
  "parameter_schema": [{
    "id": "window_1", "label": "窗口期数", "type": "integer",
    "default": 20, "minimum": 1, "maximum": 500, "step": 1
  }],
  "series_outputs": [{"id": "ma", "expression": "rolling_mean(market_close, window_1)"}]
}
```

未提供参数和显式传入同样默认值归一化为相同有效参数。禁止未知键、固定参数覆盖、布尔值、字符串、null、NaN/Inf、非整数窗口和越界值。步长以最小值为起点校验，浮点使用容差；范围由用户缩小但不能突破算子硬限制。跨参数约束在每次运行边界验证，如 `min_periods <= window`、`ddof < window`、`lower <= upper`。

## 4. 后端实现

### 4.1 统一参数模块

新增 `custom_indicators/series_parameters.py`：能力注册、AST 候选识别、精确绑定/解绑、参数引用校验、有效值归一化、跨参数校验。前端不维护另一份权威白名单。

新增定义级接口：

- `POST /api/custom-indicators/parameters/inspect`：输入草稿，返回带源位置标识的可开放输入和已绑定参数使用位置。
- `POST /api/custom-indicators/parameters/bind`：指定候选位置和新参数/已有参数，返回更新的草稿；或指定参数执行固定操作。

候选标识与当前公式树绑定，提交同时携带草稿；服务端重新定位校验，不执行用户代码、不使用 `eval`。公式合法性与固定签名编译仍走现有 validate/save 流程。

### 4.2 编译和执行

保存/显式校验阶段把声明参数作为固定类型 scalar 输入编译并预热；运行时传入数值，不为每个窗口值创建新 JIT 签名。未预热运行仍失败关闭，`python_fallback=0`、`request_time_compilation=0`。

固定配置校验只额外允许受新契约声明且在合法位置使用的参数引用，绝不允许行情序列或行情计算结果决定窗口。

### 4.3 历史窗口与结果

- 每个运行实例根据有效参数重新推导历史需求；嵌套 rolling 正确累加窗口，收益序列额外前取一个价格观察。
- 递归平滑保留全历史语义，不擅自换成有限窗口近似。
- 实例使用独立元数据，不修改 repository 中的定义或共享编译计划。
- 参数化裁剪上下界会影响输出范围；运行元数据按本次值重算，不能沿用默认值推导的界限。
- 缓存使用指标版本、完整有效参数、实际数据指纹/代次、产品、区间、截止日及展示点数。结果附完整 `parameters` 和稳定 `parameter_hash`。
- 现有快照只计算锁定 revision 的默认参数；不能拿默认参数的快照替代覆盖参数计算。
- Excel 导出与页面预览使用同一参数归一化、同一取数窗口和同一实例；工作簿留存实际参数，不导出默认值冒充本次值。

## 5. 前端实现组织

- `IndicatorParameterEditor`：定义级候选、共享绑定、默认值/范围设置；调用统一后端能力。
- `IndicatorParameterInputs`：运行级编辑、校验、应用、恢复默认；不修改指标定义。
- 画布增加参数节点，类型仍为 scalar；图与公式往返保存 `parameter_schema` / 契约版本。
- `IndicatorStudio` 保留参数 schema，不再无条件清空；预览与导出携带已应用覆盖。
- 产品详情新增自定义时序区域，按目录和参数 schema 自动渲染，不硬编码某个 KDJ 的参数输入框。
- 新界面文案接入现有系统 i18n，用户参数名保留为业务内容。

## 6. 自审核与验收

必须验证：

- 旧固定指标输出不变；旧参数定义仍固定默认值，新定义才允许覆盖。
- 参数候选定位准确，不把同值常量误合并，不开放价格数据或结构常量。
- 默认/部分覆盖/全部覆盖正确，非法类型、范围、步长、跨参数关系失败。
- 同指标不同参数复用一个已预热 NJIT 计划，结果及缓存隔离。
- MA、嵌套滚动、KDJ 多通道与受控参考结果一致，短区间从历史前取数据。
- 空样本、NaN、窗口边界、不足样本状态保持契约。
- 编辑→校验→保存→回读→画布→公式→预览→导出参数不丢失。
- 页面参数未应用时不计算，恢复默认不修改全局，旧响应不覆盖新结果。
- 前端组件测试、后端针对性回归、构建/类型检查与浏览器流程验证。

本轮不提交或推送 Git；保留已有工作区改动，源码历史回滚仍由 Git 管理。

## 7. 实际交付范围（2026-09-08）

定义入口已接入指标中心公式编辑区下方的“计算参数”。用户无需直接编写参数代码；系统识别输入、生成代码，用户填写显示名称和数值约束。参数名称保持用户输入的业务文本。

运行入口已接入指标中心预览和产品详情的“时序指标研究”。指标中心应用参数后，点击“预览指标”执行；产品详情选择指标后使用默认值计算，应用新参数后自动重算。尚未在不支持时序结果的评价方案、产品对比等页面新增时序功能，不宣称全站所有页面均已接入。

参数化指标从原构建向导继续编辑时进入画布，避免原向导把参数错误还原成常量；高级公式模式与画布均保留参数身份。画布提供可变参数节点、合法连接检查和已有参数资源。未应用的画布或参数设置会阻止指标校验、保存和预览。

第一批开放滚动窗口/最少观察数、递归平滑周期、滞后/差分期数、裁剪边界。不开放任意乘法系数、年化因子、自由度或公式结构；例如通用公式中的 BOLL 标准差乘数，不能仅因其是数字就开放。

Excel 是本次计算的可复核快照：参数、数据区间及公式均对应导出时有效值。滚动窗口在生成工作簿时展开为明确单元格范围；修改工作簿参数单元格不会自动重新取数或重建全部滚动范围，需要在系统修改参数后重新导出。

数值验收覆盖 MA、嵌套滚动、KDJ 三通道、参数改变后的范围推导、历史版本默认值、缓存隔离、图形往返和导出。最终执行结果及未通过的全量检查见 `docs/indicator_runtime_parameters_acceptance.md`。
