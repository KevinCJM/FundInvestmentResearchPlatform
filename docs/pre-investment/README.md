## 如何完成一次研究

1. 在设置中发布风险标尺，在投资目标中确认资金事实、成功标准及风险授权。
2. 选择资产范围：可从产品池构建大类，也可先用指数／参考产品构建战略大类。研究代理与最后实际投资的产品分别管理。
3. 在 LTCMA 中心研究并确认长期收益与风险假设；在 SAA 中选择精确版本，比较候选并保存政策。
4. 按需做 TAA，保存相对该 SAA 的战术决策；纯 SAA 研究无需伪造 TAA。
5. 进入产品与资金，确定实施映射、产品权重、费用、持仓与现金，计算实际产品风险和剩余资金。
6. 汇总为同一研究包，锁定候选后验证，满足对应条件后具名研究定稿。修改输入必须重新验证。

## 当前能力与限制

风险标尺、精简目标流程、两类 LTCMA 上游、五类 CMA、三种 SAA 模式，以及产品与资金／证据汇总／锁定验证／研究定稿已有基础实现。旧总设计中把产品实施、统一验证整体列为下一阶段的叙述已失效。

仍需区分以下边界：

- 历史有效前沿用于历史配置实验；不能替代前瞻 CMA。研究可复现不证明历史 PIT 合格。
- 当前 class-level TAA 与产品应用门禁尚未彻底解耦；独立 LTCMA 不要求实施映射，并不意味着每个旧 TAA 入口都支持无映射。
- 单 CMA 椭球、模式 A 的 E2 参数平均、模式 B 的共同约束有各自能力门禁；E3 原生混合路径、多 CMA 椭球、模式 B 产品联合 QCQP 不作为已完成能力。
- 产品实施基础版支持声明条件下的 ETF／现金研究；全期实际交收、成交容量、基金未来费率、认证独立审批仍未验证。
- 研究定稿不自动成为交易指令、实盘组合或投资效果证明。账户与组合核算仍见独立目标设计。

## 跨页面一致性

持久化对象按精确版本及内容 hash 承接，不自动采用最新版本。资产范围、产品池、研究日、PIT、模型、费用或资金状态改变时，废弃依赖它们的未确认预览；晚到响应不能恢复旧候选。草稿恢复必须说明缺失／失效依赖。

历史结果只读；当前退休、准入与有效性另行核验。底层数据更新不回写已冻结研究。保存、验证、定稿均由后端校验，不以按钮禁用或前端通过数量替代。
