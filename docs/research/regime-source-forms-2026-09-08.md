# 情景数据源表单改造

用户先确定“用什么数据”，再设置“使用哪一列、哪段时间”。同一来源只绑定一次；内部编号与校验值只用于追溯，不要求手填。

| 节点 | 操作顺序 |
| --- | --- |
| 上传时序（原不可变上传时序） | 设置频率 → 选择 CSV / XLSX / JSON → 选择工作表和列 → 确认样例 → 保存并使用；也可搜索已上传版本 |
| 指数行情 | 搜索指数 → 选择一次 → 选择数值字段与日期范围 |
| 宏观时序 | 搜索数据序列 → 选择一次 → 选择数值字段与日期范围 |
| 常量序列 | 连接基准时间轴 → 设置固定数值 |

画布检查器和构建向导使用同一份数据源编辑组件，仍修改原计算图的 `parameters`；高级公式继续使用原注册节点编号。节点名称与计算参数各保留一个入口。

新增指标使用独立的“指标计算”类型，连接画布上游；见 [指标计算节点设计](regime-indicator-nodes-2026-09-08.md)。手工输入时序不再提供入口，已有内联数据只读。

## 绑定规则

- 指数、宏观、上传、指标分别声明哪些字段属于来源身份。更换数据时先移除旧身份和快照，再绑定新来源；保留用户自定义节点名、日期范围及仍适用的数值字段。
- 已有产品绑定指标定义保留兼容表单：版本与计算对象分别绑定，对象或窗口变化后清除旧计算指纹和快照。此类型不再用于新建节点。
- 生产指标目录复用指标中心当前服务的内置和自定义版本库，保留历史修订。目录说明类型化版本、上下文和适用产品的限制；执行时仍由原历史指标接口校验预热、样本和数据可得性。
- 不修改指标中心的编辑、保存、执行代码。实时与事后执行限制、固定签名 NJIT 路径保持原契约。
- 已有 `rows` / `inline_rows` 仅保留读取和回放契约；手工编辑组件已删除。

## 文件导入

- 新增 `POST /api/research-series/parse-file`，接收文件原始字节；只解析，不保存。CSV 支持 UTF-8 和 GB18030；Excel 支持 `.xlsx` 和工作表选择；JSON 支持行数组或 `rows` 数组。
- 最大 8 MB、20,000 行、100 列；Excel 解压上限 32 MB。拒绝重复或空表头、无数据、超限、嵌套单元格及 Excel 公式，避免将未计算公式误当数值。
- 浏览器只做列映射与展示。最终日期、数值、修订校验和完整样本统计复用已有 `/profile`；算术仍由预热 NJIT 执行。
- 用户确认后保存内容寻址的不可变 Parquet。增加原子写入的名称/绑定回执，供 `GET /api/research-series/uploads` 搜索和分页复用；以前没有回执的上传文件仍可选择。
- 上传失败或取消不替换当前节点。卸载、切换节点、取消会中止客户端请求并丢弃晚到结果。修改频率不丢失待确认文件；保存期间节点变化时要求按新配置重试。
- 空数值保留缺失；未指定可得日期列表示用户按观察日已知处理，页面明确提示修订数据应指定实际发布日期。

## 验证范围

覆盖文件解析、Excel 工作表、异常与限额、不可变版本复用、无市场快照的上传/指标目录、内置与历史版本目录、NJIT 无请求期编译、单次绑定、旧身份清理、指标对象选择和取消的晚到响应。

浏览器覆盖 320 / 768 / 1440 像素，保留单节点预览、上游叠加、区间归一化和问号说明的回归。验证不更改用户已有草稿或正式研究数据。
