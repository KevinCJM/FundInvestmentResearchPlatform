# 情景算法中心：时序计算构建改造

## 目标与操作流程

情景定义是枚举时序计算。用户依次定义输入、组合计算步骤、指定输出；试算与结果展示单独管理。画布、向导和高级公式编辑同一份图，切换不改变参数、节点身份或共享依赖。

- 页面沿用指标中心的名称、说明、公式编辑方式和输出通道布局。枚举输出增加状态项，数值输出继续使用单位、格式和小数位。
- 向导分为输入变量、计算逻辑、输出通道。计算步骤使用列表选择，右侧只展开当前步骤；不再同时铺开所有节点的复杂参数。
- 资源按变量、常量、算子、已有指标组织。显示中文名称和用途；执行后端、签名、编译凭证收进技术详情。
- 数据变量在构建阶段表达含义；数据源字段与实际序列的绑定有独立入口。不可用数据在试算时报告，不阻止用户构建计算关系。
- 输出名称、颜色和枚举编号集中配置。缺失状态单独显示“未识别”，不能当作震荡。状态编号是类别，无大小意义，不能参与普通数值均值或插值。
- 实时/事后是计算使用方式，不是输出类型。实时禁止任何事后上游；峰谷完整区间的回填保留真实可得时间。

## 前后端边界

提取指标中心的纯展示构建组件供两边使用，以输入和回调适配旧定义。保留指标原来的保存、表达式、窗口及预览语义，不批量改写已有文件或结果。

普通数学与因果滚动算子由指标中心 typed registry 提供名称、签名和参数，情景目录生成对应节点，运行进入相同 typed AST、DAG、固定签名 NJIT 路径。峰谷、区间统计、分类、确认等领域节点保留独立内核，使用相同节点配置方式。复杂模型保留显式隔离执行节点。

通用输出合同分别描述形状、值类型、枚举域、缺失值和数据引用。情景主输出为枚举时序；概率、置信度与其他诊断仍有自己的类型。旧的固定输出槽通过适配转换，不将整数类别伪装成普通浮点收益。

高级公式允许直接使用指标目录的数值函数和数学表达式；服务端展开为注册节点，禁止程序语句或任意函数。保留旧声明公式兼容读写。固定窗口和阈值仍是明示参数，不能在运行时悄悄覆盖。

## 峰谷模板

价格变量 → 峰谷定位（左、右、首、尾窗口）→ 相邻完整区间 → 区间涨跌幅 → 阈值分类 → 市场状态。

区间振幅、波动率和效率分别添加。改阈值只能改变分类，不能改变峰谷位置；未知首尾保持缺失。仅在需要时显式添加噪声合并节点，且其事后属性继续向下游传播。

## 验收

1. 两边共用的输出与构建组件保留原指标交互；旧指标回归通过。
2. 目录新增数学算子与指标 registry 签名一致；实际 prepare/evaluate 走同一 NJIT 计划，运行时不编译。
3. 图与公式往返保留节点、端口、版本和共享依赖；公式错误可定位，未应用草稿阻止保存及运行。
4. 峰谷模板结果对照；常量调整不改峰谷；缺失不是震荡；实时拒绝事后节点及其依赖。
5. 自审核、后端回归、前端回归、构建以及浏览器实际操作验证。

## 交互与数据合同细化

| 用户动作 | 页面行为 | 数据规则 |
| --- | --- | --- |
| 新建或选模板 | 进入同一工作台；模板入口默认折叠，空图展开 | 模板产生独立定义，不改已有版本 |
| 选择计算步骤 | 左侧步骤列表，右侧仅编辑所选步骤；可跳转画布 | 节点 ID 与连接不因显示名称变化而改变 |
| 绑定输入 | 变量说明与数据绑定分开，字段配置按需展开 | 更换数据绑定保留下游端口；运行前检查真实可用性 |
| 添加算子 | 按变量、常量、算子、指标浏览；显示中文名称、用途和参数 | 参数与端口取自服务端 schema，禁止随意转换空值或截断整数 |
| 编辑高级公式 | 支持注册节点声明和普通数值表达式；应用后同步画布、向导 | 未应用草稿不能运行、保存或切换；解析不执行 Python，也不编译数值计划 |
| 配置输出 | 主通道为市场状态；可添加滤波线、收益、波动等数值通道 | 共八个通道；来源按端口类型筛选；删除通道一并删除展示设置 |
| 修改通道 ID | 失焦后校验并提交，重复编号直接显示可读错误 | 标识符不能覆盖已有通道；名称、颜色、格式属于展示元数据 |
| 运行与查看 | 选择实时/事后和截至日，结果独立于构建显示 | 预热计划后运行；冻结运行定义、颜色、通道单位与小数位 |

输出由 `graph.outputs` 指向计算结果，`graph.channel_metadata` 保存名称、单位、数值/百分比格式、小数位。旧定义没有元数据时不会被补写一个空字段，保留原序列化行为。标准输出描述 `series_outputs` 明确声明值类型、形状、时间轴、枚举域和缺失语义。

市场状态是枚举输出：状态码对应定义中的状态项，不能接入普通数值算子；`unclassified` 是保留的缺失状态。概率保留时间×状态矩阵，置信度、识别时点、生效时点继续保留各自类型。自定义数值通道必须与主状态具有完全相同的观测轴；不插值、不填零，也不参与重新分类。

结果页的自定义数值输出按需展开，每次选择一个通道。走势图使用完整样本，表格明确显示最近最多 250 个观测；百分比只改变展示比例。历史结果读取冻结设置，编辑当前草稿不能改变旧结果。

高级公式可以写 `smooth = rolling_mean(market.value, 20, 20)` 或包含算术的表达式，再将结果连接分类节点。滚动统计窗口、滞后长度最多 5,000；读写图谱不触发计算编译。完整区间的事后结果仍保留真实获知日期，不能通过接入通用算子或改变输出槽绕过实时限制。

## 节点预览空间与全屏设计（2026-09-09）

问题：侧栏已占满浏览器高度，但结果区又嵌套固定高度的滚动框；“紧凑、标准、展开”改变外框，图表仍按固定像素绘制，用户感受不到有效放大。

设计取舍：

- 产品：查看走势优先。取消结果区高度档位、拖动条和收起按钮，以“全屏展开／退出全屏”表达唯一的放大动作。
- 用户：节点配置在上、结果在下；结果至少填满剩余空间，内容较多时由侧栏统一滚动。原始数据表默认折叠，随时可查。
- 前端：使用 flex 自适应布局和 ResizeObserver 获取实际绘图区尺寸；主图、子图按实际高度分配空间，共用时间轴，子图设最小可读高度。全屏使用浏览器原生模态 dialog，覆盖浏览器内容区；背景不可交互，Tab 留在图表内，Esc 仅退出图表并将焦点还给展开按钮。

- 后端：现有 preview-runs/{id}/series 完整分页读取和 normalized-chart 接口已经满足需求。显示高度、全屏状态均为本地视图状态，无需新增接口、字段或计算；后端冻结结果及 NJIT 归一化路径继续复用。

## 跨分支节点对比预览（2026-09-10）

### 使用方式与布局

用户在递归平滑的节点预览里，也需要对比同一数据源分出的单边 EMA；计算依赖关系不应限制比较对象。保留主节点与输出、分析方式和截至日，在运行按钮前新增可折叠的“叠加对比节点”：

- 搜索节点名称、输出名称或节点编号；显示节点名与端口名，区分上游、其他分支、同节点其他输出。
- 可勾选最多七个数值输出，与主输出组成最多八个预览通道。上限沿用图谱输出契约，不自动执行全图。
- 点击“预览节点数据”统一计算，选择的曲线自动出现在结果中，默认独立子图，可改同图同轴或同图右轴。
- 图表旁的“添加其他节点对比”可直接展开上方选择器并聚焦搜索；“叠加已计算节点”管理本次结果的显示，包含所有已计算分支的可绘制输出。增加尚未计算的分支在上方选择后重新预览；不为图表显示创建计算连线或修改算法。
- 共用时间轴，以主节点日期范围为界，保持现有日期对齐、缺失留空、区间归一化、原值表格与全屏行为。不同频率保留各自观测点。
- 改变节点、对比选择、模式、截至日或草稿后标记旧结果过期。读取失败可单独重试；取消和卸载终止等待。

### 后端与数据一致性

`prepare` 和 `preview-runs` 请求增加可选 `comparison_targets`（节点 ID 与端口），只有独立节点预览可使用。投影以主目标和对比目标的依赖并集构建临时定义，规范去重并排序；保留 `preview` 主输出，附加内部 `comparison_1..7` 通道。未选中的未完成节点不参与校验或执行。

同一任务深拷贝冻结定义，使用相同 mode/as_of 与运行内数据源缓存，共享依赖只计算一次。编译令牌绑定投影图和所有目标端口，不能用单节点令牌执行新增分支。读取序列仅返回本任务已有结果，不读取其他运行或重新取源；返回 `overlay_outputs`、各输出关系和 `comparison_targets`。旧 `upstream_outputs` 保留为现有消费方的窄目录，数值执行只有一套。

所有目标分支继续执行现有语义、输入、时点和实时门禁；数值输出的上游若有事后节点，实时预览仍禁止。前端提前禁用并说明，后端再次校验。图谱仍只能以正式 state 契约保存，临时预览不能借对比功能保存或发布。

### 算子与计算边界

本次仅调整图投影、请求编排、结果目录和展示，不新增算子或数学内核，不修改指标中心。递归平滑、EMA及归一化均复用现有固定签名 NJIT 执行；主节点与对比节点保持可独立替换、独立预览。共享源与节点数组由现有执行器复用，没有新增数组复制、重采样、前端数值变换或 Python 数值回退。边界校验只遍历最多128节点的图元数据。
