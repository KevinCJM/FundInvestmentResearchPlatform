# 配置研究全链路优化设计

依据：本轮人工走查登记的 J01–J25。目标是让研究员不必记住菜单路径、反复选数据或理解内部计算参数，也能完成一轮有证据、可恢复的配置研究。

## 共同交互契约

一条持续可见的链路：**产品范围 → 构建大类 → 长期配置 SAA → 战术研究 TAA → 产品配置**。顶部显示真实研究名称、研究日和已锁定对象，不再使用示例名称冒充当前研究。每页只有一个主要下一步，高级算法与审计按需展开。

研究上下文持久保存名称、日期及已保存对象引用；草稿只保存用户输入，不把旧计算结果当成当前口径结果。刷新或 PIT 切换能找回输入，但须重新计算。显式切换产品域使下游引用失效；不同域分别存草稿，不能暗中混用。服务器仍负责可投资域、不可变版本及 PIT 校验，本地草稿没有认证效力。

日期分别命名：研究日（要站在哪天判断）、方案日期（何时确定基线）、行情截至（观察值末日）、知识可得（当时是否发布）、训练/验证区间。默认值在真实覆盖范围内；修正建议需要用户明确点击，不能偷偷关闭搜索或 PIT。

## 页面布局及操作

| 页面 | 首屏工作区 | 主要下一步 | 展开内容 |
| --- | --- | --- | --- |
| 产品池 | 发布版本、成员与待复核项 | 使用已发布版本开展配置 | 定义、评价关联、例外、发布审计 |
| 选池 | 当前研究日、可用版本、恢复的选择 | 锁定范围并构建大类 | 历史版本与回放证据 |
| 大类 | 大类卡片、产品归属、类内权重、异常提示 | 保存并继续 SAA | 详细指标、技术口径 |
| SAA | 方案、构建日期、预算/约束、策略候选 | 采用长期配置并研究偏离 | 风险指标、采样/求解参数、年度明细 |
| TAA | 步骤导航、研究条件、SAA 与拟议目标、判断摘要 | 比较 → 情景检查 → 保存判断 → 产品配置 | 全候选、信号细项、逐日结果、审计 |
| 产品配置 | 承接的类预算、类内产品权重 | 运行并保存产品研究 | 约束细节和口径说明 |

选品支持批量，显示已有大类归属；跨类重复提前阻止。单一产品的类内权重合理建议 100%。主界面统一百分比；偏离及两组合收益之差使用百分点，相对净值收益另标定义。有效前沿除了图，也有可直接采用的候选权重/收益/风险表。

桌面避免多层大标题挤占首屏；手机使用单列卡片，长名称允许换行，只有宽表局部滚动。输入有明确 label；错误就近、可读且持续显示；禁用按钮说明原因。折叠后关键状态和主要动作仍可见。

## 可信研究与异常处理

真实诊断发现：511010.SH 在活跃快照中，2026-06-01/02 的 `adj_nav` 为 145.947686/1.459430，而 `unit_nav` 为 141.488/141.487。该断点直接进入收益链路。本次不猜测复权倍数、不改正式行情；增加可解释的数量级断点检查，阻止误导结果向下游传播。

共享规则：相邻净值比例 ≤0.1 或 ≥10（含等号）标为待核查，输出产品/资产、日期、变动及数量；这是特定输入质量检查，不代表全面数据认证。检查发生在大类拟合/保存、既有分类回测及 TAA 计算/应用边界。异常数据可查看，但必须修正来源或替换产品、重新构建后再计算。

TAA 新增 `/preflight`：读取锁定数据，返回覆盖范围、样本数、训练数据尚不可得计数、未知可得计数、最早可得日、可行日期建议、质量问题和行动入口。建议训练边界只依赖日期/可得时点和至少 20+20 样本，不使用收益表现选择边界。既有训练门禁保持；未知时点明确限制为研究，不能认证 PIT。

二次走查补充：趋势应在每个收益区间开始时，寻找最近、完整且已知的连续观察窗口，而不是要求紧贴开始日的窗口必然已公告。每个依赖仍需 `available_at <= period_start`，未知时点不能当成已知；不修改公告日、不用未来收益。超过规则有效期则回到 SAA。保留窗口起止、最后观察日、可得日和滞后天数，运行前展示训练/验证有效信号数；训练完全没有可用信号时拒绝搜索，并说明相同零评分不能证明最佳强度。该调整改变趋势时点算法，应更新算法版本并重新计算，旧冻结研究不迁移、不改写。

## 情景与版本

情景是具名研究实验，可并列比较、移除和随版本保存，最多 12 个。输入改变则相关实验须重新计算，不把旧实验混入新结论。保存请求只上传情景定义；后端复用同一已核验 preview 重算结果，拒绝客户端提供收益。保存后结果、定义和内容 hash 保持不可变；旧版本缺少情景字段时展示“未保存情景”。

历史情景限制在研究时点和数据范围内；自定义冲击明确是资产涨跌假设，不附带概率。趋势摘要展示信号值、信号日、原始偏离、实际偏离及约束影响，强度选择方式不能替代经济解释。

SAA → TAA 继承资产、权重、产品映射和约束；TAA 以自身训练/验证、日频目标及费用重新计算基准。原 SAA 回测结果不冒充 TAA 对照。交接时明确这一点，保留零偏离为有效结论。

## 数值、存储与版本边界

新增检查是独立输入资格语义，不是新的黑盒配置算法；复用唯一 TAA 模拟核心。数值扫描采用固定签名 NJIT 并纳入启动预热、禁止新签名编译；只读任意步长数组可直接进入，输出为每资产的首个异常位置与计数，或时间资格摘要。Pandas 只用于 Parquet 解码/对齐及封装；不增加逐期 Python 运算。

计算输入、历史版本和行情文件不原地修改。只在解码/对齐边界做必要 dtype 转换；检查默认复用收益数组。历史情景仅允许本次 preview 已锁定的覆盖范围，复用只读收益切片并随版本冻结；扩大情景区间须先调整研究区间、重新计算。文件大小和情景数量设预算，失败时不创建不可读版本。

## 验收

1. 产品池到产品交接浏览器走查：真实对象、可恢复输入、正确预算和主要下一步。
2. 刷新/PIT 变更/返回 SAA/切换产品域：不丢输入、不串数据、不显示旧结果为新结果。
3. 数量级断点、缺失、非有限、边界等号；输入只读、切片共享、固定签名不新增。
4. 预检可行/不可行日期，20+20 样本，训练未成熟/未知，建议不得利用验证收益。
5. 多情景保存恢复、过期 preview、历史数据变化、客户端结果注入、旧版本读取。
6. 定向后端/前端测试、构建、浏览器研究路径和 390px 布局；记录已完成与尚缺实证的分支，不把技术通过当成投资有效性。
