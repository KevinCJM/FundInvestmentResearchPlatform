# 历史配置空间与有效前沿

本主题负责历史样本下的随机探索、逐目标前沿和可采用权重，不替代前瞻[SAA](saa.md)。目标点数、单点迭代预算与实际成功节点数分别报告。
## 统一流程

同一前端业务模块“可配置空间与有效前沿”：数据方案与区间 → 收益／风险口径 → 单项／联合边界 → 多轮探索与精度 → 可选整条前沿和代表点精炼 → 生成 → 散点、前沿、轮次统计、代表点及逐点权重采用。

配置直接可见；指标相关细项按选项显示，详细结果可在模块内展开。保留普通／对数收益、现有五个收益选项与七个风险选项、全部相关配置、默认六轮及轮次增删。沿用工作台令牌、40px 操作高度、表格语义和移动端重排，不把全部实现强塞进一个组件文件。

## 多轮随机探索

- 第 0 轮使用 Dirichlet(1) 随机向量，在单项／联合／总资金约束下生成候选；不再把第一个点固定为等权。`samples` 为本轮尝试预算，失败不计作可行点。
- 后续每轮只从上一有效轮结束时确定的种子集合选择，使用 `(1-step) * seed + step * noise` 扰动，再修复约束。种子集合在整轮内冻结，禁止以当前轮刚生成的点替换。
- 首轮保留全部可行点作为种子，与历史行为一致。后续每轮结束按当轮收益最小值至最大值分成 `buckets` 桶；最大收益端点明确归最后一桶。每个非空桶选风险最低点，风险相同时保留最早候选；所有收益相同时按风险择优取至多桶数个点。没有有效候选的轮次保留上一有效轮种子并报告状态。
- 恢复的是有方向的筛选机制，不保证每轮每个点严格改善或全局收敛。保留所有可行采样作为扩展视图，同时提供各轮筛选保留点视图；最终候选统一比较，避免删除当前已有散点查看能力。
- 返回逐轮请求／接受／筛选数量、候选区间、父候选索引与选种标记。增加可保存的随机种子输入，默认 42；同输入同种子确定性复现。

## 严格权重精度

选择 `step` 时，最终可采用权重必须同时满足 `w_i = k_i * step`、`sum(k_i)=1/step`、单项与全部联合上下限。默认不量化；保留 0.1%、0.2%、0.5%。步长须能整除总资金 1；不允许隐式改成其他精度。

唯一 NJIT 整数可行化内核：将上下限转换为整数 `ceil(lo/step)` / `floor(hi/step)`；先作接近输入向量的平衡舍入并校验全部约束，必要时执行有界整数深度优先搜索。搜索按接近输入的位置优先枚举，使用剩余总量及每组剩余上下界剪枝；预算固定 50,000 次节点访问。完整穷尽代表不可行，预算用尽代表未求得可行解，两者状态分开。只返回已验证可行解，不承诺最近点或整数全局最优。

连续修复仍服务未量化请求；整数修复是不同权重域的必要路径，不是历史副本。禁止整数结果再次归一化或连续修复。请求开始先做离散可行性检查，失败返回清晰错误，避免重复尝试明显无解的约束。

代表点局部精炼仍以原候选为基准，每个新 proposal 进入同一权重域修复，只有严格改善才替换；额外校验初始精度。

## 连续前沿与可采用组合

保留 20／200 个收益目标与独立单点最大迭代预算，使用当前唯一 NJIT QP／SQP 实现。连续理论曲线是参考，不表示指定精度的可行组合。

- 未量化时延续已有网格、候选集合、代表点和采用契约。
- 量化时，连续网格点保留真实求解坐标、权重、状态和迭代信息；逐点通过同一整数内核生成可采用组合，并重新计算其真实收益／风险，报告是否仍达到原目标。只有成功的离散组合加入可采用候选集合。
- 连续曲线在自身连续候选域内判断非支配性；离散候选前沿在最终离散集合内判断。两者图例、权重明细与采用按钮明确区分，不能跨域混合选最大夏普等代表点。
- 采用操作提交离散修复后的权重；不可行或预算耗尽时禁用并说明。连续解和离散解不共享虚假的坐标或成功声明，重复点单独计数。

## API 与状态管理

沿用现有 endpoint 和大部分请求字段。`exploration.seed` 默认 42；rounds 参数严格校验，单项／联合约束不静默忽略未知资产或覆盖重复组。扩展响应 `exploration`（轮次审计与筛选索引）、`weight_domain` 和网格 `adoption`（可采用权重与重算指标）。旧的基础响应字段继续保留。

前端草稿保存新增种子和既有所有参数；结果不持久化为新历史记录。任何配置变化均清除旧结果；进行中的旧请求不能覆盖新配置的结果。生成按钮附近显示采样预算、精度及目标点数，空、忙、失败状态在模块内可见。

### 指标参数补充

现有收益 EWM 的 `window` 曾只传参未参与数值计算。本轮使其在采样、精炼、连续网格及离散采用中使用同一口径：仅对末尾 N 个收益观察期按现有递推规则计算，0 为全部样本，超过样本长度时使用全部可用样本。风险仍使用自己的独立窗口。无风险利率和其他指标公式不在本轮变更。

## 计算与算子边界

收益计算、风险计算、桶内选种、整数可行化、轮次编排内核各自保持明确职责。整数搜索共享剩余总量与分组状态，是耦合约束内核；轮次探索共享随机状态和上轮种子，保留为耦合执行。收益／风险及选种可独立测试替换，不新增画布黑盒节点。

全部生产数值路径为固定签名 NJIT，登记启动预热并关闭新签名编译；版本升级到 3.0.0，明确这是恢复业务语义及严格精度的算法变化。只读共享收益矩阵，候选权重和搜索栈为独占工作数组；轮次用索引范围访问，不复制历史收益矩阵。返回数组及整数搜索缓冲区是必要输出／工作内存；不声称全流程零分配。
## 唯一计算链与 API

```text
ClassAllocation + FrontierGridControls
→ POST /api/efficient-frontier
→ 原有分类净值读取、收益转换与随机探索
→ 可选三个代表点局部精炼
→ solve_frontier_grid_kernel
   → 收益向量、风险模型与线性约束（一次构建）
   → 最小风险端点 + 最大收益端点
   → N 个收益目标、N 次逐目标尝试
→ 成功的网格解加入同一候选集合
→ 唯一 Pareto 筛选 + 唯一最终代表点选择
→ API、目标明细、曲线和采用权重
```

新增请求是独立的 `frontier_grid`，不将它装进旧的 `refine.iterations`：

```json
{
  "frontier_grid": {
    "point_count": 200,
    "max_iterations": 300,
    "weight_domain": "continuous",
    "accept_continuous_weights": true
  }
}
```

不提供该字段时不运行目标网格，原有请求行为不变。可选 `target_start/target_end` 支持显式数值区间，两者必须一起提供且有序；默认由两个求解端点自动确定。请求拒绝多余字段、布尔型点数、小数点数、越界预算及不完整区间。计算校验失败返回 HTTP 400，Pydantic 格式错误返回 422；不升级为无说明的 500。

每个 `frontier_grid.points[i]` 保存 `target_index/target/status/iterations/value/weights/optimality_residual/constraint_violation/candidate_index/duplicate_of/on_frontier`。失败迭代可保留有限的实际诊断值，但 `candidate_index=null`，不进入可采用集合。

响应明确区分：

- `requested_points`：目标数量。
- `attempted_points`：逐目标处理数量，包含经已求解上界证明不可行而直接拒绝的目标。
- `solver_calls`：真正执行过至少一次目标优化迭代的数量；可行的 20／200 目标验收要求恰好 20／200。
- `successful_points/failed_points/unattempted_points`：三者合计等于请求点数。
- `infeasible_targets/duplicate_targets/duplicate_solutions/added_candidates`：不可行、重复和新增候选分别留痕。
- `endpoints`：两个端点的状态、迭代数、残差和收益；端点调用不冒充目标网格调用。

原 `refinement.items` 继续记录各局部分支的改善；`final_representatives` 的来源增加 `grid`。最终三个代表点始终从采样、局部精炼和成功网格解的同一个集合重选，不能把某个分支的结果冒称集合最优。

## 数学与求解边界

现有收益口径均为权重的线性函数，记为 `mu' w`，包括当前内核定义的平均、年化平均、累计求和及 EWM。此处复用既有数值真相，不借网格功能修改收益定义。

对目标收益 `r_k` 求：

```math
min_w Risk(w)
s.t. 1'w = 1,
     lo_i <= w_i <= hi_i,
     group_lo_g <= sum_{i in g} w_i <= group_hi_g,
     mu'w >= r_k.
```

标准差、年化标准差及 EWM 波动可写成 `sqrt(w' Sigma w)`，等价于最小化方差。样本协方差复用统一 `covariance_2d`；EWM 使用现有风险递推的极化计算交叉项，避免维护另一套衰减语义。均值—方差验收逐点对照解析解和测试专用 SciPy 参考；SciPy 不进入生产调用链。

主动集 QP/LP 从真实可行初值出发，求 KKT 方向，遇到边界加入独立约束，符号不合格的乘子移出主动集。最大收益端点是 H=0 的线性规划，走到实际阻挡边界；不是用巨大风险厌恶参数近似 LP。方向方程的小对角正则不改变原始目标和梯度，成功判据仍按原目标的数值残差及可行性检查。

非二次风险复用原风险内核，以有限差分梯度、受约束 QP 子问题、可行线段搜索和阻尼 BFGS 更新进行局部 SQP。差分步长及外层局部步长容差为 `1e-6`；不能把非光滑 VaR/ES/下行风险/最大回撤的局部停止解释为全局解。每个内层 QP 最多 300 次、线搜索最多 30 次，响应披露这些预算。达到外层上限、线搜索失败或数值失败均保留状态。

数值契约：QP 方向容差 `1e-9`，停止时原目标归一化驻点残差检查不超过该容差的 10 倍；最终资金/单项/分组/目标约束最大违反量不得超过 `1e-7`。边界误差不通过放宽经济约束或修补权重掩盖。

默认目标从已求解最低风险组合的收益到已求解最大收益端点等分。端点未收敛时不宣称区间已确定，N 行全部记录 `range_unresolved`。超出已求解最大收益上界的显式目标标记 `infeasible_target`；数值初值失败不当成数学不可行证明。奇异协方差、平坦目标或严格边界可能产生重复解；这不是 N 个不同有效点的保证。

## 算子颗粒度与内存

QP 的主动集、KKT 方向、阻挡约束和乘子移除共享迭代状态，属于联合约束耦合内核；拆成普通无状态单向节点会改变迭代语义。外部独立步骤为模型与约束构造、目标网格、逐点调度、候选合并、Pareto 筛选及展示；没有把整个配置过程注册为新的黑盒算子。

历史收益矩阵只在输入边界做一次必要的 dtype/布局转换，网格内部复用同一个数组。固定签名接受只读任意步长输入；测试验证 `np.shares_memory`、只读跨步收益和约束、无输入改写及请求签名零增长。允许分配 N×资产数的求解结果、资产级 BFGS/KKT 工作区和非二次风险的收益向量；不会为每个目标复制 T×资产数的完整历史。

所有新增生产数值步骤在启动预热阶段执行，dispatcher 禁止新增签名；版本 `2.4.0`、22/22 固定签名内核。错误不会转入 Python、object mode 或外部 SciPy 求解。此实现仍使用优化线性代数作为 NJIT 内部操作，不代表整个请求零分配。

补充探针：3/8/12 资产、重叠分组和半正定 Hessian 的30组QP/LP与测试专用SciPy参考均通过，最大目标值差约 `2.96e-13`。本机2400×12只读跨步收益视图，共享底层内存，三次运行的网格内核中位数：20目标约3.44毫秒、200目标约13.15毫秒，均全部成功；不含导入、预热、取数、采样或JSON封装，不是API耗时或跨机器性能保证。进程峰值RSS约314MB包含导入/预热/参考库，不是网格单次新增内存。探针前后固定签名数量无增长，原始输入未改写。证据为 `numeric-evidence.json`。

## 权重复用

策略路由的 `cache_key`／`precomputed` 用于复用与本次输入完全一致的权重。资产顺序、样本窗口、约束、算法、PIT 与缓存身份必须一致；列名相同但顺序不同不能直接应用矩阵。输入变化使缓存失效，不能以复用替代合法窗口检查。
