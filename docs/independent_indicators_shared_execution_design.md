# 独立指标、共享执行：指标中心重构设计

## 1. 产品边界

一个标量指标只定义一个结果；不提供多标量类型、父指标/子结果选择器、指标组或批量创建组。仍保留时序指标及其已有通道协议。用户在任意页面选择多个独立指标时，服务端共享数据准备与公共 DAG 节点，不能以要求用户合并指标作为性能前提。

编辑器只保留：基本信息 → 一个结果的格式/单位/评分方向 → 计算逻辑（画布/向导/高级公式）→ 校验预览。算子可产生内部区间等结构化中间值，但最终必须通过字段提取算子归为一个数值、日期或时长。内部结构不是额外的业务指标类型。

公式展示使用真正的 LaTeX 数学记号；可编辑源码与展示记号严格区分，展示记号不能冒充无损编译输入。主预览不出现 drawdown_analysis、last_drawdown_interval 等函数名。

## 2. 最大回撤规则（本次需求的统一契约）

给定日期升序、严格有限且为正的净值 P_i：H_i=max_{j≤i}P_j，D_i=P_i/H_i−1。回撤序列为非正值。

- 最大回撤幅度 M=−min_i D_i。
- t*=max argmin_i D_i：若多个位置具有相同最大回撤，选最后位置；同一回撤段出现多个相同谷底，也选最后谷底。
- p*=max{j≤t*: D_j=0}：谷底前最后一次历史峰值；重复峰值选最后一次。
- r*=min{j>t*: D_j=0}：选中谷底后首次恢复峰值；不存在则恢复日期及恢复时长不可用。
- 最大回撤开始日期为 d[p*]；最大回撤结束日期明确命名“最大回撤谷底日期”，为 d[t*]，不与恢复日期混淆。
- 最大回撤持续天数（下跌阶段）=d[t*]−d[p*]，单位自然日；恢复天数=d[r*]−d[t*]；完整持续天数=d[r*]−d[p*]。
- 如需观察期数，使用位置差算子，单独标明“观察间隔数”，不能冒充自然日。
- 所有日期与持续时间均取同一最大回撤区间，不再以最长水下段替代最深回撤段。
- 无回撤：幅度0；开始、谷底、恢复日期以及事件持续时间均不可用，因为不存在回撤事件，不虚构一个零长度区间。空输入、非有限/非正净值在数值入口失败关闭；日期按数据提供器的对齐、排序和重复处理契约验证。
- 相等采用规范回撤序列的精确浮点比较，不用宽泛 isclose 将真实不同深度误判为相等；展示四舍五入相等不代表计算深度相等。
- 未恢复不填0、不把截止日伪装成恢复日；相关结果携带 DRAWDOWN_NOT_RECOVERED 状态。最大回撤率仍可使用。

参考概念：VectorBT 官方将 peak/valley/end 及 Active/Recovered 分开；本项目起点、谷底并列规则以本文件的用户需求为准，并不宣称与其他库默认选择规则相同。https://vectorbt.dev/api/generic/drawdowns/

## 3. 通用算子与独立内置指标

流水线：净值 → 回撤序列 → 最后一次最大回撤区间 → 提取起点/谷底/恢复位置 → 通用索引取值/日期差。幅度独立使用 −min(D)，或者在存在回撤事件时使用 −D[t*]；不再提供提取深度的业务包装。

受限白名单算子：last_drawdown_interval、interval_start、interval_trough、interval_recovery、value_at、days_between。value_at 对日期或数值序列保留原类型与量纲；interval_depth 和 date_at 不在当前目录中。区间是只读中间状态，固定长度数值 tuple 在 NJIT 内传递；不允许任意属性访问/Python callback。日期数组由数据边界转为 epoch day 的固定 float64 数组，计算结果按 date 类型还原 ISO 日期。日期不能参与普通加权评分，也不允许通过单位名称将任意数字伪装成日期。更完整的原语、回归状态与兼容语法展开规则见 indicator_operator_primitives_design.md。

内置目录中的每项都是独立指标：最大回撤率、最大回撤开始日期、最大回撤谷底日期、最大回撤持续天数、最大回撤恢复日期、最大回撤恢复天数、最大回撤完整持续天数。必要时允许从现有指标按锁定版本展开公式；用户可以自己组合字段提取和日期差，不必新增后端专用指标算法。

数学记号：\(D_i=P_i/\max_{j\le i}P_j-1\)、\(\mathcal I^*(D)\)、\(p(\mathcal I)\)、\(t(\mathcal I)\)、\(r(\mathcal I)\)、\(d_k\)、\(d_b-d_a\)。主预览使用记号，计算说明给出最后并列、峰值、恢复和日期差定义。

## 4. 跨指标共享 DAG

### 4.1 逻辑合并

批次按真实输入域、日期窗口、数据快照/可见时点、频率和缺失策略分区。对每个分区把独立指标根合并到同一 DAG。节点身份包含：算子ID+版本、完整输入类型/语义、规范常量、按顺序的父节点身份及实际参数绑定。不能仅按节点ID、公式显示文本或指标名称共享；不同无风险利率等绑定保留区别。

只合并纯函数中确定相同的节点，不做改变浮点计算顺序的代数重排，不跨币种/区间/数据代际合并。共享缺失字段不强迫无关指标使用交集样本。多根仅为执行计划内部结构，与业务指标类型无关。

### 4.2 物理执行与裁剪

固定签名批计划接受输出选择掩码，按选中根求依赖闭包；只有被依赖的节点执行。共享节点只执行一次，缓存值和独立状态供所有依赖者使用。每个根分别产生数值和状态，局部分支失败不牵连不依赖它的指标。

公共节点复用与循环融合分别审计：前者必须保证，后者只在语义等价且基准更快时采用。不要把“一次HTTP”“一个njit函数”称作“只遍历一次”。

### 4.3 预热与任意选择

不枚举所有指标组合。显式准备阶段编译兼容指标的共享计划；已保存评价方案/快照编译其固定计划。可利用已预热超集计划和选择掩码执行任意子集；若没有覆盖所选指标的预热计划，需先经准备入口编译，正式 evaluate 失败关闭，不能退回逐指标重复执行或临时JIT。

编译计划缓存绑定算法/类型，结果缓存绑定指标版本、参数、实际窗口和数据指纹。必须先检查结果缓存再执行计算；命中不能只是“结果取缓存但计算已经跑过”。跨请求复用只限相同数据代际的显式缓存，不能使用进程级可变上下文混淆请求。

## 5. API 与前端

result_kind 仅 scalar/time_series。标量结果新增/确认 value_type（number/date/duration）、日期 ISO value、duration_unit、status/warnings。日期只展示/筛选，不参与评分；持续时间可由用户明确配置优劣方向。

保留 indicator_id+revision 作为公开引用；不再要求 output_id。多指标批请求仍返回独立 results[]，列表、详情、对比、评价、组合诊断、快照和导出统一使用这些独立引用。前端不展示共享编译内部根/组；只在诊断信息中显示计划和缓存统计。

输出来源与引用解析由服务端规范化；不在浏览器正则猜算子输出。画布单标量只有一个最终结果，时序保留多通道。编译/校验错误定位节点，日期算子输入类型不匹配时给出中文诊断。

## 6. 存量迁移与代码治理

先只读扫描工作区 custom_indicators、evaluation_plans、snapshot_indicator_config 和历史定义引用。当前实际配置扫描未发现多标量定义或子结果引用，因此本轮不执行数据迁移，也不为不存在的旧数据保留第二套执行器。API 对已取消字段（包括空值）明确拒绝；滚动来源同样不得被静默重新绑定。物理清理脚本再次检查实际存储；如另一个工作区存在旧多标量引用，必须停止清理，先单独制定并验证保留原公式、规则及版本含义的迁移方案。不能修改历史运行数值或重解释旧快照。

特别注意：上一版最大回撤算子选最早并列，本次为最后并列。不可把旧执行结果的日期静默改为新规则；若有真实旧引用，数据迁移必须显式标记规则版本，或阻止自动变更并报告。正常时序协议版本、API版本、数据快照和迁移记录不删除。

删除多标量请求模型、CRUD/校验/评分分支、专属前端组件、选取子结果工具、专属测试/说明及无效导入。共享编译能力迁移到唯一当前执行实现，不保留旧函数作为回滚后门。Git负责代码回滚。工具无法物理删除文件时如实列出，不用清空文件冒充完成删除。

## 7. 快照的独立结果契约

标量配置按锁定指标版本、周期执行已准备的共享计划；日期以 ISO 日期保存。时序配置必须指定 channel_id 和 last_finite，不能送入标量执行接口，也不能把两个通道写入同一字段。同一时序指标版本和目标的多个通道只运行一次原有时序计划。

内部快照模式在完整请求区间内通过固定签名 NJIT 取末个有限值，然后记录 value_date；不从最多5000点的图表序列反推，不使用预热区间的有限值补齐本期结果。所取值早于区间末日时显示说明；全缺失返回不可用而非零。快照缓存与普通图表缓存区分，参数/源数据/版本仍参与身份计算。元数据保留通道、归约、锁定展示信息及值的实际日期。生成期间源数据代际变化则拒绝产出；完成或失败均关闭本任务的计算资源。

## 8. 验收

独立数学参考：最后并列、同段重复谷底、重复峰值、尚未恢复、无回撤、周末跨日、空/非有限/非正净值、日期不齐。所有日期/时長同一区间；更深与更长区间不同的反例。

共享计划：两个独立指标依赖同一回撤序列时节点仅一次；多个日期和时长共享同一个区间；不同参数/窗口不串用；子集根不执行无关分支；缓存命中真实0次计算；正式运行新JIT签名为0；读取顺序和并发结果一致。

产品流程：仅使用现有算子创建独立自定义日期/持续时间指标；保存/更新/预览/画布往返；LaTeX无函数名占位；详情/对比/评价/快照/Excel；已存在的旧公式解析契约回放，退役子结果字段拒绝。最后运行专项后端、前端、浏览器、构建、i18n和路由治理检查。未通过项逐项报告，设计文档不等于验收记录。物理待清理清单由 indicator_retirement_manifest.json 维护，内容哈希不符时不得删除。
