# 新版投研首页

## 需求

将用户提供的浅色首页设计整合进当前 React 应用，替换 `/` 的旧首页。保留小牛研究场景、五阶段流程、四类核心能力、全球数据、精选功能与页脚的顺序和主要视觉比例；不能仅展示图片或另外维护一套演示路由。

- 首页支持中英文、桌面/平板/320px 手机、键盘与减少动态效果设置。
- 导航、流程卡和工具卡打开已有业务页面；首页自身不启动下载、计算、保存研究、账户创建或下单。
- 搜索只查找功能入口；导览说明工作流；研究示例明确不是运行结果或投资建议。
- 最近打开只显示当前浏览器实际访问过的模块，支持单独清除，不记录产品编号、查询条件或研究内容。
- 工作台继续保留原导航、阶段目录、PIT 口径提示与业务状态，不能套用首页的宣传式信息布局。

## 技术设计

- `App.tsx` 仍只有一个 `/` 路由，调用 `ProcessHome`；旧首页 JSX 和未使用的 `home.*` 翻译在本次替换中删除。没有复制原型中的 HTML 字符串、命令式演示路由或模拟研究后端。
- `ProcessHome` 组合首页区块，`homepage/HomeHeader` 提供浅色导航；原 `Header` 仅在 `/` 不渲染。所有工作台仍使用原 Header 和 PIT 组件。
- `homepage/catalog.ts` 定义真实模块入口，阶段 URL 复用 `processRegistry`；搜索、卡片与历史记录共享该目录，链接不接受用户输入 URL。
- `homepage/history.ts` 以最长路径匹配模块，只持久化白名单 ID，最多 8 个，去重且限制读取长度；存储不可用不阻断页面。清理失败明确提示，不能误称已清理。
- 共享 `LocalizationProvider`、`chooseLocale` 和 `locales/system.json`，不添加第二份语言偏好。服务器业务翻译不能覆盖内置首页系统文案。
- 原生 `dialog.showModal()` 提供背景隔离；显式设置搜索焦点、Tab 首尾循环，Escape/关闭恢复触发点；卸载恢复滚动和键盘监听。在 StrictMode 下验证挂载清理。
- CSS 只使用 `.quant-homepage` 和 `home-*` 命名，不重写现有全局组件。小屏重排内容，不把桌面画面整体缩小。
- 图片复用用户本地 `FundInvestmentResearchPlatform-fresh/frontend/public` 中已有的小牛与地球 WebP、品牌 SVG；源目录只读未改动。`800/1200/1672` 像素规格通过 `srcset` 选择，Hero 优先加载，地球延迟加载，无外部图片依赖。
- 与图片的有意文案差异：将“界面演示”改为“投研平台”；将“未连接业务服务”改为研究示例/下单边界，避免对整个实际应用作错误承诺。K 只代表界面标识，弹窗明确不是已登录身份。
- 本次不修改后端生产 API、数值算法、下载或数据目录配置。新增 `backend/tests/business_numeric_app.py` 仅供浏览器测试，复用既有固定签名 NJIT 路由及预热，不访问正式数据、不新造计算实现。

## 验证与回滚

验收记录与截图见根目录 `design-qa.md`。运行前端全量 Vitest、TypeScript、Vite 构建、i18n 契约、隔离 Playwright，以及相关业务数值/本地化后端测试；真实工作区数据验收默认跳过，不据此宣称投资有效性或生产部署完成。

回滚使用 Git revert。不得在源码中恢复双首页或保留旧入口作为隐藏开关。
