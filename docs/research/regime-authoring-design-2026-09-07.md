# 情景独立构建与峰谷算子拆分设计

## 范围与隔离

参考指标中心的变量／常量／算子目录、规范计算图及公式往返思路，在历史情景模块内实现。不得修改 `backend/cal_indicators`、`backend/custom_indicators`、指标路由、IndicatorStudio、indicator-graph 或公共 GraphCanvas。指标中心现有代码作为只读依赖；开发前记录其文件哈希，验收时再次比较。

旧 `model.peak_trough` 定义继续原样执行。新版日频模板升级为独立节点链；已保存方案和既有运行不自动迁移。

## 计算节点

1. `pivot.local_extrema`：只查找局部交替峰谷，四窗口独立，平台取最早点，同类候选保留更极端点。输出专用峰谷序列，不输出市场状态。NaN/Inf/非正值断开连续块。
2. `segment.between_pivots`：将相邻异类峰谷转成 T 长度 start/end 索引数组；只覆盖完整 `[start,end)`，无效和尾部为 -1。
3. `segment.change`、`segment.amplitude`、`segment.volatility`、`segment.duration`、`segment.efficiency`：独立统计节点，输入价格与同一分段节点的边界，输出每个波段在其日期区间重复的统计值。右端点参与统计，不进入前段标签。
4. `model.range_threshold`：通用三态阈值，参数或常量序列输入；大于上界为正向，小于下界为负向，等于门槛归中性。缺失保持未知。只做比较，不寻找峰谷或合并波段。
5. 原有 `output.state` 或图根输出返回每日枚举；附加统计不自动参与状态分类。

默认日频链：指数→峰谷→分段→涨跌幅→阈值分类。上下阈值以两个常量节点接入。默认 ±3% 只是可调研究起点。振幅、收益波动率、效率和区间合并均为显式可选步骤。

统计定义：涨跌幅=end/start−1；振幅=max/min−1；波动率为逐期简单收益的样本标准差，ddof 可选0/1，默认1且不年化；效率=绝对端点价格差/累计绝对逐期价格差；长度=end−start。越界、乱序、不一致边界和缺失路径失败关闭或输出未知，禁止跨段串算。

所有数学循环使用固定签名 NJIT，加入现有启动预热目录并禁用新增签名。Python 只负责验证、数组转换、编排和结果封装。

## 时间与来源合同

峰谷检测及完整区间统计登记为事后节点；实时模式在目录、后端解析和执行入口禁止。依赖传播覆盖最终输出上游，完整样本可得性由注册元数据决定，不能靠旧节点名称判断。可得日采用完整识别输入的最晚可得日，不能生成交易生效日。

区间索引只允许连接同一分段节点的一对边界，并禁止在分段以后单独重采样、截取或错接到另一日期轴。结果证据沿实际分类上游查找，不取不相关诊断节点。旧峰谷证据与新独立统计证据可区分。

## 三种编辑方式

- 画布构建：继续使用现有公共画布的只读依赖；情景侧节点库按变量／常量／算子／指标分类。
- 构建向导：修改同一份 graph；提供节点参数、可兼容上游输入、多输出端口、删除／增加节点及状态根选择。
- 高级公式：情景专用受限声明式源码。每行一个具名算子调用，名称由注册 ID 将点替换为下划线产生，例如 `swings = segment_change(value=market.value, start=segments.start, end=segments.end)`；`output(state=classifier.state)` 声明根，`expose(market, swings)` 声明调试节点。参数为受控字面量，引用只能是已声明节点的端口；不执行 Python、不支持导入、任意调用或属性链。

后端 authoring/resolve 接受 base definition 与 graph/formula，执行 AST 白名单及原图校验，返回规范源码、definition 和诊断。节点标签、类型版本、布局及业务元数据从基础定义保留；新增节点使用当前版本。往返不改变显式参数、输入、输出、暴露节点和类型版本。解析不读行情、不准备或执行数值计划。

公式草稿未应用时，运行／保存与切换模式需要先应用或显式放弃，禁止运行上一次有效图冒充当前输入。异步响应按请求与基础定义指纹丢弃旧结果。保存仍走现有定义及版本接口，不建立第二份业务定义。
